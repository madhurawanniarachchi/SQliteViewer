Convert SQLite to JSON

Export rows as a JSON array of objects, ready for APIs, front-end prototypes, test fixtures and document databases.

Export to JSON

Export a SQLite table to JSON

  1. Open your .db, .sqlite, .sqlite3 or .db3 file in SQLite Viewer. It stays in your browser.
  2. Select a table, or write a query that returns exactly the rows you need.
  3. Click Export above the results and choose the columns to include.
  4. Pick JSON and the file downloads straight away.

What the JSON looks like

Each row becomes an object keyed by column name, and the file is an array of those objects.

[
  { "id": 1, "name": "Ada", "email": "ada@example.com" },
  { "id": 2, "name": "Linus", "email": "linus@example.com" }
]

Shape the output with SQL

Use a query to rename columns with AS, join related tables or filter rows before exporting, so the JSON matches the structure your application expects.

Your data never leaves your device

The conversion runs as JavaScript in your browser tab. The database is not uploaded to a server, so it is safe to use with customer data, app databases and internal files.
