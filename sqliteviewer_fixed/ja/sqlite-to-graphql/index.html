スキーマを生成

  1. SQLite データベースを開きます。
  2. ER 図でエンティティを確認します。
  3. エクスポート形式として GraphQL SDL を選びます。
  4. 型定義をエクスポートし、API プロジェクトで確認します。
type Customer {
  id: Int!
  name: String
  orders: [Order!]
}

type Order {
  id: Int!
  customerId: Int!
}

SDL は完全な API ではありません

データベーススキーマはストレージを記述し、GraphQL はアプリケーション向けの契約を記述します。生成された SDL は、リゾルバー、認証、ページネーション、バリデーション、ミューテーション、フィールド単位の認可を作成しません。構造化された最初の下書きとして扱ってください。

型のマッピングを確認

SQLite の型は GraphQL のスカラーと完全には対応しません。日付はテキストや数値で保存されていることがあり、小数にはカスタムスカラーが必要な場合があり、バイナリデータにはアプリケーション固有の表現が必要です。より分かりやすい API 名が適切な場合は、技術的なデータベースのフィールド名を変更してください。

すべてのデータベーステーブルを自動的に公開しないでください。クライアントがアクセスすべきフィールドと操作だけを選び、API 層で認可を適用してください。

関係は意図的に使う

宣言された外部キーは GraphQL の関係を示唆しますが、リゾルバーの動作はサーバーの実装に依存します。コストの高い入れ子のデータベースアクセスを避けるために、バッチ処理とページネーションを検討してください。
