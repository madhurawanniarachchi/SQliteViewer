スキーマの可視化

SQLite から ER 図を生成

見慣れないデータベースを、テーブル、列、型、主キー、外部キーのつながりが分かる読みやすい地図に変えます。

ER 図ツールを開く

図を作成する

  1. ビューアで SQLite データベースを開きます。
  2. テーブルのサイドバーで ER 図 を選びます。
  3. 全体表示を使うと、すべてのエンティティがダイアログの表示範囲に収まります。
  4. 各エンティティの列名、SQLite のデータ型、キーのマークを確認します。

リレーションの線は、SQLite で宣言された外部キーから作られます。論理的な関係が外部キー制約で定義されていない場合、スキーマリーダーは列名だけでは確実に判別できません。

結果の読み方

  • PK は、行を一意に特定するための主キー列を示します。
  • FK は、別のテーブルのキーを参照する列を示します。
  • 列の型は、宣言された SQLite の型を表示します。SQLite の型システムは柔軟なため、保存された値が宣言と異なる場合もあります。
  • 接続線は、参照される側と参照する側のエンティティを示します。
図は、データベースが主キーと外部キーを一貫して宣言しているときに最も役立ちます。線が欠けている場合は、表示の問題ではなく制約が不足していることが多いです。

スキーマをエクスポート

図を確認したら、スキーマを SQL DDL、DBML、Mermaid、GraphQL SDL でエクスポートできます。SQL DDL は元のデータベース定義に最も近い形式です。DBML と Mermaid はドキュメント作成に便利です。GraphQL SDL は API モデルの出発点で、アプリケーションに合わせた調整が必要な場合があります。

確認に役立つ質問

主キーのないテーブル、想定外のエンティティを指す外部キー、一貫性のない命名、必須にすべき NULL 許可の列、多対多の関係を表す中間テーブルを探しましょう。アプリケーションのデータベースを引き継ぐときや移行を計画するときに役立ちます。
