はじめに

SQLite ファイルをオンラインで安全に開く方法

デスクトップソフトをインストールせず、ファイルをリモートサーバーに送らずに、ローカルの SQLite データベースをブラウザで確認します。

SQLite Viewer を開く

3 ステップでデータベースを開く

  1. 最新のデスクトップブラウザーで SQLite Viewer を開きます。
  2. データベースを開始カードにドロップするか、カードをクリックして .db、.sqlite、.sqlite3、.db3 ファイルを選択します。
  3. サイドバーでテーブルを選びます。ビューアがクエリタブを作成し、最初のページの行を表示します。
プライバシー: ファイルはブラウザの JavaScript によってローカルで読み込まれます。テーブルの確認、SQL の実行、ER 図の生成にアップロードは不要です。

確認できること

テーブル一覧から、テーブルやビューにすばやくアクセスできます。長いスキーマの検索、複数の指標によるテーブルの並べ替え、列情報の確認、表示する列の制御、幅の広い結果を見るときの列の固定ができます。

より詳しい作業にはSQLエディタを使います。基本的なクエリは次のとおりです。

SELECT *
FROM "customers"
LIMIT 0, 30;

ファイルが開かないとき

  • SQL テキストのダンプではなく、本物の SQLite データベースであることを確認してください。
  • 一般的でない拡張子は .db にリネームすると、ファイル選択に表示されます。
  • ファイルが暗号化されていないか確認してください。暗号化されたデータベースには対応する拡張機能やキーが必要で、通常の SQLite としては読めません。
  • 非常に大きなファイルの場合は、メモリを多く使うブラウザタブを閉じてからもう一度試してください。

調査結果を保存またはエクスポート

クエリ結果は一般的な形式でエクスポートできます。行を編集したり書き込み文を実行した場合は、DB を保存で現在のデータベースをダウンロードしてください。元のローカルファイルが黙って上書きされることはありません。
