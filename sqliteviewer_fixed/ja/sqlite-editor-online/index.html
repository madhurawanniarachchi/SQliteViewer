ブラウザ上のデータベースエディタ

SQLite データベースをオンラインで編集

デスクトップ版 SQLite エディタをインストールせずに、テーブルの行を更新し、SQL の書き込み文を実行し、最新のデータベースをダウンロードできます。

SQLite エディタを開く

主キーで保護された行の編集

データベースを開いてテーブルを選びます。テーブルに使用可能な主キーがある場合、結果に個々の行を編集・削除する操作が表示されます。エディタは画面上の位置ではなく主キーの値を使って対象の行を特定します。

  1. 行の編集を選びます。
  2. 必要なフィールドの値を変更します。列が許可している場合は NULL のオプションを使えます。
  3. 行を保存し、更新された結果を確認します。
  4. 完了したらDB を保存を選んでデータベースをダウンロードします。
重要: 変更はブラウザのメモリ上にあるデータベースに対して行われ、元のファイルを自動的に上書きすることはありません。ページを閉じる前に最新のデータベースをダウンロードしてください。

SQL で一括変更

クエリワークスペースは SQLite の書き込み文にも対応しています。例:

UPDATE "products"
SET "active" = 0
WHERE "last_order_at" < '2025-01-01';

更新や削除を実行する前に WHERE 条件を慎重に確認してください。まず同じ条件を SELECT として実行し、対象の行を確認してから書き込みクエリを実行するのが良い手順です。

行を編集できない原因

安全な行操作では、ビューアがレコードを確実に特定できる必要があります。主キーのないテーブルは、行のインターフェイスで読み取り専用になることがあります。ビュー、計算結果、結合、集計クエリは、通常は単一の元の行に安全に対応付けられませんが、確認やエクスポートは可能です。

完成したデータベースをダウンロード

「DB を保存」は、成功した行の編集や書き込みクエリを含む、現在の SQLite データベースの状態をエクスポートします。ダウンロードしたファイルを実際に使うアプリケーションで確認するまで、元のファイルをバックアップとして保管してください。
