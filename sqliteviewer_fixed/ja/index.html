ブラウザで使えるプライベートなデータベース作業環境

データをアップロードせずに SQLite ファイルを確認・編集

SQLite Viewer はブラウザ上で直接動作します。ローカルの .db、.sqlite、.sqlite3、.db3 ファイルを開き、スキーマや行を確認し、SQL を実行し、変更を加えて最新のデータベースをダウンロードできます。ファイルをサーバーに送信することはありません。

テーブルの閲覧と検索

大規模なスキーマも楽にたどれます。テーブル一覧を名前、行数、セル数、推定サイズで並べ替え、重要な結果列を固定できます。

実際のデータベースの行を編集

主キーに対応した操作で行の追加・更新・削除ができます。変更はダウンロードするまでブラウザ内のデータベースに保持されます。

マルチタブの SQL ワークスペース

テーブルやクエリごとに新しいタブを開き、複数のデータベースを切り替え、各結果を元のクエリと関連付けたまま扱えます。

ER 図を生成

エンティティ、列、データ型、主キー、外部キーの関係を可視化し、図をウィンドウに合わせて表示できます。

スキーマと結果をエクスポート

ER スキーマを SQL DDL、DBML、Mermaid、GraphQL SDL で、クエリ結果を一般的なデータ形式でエクスポートできます。

変更した SQLite ファイルを保存

変更はローカルで適用されます。「DB を保存」を選ぶと、現在のデータベースを使える SQLite ファイルとしてダウンロードできます。

使い方

データベースファイルから役立つ答えまで 3 ステップ

  1. データベースを開く。対応する SQLite ファイルをページにドロップするか、ファイル選択を使います。
  2. 調べる・クエリする。テーブルを選び、列を確認し、行を編集するか、自分の SQL を実行します。
  3. 必要なものをエクスポート。結果、スキーマ定義、または変更後のデータベース全体をダウンロードします。

SQLite の実用ガイド

ワークフローを学ぶか、専用ツールを開く

SQLite ファイルをオンラインで開く方法安全な、手順どおりのブラウザ作業フロー。 オンライン SQLite エディタ行を編集して、変更したデータベースを保存します。 SQLite ER 図ジェネレーターテーブル、キー、関係を理解します。 SQLite を CSV に変換任意のテーブルやクエリ結果を CSV でエクスポートします。 SQLite を JSON に変換行をオブジェクトの JSON 配列として取得します。 SQLite を Excel に変換データから XLSX ブックを作成します。 SQLite を SQL DDL に変換持ち運び可能なスキーマ定義をエクスポートします。 SQLite を DBML に変換スキーマをデータベース設計ツールに取り込みます。 SQLite を Mermaid に変換テキストベースの ER 図を作成します。 SQLite を GraphQL SDL に変換役立つ GraphQL スキーマの出発点を生成します。 Android の SQLite データベースを表示エクスポートしたアプリのデータベースを安全に確認します。 インストール不要の SQLite ブラウザローカルのブラウザツールが適している場面を知ります。 Android アプリのデータベースをライブ編集実行中のデバッグアプリの行をブラウザから変更します。 便利な SQLite クエリテーブル、キー、重複、クエリプランを確認します。

よくある質問

SQLite Viewer の FAQ

SQLite データベースはアップロードされますか？

いいえ。データベースはブラウザ内の JavaScript によってローカルで開かれ処理されます。確認のためにファイルをアップロードする必要はありません。

SQLite データベースを編集して保存できますか？

はい。対応するテーブルの行を編集するか書き込みクエリを実行し、「DB を保存」で最新の状態をダウンロードできます。

どの SQLite ファイル拡張子に対応していますか？

ファイル選択では .db、.sqlite、.sqlite3、.db3 を受け付けます。有効な SQLite データベースが別の拡張子の場合は、選択前に名前の変更が必要なことがあります。

大きなデータベースでも使えますか？

大きなファイルはブラウザの利用可能なメモリに左右されます。ビューアは表示する結果行を制限し、負荷の高いテーブルのメタデータをサンプリングして快適さを保ちます。
