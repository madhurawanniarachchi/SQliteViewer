SQLite を Excel (XLSX) に変換

任意のテーブルやクエリ結果から、レポート、共有、さらなる分析に使える Excel ブックを作成します。

Excel にエクスポート

SQLite のテーブルを Excel にエクスポート

  1. .db、.sqlite、.sqlite3、.db3 のファイルを SQLite Viewer で開きます。ファイルはブラウザ内に留まります。
  2. テーブルを選ぶか、必要な行だけを返すクエリを書きます。
  3. 結果の上にあるエクスポートをクリックし、含める列を選びます。
  4. Excel を選ぶと、ファイルがすぐにダウンロードされます。

エクスポート前に SQL を活用

まず SQL でテーブルの絞り込み、並べ替え、集計、結合を行い、その結果をエクスポートします。Excel には選択した行と列がそのまま渡され、テーブル名がシート名になります。

Excel エクスポートはスプレッドシートライブラリを必要に応じて読み込むため、初回のエクスポートにはインターネット接続が必要です。データベース自体がブラウザの外に出ることはありません。

データがお使いのデバイスの外に出ることはありません

変換はブラウザのタブ内で JavaScript として実行されます。データベースはサーバーにアップロードされないため、顧客データ、アプリのデータベース、社内ファイルでも安心して使えます。

Excel からのインポートも可能

SQLite Viewer は .xlsx や .xls ファイルを新しい SQLite データベースにインポートすることもでき、スプレッドシートを SQL で検索できます。プレーンテキスト形式が良い場合は CSV や JSON をお試しください。
