デスクトップ版 SQLite アプリが使えない、または必要ないときに、最新のブラウザですばやくデータベースを確認できます。

SQLite ブラウザを開く

ブラウザツールが役立つ場面

Web ベースのビューアは、一度きりのデータベース確認、サポート業務、授業の演習、エクスポートしたアプリのデータベース、ソフトをインストールできない環境に便利です。アプリは Web から読み込まれますが、選択したデータベースはブラウザ内でローカルに処理されます。

インストールなしで使える機能

  • テーブルやビューの検索と閲覧。
  • SELECT 文の実行とページ分割された結果の確認。
  • 複数のクエリタブとデータベースタブの利用。
  • 安全に特定できる行の追加、編集、削除。
  • 列、型、キーを含む ER 図の生成。
  • 結果やスキーマ形式のエクスポート。
  • 変更後の現在のデータベースのダウンロード。

ブラウザツールかデスクトップアプリか

非常に大きなデータベース、暗号化拡張機能、継続的な本番運用の管理、高度なインデックス分析、ファイルシステムの直接ロックには、引き続きデスクトップアプリが適しています。通常の SQLite ファイルで、速さ、持ち運びやすさ、ローカル処理を重視するなら、ブラウザツールが最も力を発揮します。

データベースはブラウザのメモリ上にあるため、ページを閉じたり更新したりする前に、元のファイルを保管し、変更をダウンロードしてください。

プライバシーに関する注意

ページが HTTPS で配信されていることを確認し、信頼できるアプリのコピーを使用してください。SQLite Viewer はデータベースのアップロードを必要としませんが、ブラウザ拡張機能やデバイス自体もセキュリティ環境の一部です。
