SQLite を CSV に変換

テーブルや任意の SQL クエリの結果を、Excel や Google スプレッドシートで開ける、または別のデータベースにインポートできる CSV ファイルにします。

CSV にエクスポート

SQLite のテーブルを CSV にエクスポート

  1. .db、.sqlite、.sqlite3、.db3 のファイルを SQLite Viewer で開きます。ファイルはブラウザ内に留まります。
  2. テーブルを選ぶか、必要な行だけを返すクエリを書きます。
  3. 結果の上にあるエクスポートをクリックし、含める列を選びます。
  4. CSV を選ぶと、ファイルがすぐにダウンロードされます。

必要なものだけをエクスポート

エクスポートは現在のクエリに従うため、WHERE での絞り込み、テーブルの結合、並べ替え、行数の制限をしてから、その結果をそのままエクスポートできます。列ピッカーで、ファイルに含めたくない列を除外することもできます。

ヒント: テーブル全体をエクスポートするには、テーブルを選び、エクスポートをクリックする前にクエリから LIMIT を削除してください。

データがお使いのデバイスの外に出ることはありません

変換はブラウザのタブ内で JavaScript として実行されます。データベースはサーバーにアップロードされないため、顧客データ、アプリのデータベース、社内ファイルでも安心して使えます。

CSV を使う場面

CSV は、スプレッドシート、BI ツール、一括インポートに最も適した持ち運びやすい形式です。型付きの値や入れ子のデータが必要な場合は JSON を、書式付きのブックが必要な場合は Excel を使ってください。
