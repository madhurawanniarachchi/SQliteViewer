データベースはブラウザ内に留まります

SQLite Viewer は、選択されたデータベースファイルの内容をサーバー側で処理するためにアップロードするのではなく、ユーザーのデバイス上で開いて処理するよう設計されています。

ローカルでのデータベース処理

SQLite ファイルを選択すると、ブラウザの JavaScript がそれをローカルメモリに読み込みます。テーブルの閲覧、SQL の実行、行の編集、スキーマの確認、データベースのエクスポートは、ブラウザのセッション内で行われます。これらの機能を提供するために、アプリケーションが選択したデータベースファイルをサーバーに送信する必要はありません。

Web サイトが受け取る可能性のある情報

多くの Web サイトと同様に、ホスティング基盤は IP アドレス、ブラウザの種類、要求されたページ、タイムスタンプ、エラーログなどの通常のリクエスト情報を受け取ることがあります。サイトではページ訪問や全体的な利用状況を把握するために分析ツールを使用する場合があります。データベースのファイル名、テーブルの内容、SQL クエリのテキストは、意図的に分析イベントとして送信されるべきではありません。

ブラウザのストレージ

アプリケーションは、クエリタブやクエリ履歴など、ローカルの設定やワークスペース情報のためにブラウザのストレージを使用することがあります。この情報は、ユーザーまたはブラウザが消去するまで、ブラウザプロファイルに関連付けられたままになります。

ダウンロードと元のファイル

編集はメモリ上のデータベースに対して行われます。「DB を保存」は現在の状態のダウンロードを作成します。アプリケーションがディスク上の元のデータベースファイルを黙って置き換えることはありません。

お客様の責任

アクセス権限のあるデータベースを使用してください。機密性の高いファイルを開く際は、デバイス、ブラウザプロファイル、インストール済みの拡張機能のセキュリティを考慮してください。共有デバイスで作業する場合は、ブラウザのストレージとダウンロードしたコピーを消去してください。

サードパーティのリソース

ページは、サードパーティのサービスからライブラリ、分析ツール、その他の Web サイトリソースを読み込むことがあります。これらのサービスは通常の Web リクエストデータを受け取る場合がありますが、選択したデータベースがそれらのリクエストに意図的に含まれることはありません。

極めて機密性の高い、または規制対象のデータについては、組織が承認した環境とブラウザ設定を使用し、使用前に展開されたアプリケーションのネットワーク動作を確認してください。
