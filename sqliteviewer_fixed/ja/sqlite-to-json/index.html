SQLite を JSON に変換

行をオブジェクトの JSON 配列としてエクスポートします。API、フロントエンドのプロトタイプ、テストデータ、ドキュメント DB にそのまま使えます。

JSON にエクスポート

SQLite のテーブルを JSON にエクスポート

  1. .db、.sqlite、.sqlite3、.db3 のファイルを SQLite Viewer で開きます。ファイルはブラウザ内に留まります。
  2. テーブルを選ぶか、必要な行だけを返すクエリを書きます。
  3. 結果の上にあるエクスポートをクリックし、含める列を選びます。
  4. JSON を選ぶと、ファイルがすぐにダウンロードされます。

JSON の形式

各行は列名をキーとするオブジェクトになり、ファイルはそれらのオブジェクトの配列になります。

[
  { "id": 1, "name": "Ada", "email": "ada@example.com" },
  { "id": 2, "name": "Linus", "email": "linus@example.com" }
]

SQL で出力を整える

エクスポート前にクエリで AS による列名の変更、関連テーブルの結合、行の絞り込みを行うと、JSON をアプリケーションが期待する構造に合わせられます。

データがお使いのデバイスの外に出ることはありません

変換はブラウザのタブ内で JavaScript として実行されます。データベースはサーバーにアップロードされないため、顧客データ、アプリのデータベース、社内ファイルでも安心して使えます。
