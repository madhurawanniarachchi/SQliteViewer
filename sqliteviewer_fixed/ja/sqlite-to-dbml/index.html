SQLite を DBML に変換

既存の SQLite スキーマを、ドキュメントやデータベース設計のワークフローに使える読みやすい DBML に変換します。

DBML エクスポーターを開く

SQLite ファイルから DBML を生成

  1. SQLite Viewer でデータベースを開きます。
  2. ER 図を選びます。
  3. エクスポート形式の一覧で DBML を選びます。
  4. 生成されたテキストをエクスポートし、お好みの DBML ツールで確認します。

変換に含まれるもの

エクスポートには、テーブル、列名、宣言された SQLite のデータ型、主キー、宣言された外部キーの関係が含まれます。テーブルの行を公開することなく、設計ツールが有用なモデルを描画できるだけの構造を提供します。

Table orders {
  id integer [pk]
  customer_id integer [not null]
  created_at text
}

Ref: orders.customer_id > customers.id

なぜ DBML を使うのか

DBML はデータベースのバイナリより確認しやすく、実行可能な SQL よりもデータモデリングに特化しています。チームはスキーマの議論、図の作成、関係の文書化、マイグレーションを書く前の変更計画に利用しています。

DBML は設計上の表現であり、バイト単位のデータベースバックアップではありません。元の SQLite ファイルを保管し、データを含む動作するデータベースが必要なときは「DB を保存」を使ってください。

生成されたモデルを確認

SQLite は柔軟な型宣言を許容し、スキーマに外部キーが含まれないこともあります。カスタム型、複合制約、生成列、インデックス、アプリケーションコードにのみ存在する関係を確認してください。必要に応じて、エクスポート後に設計レベルの注釈を追加します。
