スキーマのエクスポート

SQLite スキーマを SQL DDL に変換

ドキュメント、レビュー、移行計画、バージョン管理のために、読みやすいスキーマ定義を取り出します。

SQLite スキーマエクスポーターを開く

データベースファイルから SQL DDL をエクスポート

  1. SQLite データベースを開きます。
  2. ER 図を開きます。
  3. エクスポート形式として SQL DDL を選びます。
  4. 生成されたスキーマのテキストをエクスポートして保存します。

結果はテーブルのデータではなく、データベースの構造を表します。エンティティ定義、宣言された列の型、SQLite のスキーマメタデータから推測できるキー情報が含まれます。

出力例

CREATE TABLE "orders" (
  "id" INTEGER PRIMARY KEY,
  "customer_id" INTEGER NOT NULL,
  "created_at" TEXT,
  FOREIGN KEY ("customer_id") REFERENCES "customers" ("id")
);

SQL DDL が役立つ場面

  • コードレビューでデータベーススキーマを確認する。
  • 構造の変更をバージョン管理に残す。
  • 本番の行を公開せずにテーブルをドキュメント化する。
  • 別のデータベースシステムへの移行を準備する。
  • 想定と実際のテーブル定義を比較する。
移行に関する注意: SQLite の構文や型アフィニティは PostgreSQL、MySQL、SQL Server とは異なります。エクスポートした DDL は SQLite スキーマの信頼できる記述として扱い、移行先のエンジンに合わせて型、自動採番の動作、引用符、制約を調整してください。

スキーマのエクスポートとデータベースの保存の違い

SQL DDL には構造のみが含まれます。行とローカルでの編集を含むデータベースが必要な場合はDB を保存を使ってください。行をポータブルなテキスト形式で取り出したい場合は、結果のエクスポート機能を使います。
