SQLite in CSV umwandeln

Machen Sie aus einer Tabelle oder dem Ergebnis einer beliebigen SQL-Abfrage eine CSV-Datei, die Sie in Excel oder Google Tabellen öffnen oder in eine andere Datenbank importieren können.

Als CSV exportieren

Eine SQLite-Tabelle als CSV exportieren

  1. Öffnen Sie Ihre .db-, .sqlite-, .sqlite3- oder .db3-Datei in SQLite Viewer. Sie bleibt in Ihrem Browser.
  2. Wählen Sie eine Tabelle oder schreiben Sie eine Abfrage, die genau die benötigten Zeilen liefert.
  3. Klicken Sie über den Ergebnissen auf Exportieren und wählen Sie die gewünschten Spalten.
  4. Wählen Sie CSV, und die Datei wird sofort heruntergeladen.

Exportieren Sie nur, was Sie brauchen

Da der Export der aktuellen Abfrage folgt, können Sie zuerst mit WHERE filtern, Tabellen verknüpfen, sortieren oder Zeilen begrenzen und dann genau dieses Ergebnis exportieren. Mit der Spaltenauswahl lassen Sie unerwünschte Spalten weg.

Tipp: Um eine ganze Tabelle zu exportieren, wählen Sie sie aus und entfernen Sie vor dem Klick auf Exportieren jedes LIMIT aus der Abfrage.

Ihre Daten verlassen nie Ihr Gerät

Die Konvertierung läuft als JavaScript in Ihrem Browser-Tab. Die Datenbank wird nicht auf einen Server hochgeladen und kann daher bedenkenlos mit Kundendaten, App-Datenbanken und internen Dateien verwendet werden.

Wann CSV sinnvoll ist

CSV ist das portabelste Format für Tabellenkalkulationen, BI-Tools und Massenimporte. Wenn Sie typisierte Werte oder verschachtelte Daten brauchen, nutzen Sie JSON; für eine formatierte Arbeitsmappe Excel.
