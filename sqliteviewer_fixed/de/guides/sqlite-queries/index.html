SQLite-Abfrageleitfaden

Nützliche Abfragen zur Prüfung von SQLite-Datenbanken

Beginnen Sie mit sicherem, gezieltem SQL, wenn Sie Tabellen, Indizes, Beziehungen und Datenqualität verstehen möchten.

SQL-Arbeitsbereich öffnen

Benutzertabellen und Views auflisten

SELECT type, name, sql
FROM sqlite_master
WHERE type IN ('table', 'view')
  AND name NOT LIKE 'sqlite_%'
ORDER BY type, name;

Die Spalten einer Tabelle prüfen

PRAGMA table_info('orders');

Dies liefert für jede Spalte den deklarierten Typ, die Nullbarkeit, den Standardwert und die Position im Primärschlüssel.

Fremdschlüssel prüfen

PRAGMA foreign_key_list('orders');
PRAGMA foreign_key_check;

Die erste Anweisung beschreibt die deklarierten Verweise einer Tabelle. Die zweite meldet Zeilen, die aktivierte Fremdschlüsselbeziehungen verletzen.

Doppelte Werte finden

SELECT email, COUNT(*) AS occurrences
FROM customers
WHERE email IS NOT NULL
GROUP BY email
HAVING COUNT(*) > 1
ORDER BY occurrences DESC;

Indizes prüfen

PRAGMA index_list('orders');

Wenn Sie einen Indexnamen gefunden haben, prüfen Sie dessen Spalten mit PRAGMA index_info('index_name').

Das Abfrageverhalten prüfen

EXPLAIN QUERY PLAN
SELECT *
FROM orders
WHERE customer_id = 42
ORDER BY created_at DESC;

Der Plan kann vollständige Tabellenscans zeigen und ob SQLite einen passenden Index verwenden kann.

Sicherer Ablauf: Beginnen Sie mit SELECT- oder PRAGMA-Prüfabfragen. Führen Sie vor UPDATE oder DELETE ein SELECT mit derselben WHERE-Bedingung aus und bewahren Sie eine Originalkopie der Datenbank auf.

Große Tabellen seitenweise durchgehen

SELECT *
FROM events
ORDER BY id
LIMIT 100 OFFSET 0;

Beim wiederholten Navigieren durch sehr große Tabellen ist Keyset-Paginierung wie WHERE id > ? ORDER BY id LIMIT 100 oft effizienter als ein sehr großer Offset.
