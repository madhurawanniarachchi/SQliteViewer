Ein SQLite-Schema in SQL DDL umwandeln

Extrahieren Sie lesbare Schemadefinitionen für Dokumentation, Review, Migrationsplanung oder Versionsverwaltung.

SQLite-Schema-Exporter öffnen

SQL DDL aus einer Datenbankdatei exportieren

  1. Öffnen Sie die SQLite-Datenbank.
  2. Öffnen Sie das ER-Diagramm.
  3. Wählen Sie SQL DDL als Exportformat.
  4. Exportieren und speichern Sie den erzeugten Schematext.

Das Ergebnis beschreibt die Datenbankstruktur, nicht die Tabellendaten. Es enthält Entitätsdefinitionen, deklarierte Spaltentypen und Schlüsselinformationen, die sich aus den SQLite-Schema-Metadaten ableiten lassen.

Beispielausgabe

CREATE TABLE "orders" (
  "id" INTEGER PRIMARY KEY,
  "customer_id" INTEGER NOT NULL,
  "created_at" TEXT,
  FOREIGN KEY ("customer_id") REFERENCES "customers" ("id")
);

Wofür SQL DDL nützlich ist

  • Ein Datenbankschema im Code-Review prüfen.
  • Strukturänderungen in der Versionsverwaltung festhalten.
  • Tabellen dokumentieren, ohne Produktivdaten offenzulegen.
  • Eine Migration auf ein anderes Datenbanksystem vorbereiten.
  • Erwartete und tatsächliche Tabellendefinitionen vergleichen.
Hinweis zur Migration: Syntax und Typaffinität von SQLite unterscheiden sich von PostgreSQL, MySQL und SQL Server. Betrachten Sie das exportierte DDL als verlässliche Beschreibung des SQLite-Schemas und passen Sie Typen, Auto-Increment-Verhalten, Quoting und Einschränkungen an die Ziel-Engine an.

Schema-Export oder Datenbank speichern

SQL DDL enthält nur die Struktur. Wenn Sie die Datenbank mit ihren Zeilen und lokalen Änderungen benötigen, nutzen Sie DB speichern. Wenn Sie Zeilen in einem portablen Textformat brauchen, verwenden Sie stattdessen den Export der Ergebnisse.
