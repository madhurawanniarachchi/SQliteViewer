Nach Excel exportieren

Eine SQLite-Tabelle nach Excel exportieren

  1. Öffnen Sie Ihre .db-, .sqlite-, .sqlite3- oder .db3-Datei in SQLite Viewer. Sie bleibt in Ihrem Browser.
  2. Wählen Sie eine Tabelle oder schreiben Sie eine Abfrage, die genau die benötigten Zeilen liefert.
  3. Klicken Sie über den Ergebnissen auf Exportieren und wählen Sie die gewünschten Spalten.
  4. Wählen Sie Excel, und die Datei wird sofort heruntergeladen.

Vor dem Export SQL nutzen

Filtern, sortieren, aggregieren oder verknüpfen Sie Tabellen zuerst mit SQL und exportieren Sie dann das Ergebnis. Excel erhält genau die gewählten Zeilen und Spalten, der Tabellenname dient als Blattname.

Der Excel-Export lädt seine Tabellenkalkulationsbibliothek bei Bedarf nach, daher benötigt der erste Excel-Export eine Internetverbindung. Ihre Datenbank verlässt den Browser dennoch nie.

Ihre Daten verlassen nie Ihr Gerät

Die Konvertierung läuft als JavaScript in Ihrem Browser-Tab. Die Datenbank wird nicht auf einen Server hochgeladen und kann daher bedenkenlos mit Kundendaten, App-Datenbanken und internen Dateien verwendet werden.

Auch aus Excel importieren

SQLite Viewer kann auch eine .xlsx- oder .xls-Datei in eine neue SQLite-Datenbank importieren, sodass Sie eine Tabelle mit SQL abfragen können. Lieber ein Klartextformat? Probieren Sie CSV oder JSON.
