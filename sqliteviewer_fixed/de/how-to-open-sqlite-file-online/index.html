So öffnen Sie eine SQLite-Datei online sicher

Prüfen Sie eine lokale SQLite-Datenbank im Browser, ohne Desktop-Software zu installieren oder die Datei an einen entfernten Server zu senden.

SQLite Viewer öffnen

Datenbank in drei Schritten öffnen

  1. Öffnen Sie SQLite Viewer in einem modernen Desktop-Browser.
  2. Ziehen Sie Ihre Datenbank auf die Startkarte oder klicken Sie darauf und wählen Sie eine .db-, .sqlite-, .sqlite3- oder .db3-Datei.
  3. Wählen Sie in der Seitenleiste eine Tabelle. Der Viewer erstellt einen Abfrage-Tab und zeigt die erste Seite mit Zeilen an.
Datenschutz: Die Datei wird lokal von Browser-JavaScript gelesen. Zum Prüfen von Tabellen, Ausführen von SQL oder Erzeugen eines ER-Diagramms muss sie nicht hochgeladen werden.

Was Sie prüfen können

Die Tabellenliste bietet schnellen Zugriff auf Tabellen und Views. Sie können lange Schemata durchsuchen, Tabellen nach mehreren Kriterien sortieren, Spalteninformationen ansehen, sichtbare Spalten steuern und Spalten beim Prüfen breiter Ergebnismengen fixieren.

Für detailliertere Arbeit nutzen Sie den SQL-Editor. Eine einfache Abfrage sieht so aus:

SELECT *
FROM "customers"
LIMIT 0, 30;

Wenn sich die Datei nicht öffnen lässt

  • Vergewissern Sie sich, dass es eine echte SQLite-Datenbank und kein SQL-Textdump ist.
  • Benennen Sie eine ungewöhnliche Endung in .db um, damit sie in der Dateiauswahl erscheint.
  • Prüfen Sie, ob die Datei verschlüsselt ist; eine verschlüsselte Datenbank benötigt die passende Erweiterung oder den Schlüssel und lässt sich nicht als normales SQLite lesen.
  • Schließen Sie bei sehr großen Dateien speicherintensive Browser-Tabs, bevor Sie es erneut versuchen.

Ergebnisse speichern oder exportieren

Abfrageergebnisse lassen sich in gängigen Formaten exportieren. Wenn Sie Zeilen bearbeiten oder Schreibanweisungen ausführen, laden Sie die aktuelle Datenbank mit DB speichern herunter. Die lokale Originaldatei wird nicht stillschweigend überschrieben.
