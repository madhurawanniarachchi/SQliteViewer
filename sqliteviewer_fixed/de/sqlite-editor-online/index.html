Eine SQLite-Datenbank online bearbeiten

Aktualisieren Sie Tabellenzeilen, führen Sie SQL-Schreibanweisungen aus und laden Sie die neueste Datenbank herunter, ohne einen SQLite-Desktop-Editor zu installieren.

Zeilen mit Primärschlüssel-Schutz bearbeiten

Öffnen Sie eine Datenbank und wählen Sie eine Tabelle. Hat die Tabelle einen nutzbaren Primärschlüssel, enthält das Ergebnis Aktionen zum Bearbeiten und Löschen einzelner Zeilen. Der Editor verwendet die Primärschlüsselwerte, um die gemeinte Zeile gezielt anzusprechen, statt sich auf ihre sichtbare Position zu verlassen.

  1. Wählen Sie bei der Zeile Bearbeiten.
  2. Ändern Sie die gewünschten Feldwerte. Nutzen Sie die Null-Option, wenn die Spalte sie zulässt.
  3. Speichern Sie die Zeile und prüfen Sie das aktualisierte Ergebnis.
  4. Wählen Sie zum Abschluss DB speichern, um die Datenbank herunterzuladen.
Wichtig: Änderungen werden an der im Browserspeicher gehaltenen Datenbank vorgenommen. Sie überschreiben die Originaldatei nicht automatisch. Laden Sie die neueste Datenbank herunter, bevor Sie die Seite schließen.

SQL für Massenänderungen nutzen

Der Abfragebereich unterstützt auch SQLite-Schreibanweisungen. Zum Beispiel:

UPDATE "products"
SET "active" = 0
WHERE "last_order_at" < '2025-01-01';

Prüfen Sie die WHERE-Bedingung sorgfältig, bevor Sie ein Update oder Delete ausführen. Ein guter Ablauf: dieselbe Bedingung zuerst als SELECT ausführen, die betroffenen Zeilen bestätigen und erst dann die Schreibabfrage ausführen.

Was die Zeilenbearbeitung verhindern kann

Sichere Zeilenaktionen setzen voraus, dass der Viewer Datensätze zuverlässig identifizieren kann. Tabellen ohne Primärschlüssel werden in der Zeilenoberfläche eventuell schreibgeschützt angezeigt. Views, berechnete Ergebnisse, Joins und Aggregatabfragen lassen sich in der Regel nicht sicher einer einzelnen Quellzeile zuordnen, Sie können sie aber weiterhin ansehen oder exportieren.

Die fertige Datenbank herunterladen

Die Aktion „DB speichern“ exportiert den aktuellen Zustand der SQLite-Datenbank einschließlich erfolgreicher Zeilenbearbeitungen und Schreibabfragen. Bewahren Sie das Original als Backup auf, bis Sie die heruntergeladene Datei in der Anwendung getestet haben, die sie verwendet.
