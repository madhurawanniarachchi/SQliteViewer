ER-Diagramm aus SQLite erzeugen

Verwandeln Sie eine unbekannte Datenbank in eine lesbare Karte aus Tabellen, Spalten, Typen, Primärschlüsseln und Fremdschlüsselverbindungen.

ER-Diagramm-Tool öffnen

Das Diagramm erstellen

  1. Öffnen Sie die SQLite-Datenbank im Viewer.
  2. Wählen Sie in der Tabellen-Seitenleiste ER-Diagramm.
  3. Mit Einpassen bringen Sie alle Entitäten in den sichtbaren Bereich des Dialogs.
  4. Prüfen Sie Spaltennamen, SQLite-Datentypen und Schlüsselmarkierungen jeder Entität.

Die Beziehungslinien werden aus den in SQLite deklarierten Fremdschlüsseln abgeleitet. Ist eine logische Beziehung nicht durch eine Fremdschlüssel-Einschränkung definiert, kann ein Schema-Leser sie allein anhand der Spaltennamen nicht zuverlässig erkennen.

So lesen Sie das Ergebnis

  • PK kennzeichnet eine Primärschlüsselspalte, mit der eine Zeile eindeutig adressiert wird.
  • FK kennzeichnet eine Spalte, die auf einen Schlüssel in einer anderen Tabelle verweist.
  • Die Spaltentypen zeigen den deklarierten SQLite-Typ. Wegen des flexiblen Typsystems von SQLite können gespeicherte Werte manchmal von dieser Deklaration abweichen.
  • Verbindungslinien zeigen die referenzierten und die referenzierenden Entitäten.
Ein Diagramm ist am nützlichsten, wenn die Datenbank Primär- und Fremdschlüssel konsistent deklariert. Fehlende Linien weisen oft auf fehlende Einschränkungen hin, nicht auf ein Darstellungsproblem.

Das Schema exportieren

Exportieren Sie das Schema nach der Prüfung des Diagramms als SQL DDL, DBML, Mermaid oder GraphQL SDL. SQL DDL kommt der ursprünglichen Datenbankdefinition am nächsten. DBML und Mermaid eignen sich für die Dokumentation. GraphQL SDL ist ein Ausgangspunkt für ein API-Modell und muss ggf. anwendungsspezifisch angepasst werden.

Nützliche Prüffragen

Achten Sie auf Tabellen ohne Primärschlüssel, Fremdschlüssel, die auf unerwartete Entitäten zeigen, uneinheitliche Benennung, nullbare Spalten, die Pflichtfelder sein sollten, und Verknüpfungstabellen für n:m-Beziehungen. Diese Prüfungen helfen, wenn Sie die Datenbank einer Anwendung übernehmen oder eine Migration planen.
