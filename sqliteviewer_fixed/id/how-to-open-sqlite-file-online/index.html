Cara membuka file SQLite online dengan aman

Periksa database SQLite lokal di browser tanpa memasang perangkat lunak desktop atau mengirim file ke server jarak jauh.

Buka SQLite Viewer

Buka database Anda dalam tiga langkah

  1. Buka SQLite Viewer di browser desktop modern.
  2. Letakkan database Anda pada kartu pembuka, atau klik kartu tersebut dan pilih file .db, .sqlite, .sqlite3, atau .db3.
  3. Pilih tabel di sidebar. Penampil membuat tab kueri dan menampilkan halaman pertama baris.
Privasi: file dibaca secara lokal oleh JavaScript browser. File tidak perlu diunggah untuk memeriksa tabel, menjalankan SQL, atau membuat diagram ER.

Apa yang dapat Anda periksa

Daftar tabel memberi akses cepat ke tabel dan view. Anda dapat mencari di skema yang panjang, mengurutkan tabel berdasarkan beberapa ukuran, memeriksa informasi kolom, mengatur kolom yang terlihat, dan menyematkan kolom saat meninjau hasil yang lebar.

Untuk pekerjaan yang lebih rinci, gunakan editor SQL. Kueri dasar terlihat seperti ini:

SELECT *
FROM "customers"
LIMIT 0, 30;

Jika file tidak mau terbuka

  • Pastikan itu benar-benar database SQLite, bukan dump teks SQL.
  • Coba ganti nama ekstensi yang tidak umum menjadi .db agar muncul di pemilih file.
  • Periksa apakah file terenkripsi; database terenkripsi memerlukan ekstensi atau kunci yang sesuai dan tidak dapat dibaca sebagai SQLite biasa.
  • Untuk file yang sangat besar, tutup tab browser yang boros memori sebelum mencoba lagi.

Simpan atau ekspor temuan Anda

Hasil kueri dapat diekspor dalam format umum. Jika Anda mengedit baris atau menjalankan pernyataan tulis, gunakan Simpan DB untuk mengunduh database saat ini. File lokal asli tidak ditimpa secara diam-diam.
