Titik awal skema API

Konversi SQLite ke GraphQL SDL

Terjemahkan entitas database menjadi definisi tipe GraphQL yang mudah dibaca, lalu sesuaikan dengan kebutuhan aplikasi Anda.

Buka Pengekspor GraphQL SDL

Buat skema

  1. Buka database SQLite.
  2. Tinjau entitasnya di diagram ER.
  3. Pilih GraphQL SDL sebagai format ekspor.
  4. Ekspor definisi tipe dan tinjau di proyek API Anda.
type Customer {
  id: Int!
  name: String
  orders: [Order!]
}

type Order {
  id: Int!
  customerId: Int!
}

SDL bukan API yang lengkap

Skema database mendeskripsikan penyimpanan, sedangkan GraphQL mendeskripsikan kontrak yang menghadap aplikasi. SDL yang dihasilkan tidak membuat resolver, autentikasi, paginasi, validasi, mutasi, atau otorisasi tingkat field. Anggap ini sebagai draf pertama yang terstruktur.

Tinjau pemetaan tipe

Tipe SQLite tidak sepenuhnya cocok dengan scalar GraphQL. Tanggal bisa disimpan sebagai teks atau angka, desimal mungkin memerlukan scalar kustom, dan data biner membutuhkan representasi khusus aplikasi. Ganti nama field teknis database jika nama API yang lebih jelas sesuai.

Jangan pernah mengekspos semua tabel database secara otomatis. Pilih hanya field dan operasi yang boleh diakses klien, lalu terapkan otorisasi di lapisan API.

Gunakan relasi dengan sengaja

Foreign key yang dideklarasikan dapat menyarankan relasi GraphQL, tetapi perilaku resolver bergantung pada implementasi server Anda. Pertimbangkan batching dan paginasi untuk menghindari akses database bersarang yang mahal.
