Apa yang disertakan dalam konversi

Ekspor mendeskripsikan tabel, nama kolom, tipe data SQLite yang dideklarasikan, primary key, dan relasi foreign key yang dideklarasikan. Ini memberi alat desain struktur yang cukup untuk menampilkan model yang berguna tanpa membuka isi baris tabel.

Table orders {
  id integer [pk]
  customer_id integer [not null]
  created_at text
}

Ref: orders.customer_id > customers.id

Mengapa menggunakan DBML?

DBML lebih mudah ditinjau daripada biner database dan lebih berfokus pada pemodelan data daripada SQL yang dapat dieksekusi. Tim menggunakannya untuk mendiskusikan skema, membuat diagram, mendokumentasikan relasi, dan merencanakan perubahan sebelum menulis migrasi.

DBML adalah representasi desain, bukan cadangan database byte demi byte. Simpan file SQLite asli dan gunakan Simpan DB saat Anda memerlukan database yang berfungsi beserta datanya.

Tinjau model yang dihasilkan

SQLite mengizinkan deklarasi tipe yang fleksibel dan skema bisa saja tidak memuat foreign key. Periksa tipe kustom, constraint komposit, kolom yang dihasilkan, indeks, dan relasi yang hanya ada di kode aplikasi. Tambahkan anotasi tingkat desain setelah ekspor jika diperlukan.
