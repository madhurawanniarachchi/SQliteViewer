Konversi SQLite ke CSV

Ubah tabel atau hasil kueri SQL apa pun menjadi file CSV yang dapat dibuka di Excel, Google Sheets, atau diimpor ke database lain.

Ekspor ke CSV

Ekspor tabel SQLite ke CSV

  1. Buka file .db, .sqlite, .sqlite3, atau .db3 Anda di SQLite Viewer. File tetap berada di browser Anda.
  2. Pilih tabel, atau tulis kueri yang mengembalikan persis baris yang Anda butuhkan.
  3. Klik Ekspor di atas hasil lalu pilih kolom yang akan disertakan.
  4. Pilih CSV dan file langsung terunduh.

Ekspor hanya yang Anda butuhkan

Karena ekspor mengikuti kueri saat ini, Anda dapat menyaring dengan WHERE, menggabungkan tabel, mengurutkan, atau membatasi baris terlebih dahulu, lalu mengekspor hasil persis seperti itu. Pemilih kolom memungkinkan Anda mengecualikan kolom yang tidak diinginkan.

Tips: untuk mengekspor seluruh tabel, pilih tabel dan hapus LIMIT dari kueri sebelum mengklik Ekspor.

Data Anda tidak pernah keluar dari perangkat Anda

Konversi berjalan sebagai JavaScript di tab browser Anda. Database tidak diunggah ke server, sehingga aman digunakan dengan data pelanggan, database aplikasi, dan file internal.

Kapan menggunakan CSV

CSV adalah format paling portabel untuk spreadsheet, alat BI, dan impor massal. Jika Anda memerlukan nilai bertipe atau data bersarang, gunakan JSON; untuk workbook berformat, gunakan Excel.
