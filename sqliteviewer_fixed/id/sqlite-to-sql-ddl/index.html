Ekspor SQL DDL dari file database

  1. Buka database SQLite.
  2. Buka diagram ER.
  3. Pilih SQL DDL sebagai format ekspor.
  4. Ekspor dan simpan teks skema yang dihasilkan.

Hasilnya mewakili struktur database, bukan data tabel. Isinya mencakup definisi entitas, tipe kolom yang dideklarasikan, dan informasi kunci yang dapat disimpulkan dari metadata skema SQLite.

Contoh keluaran

CREATE TABLE "orders" (
  "id" INTEGER PRIMARY KEY,
  "customer_id" INTEGER NOT NULL,
  "created_at" TEXT,
  FOREIGN KEY ("customer_id") REFERENCES "customers" ("id")
);

Kegunaan SQL DDL

  • Meninjau skema database dalam code review.
  • Menyimpan perubahan struktur di version control.
  • Mendokumentasikan tabel tanpa membuka baris produksi.
  • Menyiapkan migrasi ke sistem database lain.
  • Membandingkan definisi tabel yang diharapkan dan yang sebenarnya.
Catatan migrasi: sintaks dan type affinity SQLite berbeda dari PostgreSQL, MySQL, dan SQL Server. Anggap DDL hasil ekspor sebagai deskripsi skema SQLite yang andal, lalu sesuaikan tipe, perilaku auto-increment, penulisan tanda kutip, dan constraint untuk mesin tujuan.

Ekspor skema versus menyimpan database

SQL DDL hanya berisi struktur. Jika Anda memerlukan database beserta baris dan perubahan lokalnya, gunakan Simpan DB. Jika Anda memerlukan baris dalam format teks portabel, gunakan kontrol ekspor hasil.
