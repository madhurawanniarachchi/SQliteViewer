Buat diagram ER dari SQLite

Ubah database yang belum dikenal menjadi peta yang mudah dibaca berisi tabel, kolom, tipe, primary key, dan koneksi foreign key.

Buka Alat Diagram ER

Buat diagram

  1. Buka database SQLite di penampil.
  2. Pilih Diagram ER di sidebar tabel.
  3. Gunakan Pas untuk membawa semua entitas ke area tampilan dialog.
  4. Periksa nama kolom, tipe data SQLite, dan penanda kunci setiap entitas.

Garis relasi berasal dari foreign key yang dideklarasikan di SQLite. Jika relasi logis tidak didefinisikan dengan constraint foreign key, pembaca skema tidak dapat mengenalinya secara andal hanya dari nama kolom.

Cara membaca hasilnya

  • PK menandai kolom primary key yang digunakan untuk mengidentifikasi satu baris secara unik.
  • FK menandai kolom yang merujuk ke kunci di tabel lain.
  • Tipe kolom menunjukkan tipe SQLite yang dideklarasikan. Karena sistem tipe SQLite fleksibel, nilai yang tersimpan terkadang dapat berbeda dari deklarasi tersebut.
  • Garis penghubung menunjukkan entitas yang dirujuk dan yang merujuk.
Diagram paling berguna ketika database mendeklarasikan primary key dan foreign key secara konsisten. Garis yang hilang biasanya menandakan constraint yang hilang, bukan masalah rendering.

Ekspor skema

Setelah meninjau diagram, ekspor skemanya sebagai SQL DDL, DBML, Mermaid, atau GraphQL SDL. SQL DDL paling mendekati definisi database asli. DBML dan Mermaid berguna untuk dokumentasi. GraphQL SDL adalah titik awal untuk model API dan mungkin perlu disesuaikan dengan aplikasi.

Pertanyaan tinjauan yang berguna

Carilah tabel tanpa primary key, foreign key yang menunjuk ke entitas tak terduga, penamaan yang tidak konsisten, kolom nullable yang seharusnya wajib diisi, dan tabel penghubung yang mewakili relasi many-to-many. Pemeriksaan ini membantu saat mewarisi database aplikasi atau merencanakan migrasi.
