Konversi SQLite ke JSON

Ekspor baris sebagai array JSON berisi objek, siap untuk API, prototipe front-end, fixture pengujian, dan database dokumen.

Ekspor ke JSON

Ekspor tabel SQLite ke JSON

  1. Buka file .db, .sqlite, .sqlite3, atau .db3 Anda di SQLite Viewer. File tetap berada di browser Anda.
  2. Pilih tabel, atau tulis kueri yang mengembalikan persis baris yang Anda butuhkan.
  3. Klik Ekspor di atas hasil lalu pilih kolom yang akan disertakan.
  4. Pilih JSON dan file langsung terunduh.

Tampilan JSON

Setiap baris menjadi objek dengan nama kolom sebagai kunci, dan file berupa array dari objek-objek tersebut.

[
  { "id": 1, "name": "Ada", "email": "ada@example.com" },
  { "id": 2, "name": "Linus", "email": "linus@example.com" }
]

Bentuk keluaran dengan SQL

Gunakan kueri untuk mengganti nama kolom dengan AS, menggabungkan tabel terkait, atau menyaring baris sebelum mengekspor, agar JSON sesuai dengan struktur yang diharapkan aplikasi Anda.

Data Anda tidak pernah keluar dari perangkat Anda

Konversi berjalan sebagai JavaScript di tab browser Anda. Database tidak diunggah ke server, sehingga aman digunakan dengan data pelanggan, database aplikasi, dan file internal.
