Konversi SQLite ke Excel (XLSX)

Buat workbook Excel dari tabel atau hasil kueri apa pun untuk pelaporan, berbagi, dan analisis lanjutan.

Ekspor ke Excel

Ekspor tabel SQLite ke Excel

  1. Buka file .db, .sqlite, .sqlite3, atau .db3 Anda di SQLite Viewer. File tetap berada di browser Anda.
  2. Pilih tabel, atau tulis kueri yang mengembalikan persis baris yang Anda butuhkan.
  3. Klik Ekspor di atas hasil lalu pilih kolom yang akan disertakan.
  4. Pilih Excel dan file langsung terunduh.

Gunakan SQL sebelum mengekspor

Saring, urutkan, agregasi, atau gabungkan tabel dengan SQL terlebih dahulu, lalu ekspor hasilnya. Excel menerima persis baris dan kolom yang Anda pilih, dengan nama tabel sebagai nama sheet.

Ekspor Excel memuat pustaka spreadsheet-nya sesuai kebutuhan, sehingga ekspor Excel pertama memerlukan koneksi internet. Database Anda tetap tidak pernah keluar dari browser.

Data Anda tidak pernah keluar dari perangkat Anda

Konversi berjalan sebagai JavaScript di tab browser Anda. Database tidak diunggah ke server, sehingga aman digunakan dengan data pelanggan, database aplikasi, dan file internal.

Bisa impor dari Excel juga

SQLite Viewer juga dapat mengimpor file .xlsx atau .xls ke database SQLite baru, sehingga Anda dapat mengkueri spreadsheet dengan SQL. Lebih suka format teks biasa? Coba CSV atau JSON.
