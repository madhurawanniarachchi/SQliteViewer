Jelajahi SQLite tanpa memasang perangkat lunak

Gunakan browser modern untuk pemeriksaan database yang cepat saat aplikasi SQLite desktop tidak tersedia atau tidak diperlukan.

Buka Browser SQLite

Kapan alat browser berguna

Penampil berbasis web praktis untuk pemeriksaan database sekali pakai, pekerjaan dukungan, latihan di kelas, database aplikasi hasil ekspor, dan lingkungan yang tidak memungkinkan Anda memasang perangkat lunak. Aplikasi dimuat dari web, tetapi database yang dipilih diproses secara lokal di browser.

Kemampuan yang tersedia tanpa instalasi

  • Mencari dan menjelajahi tabel dan view.
  • Menjalankan pernyataan SELECT dan memeriksa hasil yang dipaginasi.
  • Menggunakan beberapa tab kueri dan database.
  • Menambah, mengedit, atau menghapus baris yang dapat diidentifikasi dengan aman.
  • Membuat diagram ER dengan kolom, tipe, dan kunci.
  • Mengekspor hasil atau format skema.
  • Mengunduh database hasil modifikasi saat ini.

Alat browser atau aplikasi desktop?

Aplikasi desktop tetap menjadi pilihan lebih baik untuk database yang sangat besar, ekstensi terenkripsi, administrasi produksi berkelanjutan, analisis indeks lanjutan, atau penguncian sistem file langsung. Alat browser paling unggul saat Anda mementingkan kecepatan, portabilitas, dan pemrosesan lokal untuk file SQLite biasa.

Karena database berada di memori browser, simpan file asli dan unduh perubahan sebelum menutup atau memuat ulang halaman.

Pertimbangan privasi

Pastikan halaman disajikan melalui HTTPS dan gunakan salinan aplikasi yang tepercaya. SQLite Viewer tidak memerlukan pengunggahan database, tetapi ekstensi browser dan perangkat itu sendiri tetap menjadi bagian dari lingkungan keamanan Anda.
