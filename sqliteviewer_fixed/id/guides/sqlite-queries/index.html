Panduan kueri SQLite

Kueri berguna untuk memeriksa database SQLite

Mulailah dengan SQL yang aman dan terfokus saat Anda perlu memahami tabel, indeks, relasi, dan kualitas data.

Buka Ruang Kerja SQL

Daftar tabel dan view pengguna

SELECT type, name, sql
FROM sqlite_master
WHERE type IN ('table', 'view')
  AND name NOT LIKE 'sqlite_%'
ORDER BY type, name;

Periksa kolom tabel

PRAGMA table_info('orders');

Ini mengembalikan tipe yang dideklarasikan, nullability, nilai default, dan posisi primary key untuk setiap kolom.

Tinjau foreign key

PRAGMA foreign_key_list('orders');
PRAGMA foreign_key_check;

Pernyataan pertama menjelaskan referensi yang dideklarasikan untuk satu tabel. Pernyataan kedua melaporkan baris yang melanggar relasi foreign key yang diaktifkan.

Temukan nilai duplikat

SELECT email, COUNT(*) AS occurrences
FROM customers
WHERE email IS NOT NULL
GROUP BY email
HAVING COUNT(*) > 1
ORDER BY occurrences DESC;

Periksa indeks

PRAGMA index_list('orders');

Setelah menemukan nama indeks, periksa kolomnya dengan PRAGMA index_info('index_name').

Periksa perilaku kueri

EXPLAIN QUERY PLAN
SELECT *
FROM orders
WHERE customer_id = 42
ORDER BY created_at DESC;

Rencana eksekusi dapat menunjukkan pemindaian tabel penuh dan apakah SQLite dapat menggunakan indeks yang relevan.

Alur kerja aman: mulailah dengan kueri pemeriksaan SELECT atau PRAGMA. Sebelum UPDATE atau DELETE, jalankan SELECT dengan kondisi WHERE yang sama dan simpan salinan asli database.

Paginasi tabel besar

SELECT *
FROM events
ORDER BY id
LIMIT 100 OFFSET 0;

Untuk navigasi berulang pada tabel yang sangat besar, paginasi keyset seperti WHERE id > ? ORDER BY id LIMIT 100 sering kali lebih efisien daripada offset yang sangat besar.
