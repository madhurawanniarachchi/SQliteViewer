Debugging langsung Android

Siapkan bridge ADB (bekerja berdampingan dengan Android Studio)

Satu pembantu kecil memungkinkan SQLite Viewer dan Android Studio memakai ponsel Anda secara bersamaan. Unduh, tempatkan, buat berjalan sendiri, selesai.

Buka penampil

Apakah saya perlu bridge?

Sering kali tidak. SQLite Viewer dapat berbicara langsung dengan ponsel Anda lewat USB (mode USB langsung di Chrome atau Edge), tanpa memasang apa pun. Bridge hanya untuk satu situasi: Android Studio (atau alat ADB lain) sudah memakai ponsel. Hanya satu program yang dapat memiliki koneksi USB, sehingga bridge memungkinkan SQLite Viewer berbagi server ADB milik Android Studio. Dengan begitu keduanya bekerja bersamaan.

Windows: penginstal satu klik

  1. Unduh penginstal. Di SQLite Viewer, buka Live Android, pilih Server ADB, lalu klik Unduh penginstal (Windows).
  2. Simpan file. Chrome mungkin menyatakan file tidak dapat diverifikasi. Pilih Simpan (atau Unduh file yang belum diverifikasi). File ini berupa teks biasa, sehingga Anda dapat membukanya di Notepad untuk membaca persis apa yang dilakukannya.
  3. Jalankan sekali. Klik dua kali Install-ADB-Bridge.cmd. Jika Windows menampilkan Windows protected your PC, klik More info, lalu Run anyway.
  4. Kembali ke halaman. Penginstal membangun bridge di PC Anda, membuatnya berjalan sendiri setiap kali Anda masuk, dan menjalankannya. SQLite Viewer mendeteksinya dalam beberapa detik. Klik Hubungkan lewat bridge.

Bridge dipasang di %LOCALAPPDATA%\SQLiteViewerBridge dan pintasan di folder Startup menjalankannya saat masuk. Untuk menghapusnya, jalankan uninstall.cmd dari folder tersebut.

Sistem apa pun: siapkan dengan Python

  1. Pasang Python 3. Unduh dari python.org. Di Windows, centang Add Python to PATH di penginstal. Sebagian besar sistem Linux sudah memiliki python3. macOS tidak menyertakannya secara default: saat pertama kali Anda mengetik python3, macOS menawarkan untuk memasang Command Line Tools Apple (terima), atau Anda dapat memakai penginstal dari python.org.
  2. Unduh file. Unduh adb-bridge.py. Browser menyimpannya di folder Downloads. Jika berakhiran .txt, ganti namanya menjadi adb-bridge.py.
  3. Salin ke tempat permanennya. Buka terminal (folder mana pun boleh, perintahnya memakai path lengkap) dan jalankan perintah untuk sistem Anda. Perintah ini membuat folder dan menyalin file ke dalamnya. Jika browser menyimpan file di tempat selain Downloads, ubah bagian itu pada perintah.
  4. Buat berjalan sendiri. Jalankan perintah untuk sistem Anda. Perintah ini menyiapkan entri mulai-saat-masuk untuk file di tempat Anda menyalinnya, dan menjalankan bridge sekarang.
  5. Hubungkan. Kembali ke SQLite Viewer. Ia menemukan bridge dengan sendirinya. Klik Hubungkan lewat bridge.

Langkah 3: salin file (jalankan sekali)

Windows (PowerShell; tekan tombol Windows, ketik powershell, tekan Enter):

New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\SQLiteViewerBridgePython" | Out-Null; Copy-Item "$env:USERPROFILE\Downloads\adb-bridge.py" "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py"

Windows (Command Prompt; tekan tombol Windows, ketik cmd, tekan Enter):

mkdir "%LOCALAPPDATA%\SQLiteViewerBridgePython" & copy "%USERPROFILE%\Downloads\adb-bridge.py" "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

macOS (Terminal):

mkdir -p "$HOME/Library/Application Support/SQLiteViewerBridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py"

Linux:

mkdir -p "$HOME/.local/share/sqliteviewer-bridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py"

Langkah 4: buat berjalan sendiri saat masuk (jalankan sekali)

Windows (PowerShell):

python "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

Windows (Command Prompt):

python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

macOS:

python3 "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py" --add-to-startup

Linux:

python3 "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py" --add-to-startup

Di Windows ini membuat pintasan tersembunyi di folder Startup, di macOS sebuah Launch Agent, dan di Linux layanan pengguna systemd (atau entri autostart desktop). Tidak ada yang memerlukan hak administrator. Biarkan file di tempatnya; jika Anda memindahkannya, jalankan perintah lagi.

Terburu-buru? Satu perintah menjalankan langkah 3 dan 4

Buka terminal di folder tempat Anda mengunduh file dan jalankan:

python adb-bridge.py --install      # Windows
python3 adb-bridge.py --install     # macOS and Linux

Lebih suka menambahkannya ke Startup secara manual?

Windows: tekan Win + R, ketik shell:startup, dan tekan Enter. Di folder yang terbuka, klik kanan, pilih New → Shortcut, dan atur lokasinya ke:

pythonw "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

Beri nama SQLite Viewer ADB Bridge. Memakai pythonw alih-alih python menghindarkan jendela hitam. Keluar lalu masuk lagi, atau klik dua kali pintasan untuk menjalankannya sekarang.

macOS: perintah di atas membuat ~/Library/LaunchAgents/com.sqliteviewer.adbbridge.plist. Linux: perintah itu membuat ~/.config/systemd/user/sqliteviewer-bridge.service (atau ~/.config/autostart/sqliteviewer-bridge.desktop). Menulis file-file itu secara manual memang bisa, tetapi perintah lebih aman.

Periksa, hentikan, dan hapus

python adb-bridge.py --status                  # is it running?
python adb-bridge.py --remove-from-startup      # stop starting at sign-in (keeps the file)
python adb-bridge.py --uninstall                # stop it and delete everything
# add the full path to the file if you are not in its folder, as in the commands above

Apakah saya punya ADB? Pasang jika belum

Bridge meneruskan ke ADB (Android Platform Tools). Android Studio sudah menyertakannya, jadi jika Anda memakai Android Studio, bagian ini dapat dilewati. Untuk memeriksa, buka terminal dan jalankan adb version. Jika sistem tidak mengenali perintah tersebut, pasang ADB dengan salah satu perintah di bawah. SQLite Viewer juga memberi tahu Anda saat bridge berjalan tetapi tidak menemukan ADB. Bridge mencari ADB di PATH Anda dan di folder umum Android Studio, winget, Homebrew, dan unduhan manual, sehingga Anda tidak perlu mengubah PATH, dan ia menjalankan server ADB untuk Anda.

Windows

Paling mudah (Windows 10 dan 11, PowerShell atau Command Prompt):

winget install --id Google.PlatformTools -e

Tidak ada winget? Unduh langsung (PowerShell):

Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile "$env:TEMP\pt.zip"; Expand-Archive "$env:TEMP\pt.zip" "$env:LOCALAPPDATA\Android\Sdk" -Force; Remove-Item "$env:TEMP\pt.zip"

Hal yang sama di Command Prompt:

powershell -NoProfile -Command "Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile \"$env:TEMP\pt.zip\"; Expand-Archive \"$env:TEMP\pt.zip\" \"$env:LOCALAPPDATA\Android\Sdk\" -Force; Remove-Item \"$env:TEMP\pt.zip\""

Periksa bahwa berhasil (PowerShell):

& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" version

macOS

Dengan Homebrew:

brew install --cask android-platform-tools

Tanpa Homebrew:

mkdir -p "$HOME/Library/Android/sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-darwin.zip && unzip -o /tmp/pt.zip -d "$HOME/Library/Android/sdk" && rm /tmp/pt.zip

Linux

Debian, Ubuntu, Mint:

sudo apt install adb

Fedora:

sudo dnf install android-tools

Arch, Manjaro:

sudo pacman -S android-tools

Distribusi lainnya:

mkdir -p "$HOME/Android/Sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-linux.zip && unzip -o /tmp/pt.zip -d "$HOME/Android/Sdk" && rm /tmp/pt.zip

Lalu siapkan ponsel

  1. Di ponsel, buka Settings → About phone dan ketuk Build number tujuh kali.
  2. Buka Settings → Developer options dan aktifkan USB debugging.
  3. Colokkan ponsel dan ketuk Allow pada permintaan. Menjalankan adb devices seharusnya menampilkannya sebagai device.

Apakah saya perlu mengonfigurasi sesuatu?

Tidak. Bridge hanya menerima koneksi dari situs web SQLite Viewer, hanya mendengarkan di komputer Anda sendiri (127.0.0.1), dan hanya meneruskan ke server ADB di komputer yang sama. Tidak ada yang disimpan atau dikirim ke tempat lain.

Anda hanya memerlukan pengaturan dalam dua kasus:

  • Anda memakai SQLite Viewer dari alamat berbeda (salinan Anda sendiri, atau localhost saat mengembangkan). Izinkan alamat itu pada perintah yang sama:
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --allow-origin https://your-address.example
  • Port 5038 sudah dipakai. Gunakan port lain, lalu masukkan port yang sama di Advanced pada panel Android:
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --port 5040

Alamat yang diizinkan diingat dalam file bernama origins.txt (satu alamat per baris) di samping bridge: Windows %LOCALAPPDATA%\SQLiteViewerBridge (penginstal) atau %LOCALAPPDATA%\SQLiteViewerBridgePython (Python), macOS ~/Library/Application Support/SQLiteViewerBridge, Linux ~/.local/share/sqliteviewer-bridge.

Pemecahan masalah

  • “The bridge is not running on this computer”: jalankan penginstal atau perintah di atas, atau keluar lalu masuk lagi. Kemudian buka kembali panel Android.
  • Saya tidak punya Python: di Windows Anda tidak memerlukannya, gunakan penginstal satu klik di atas. Jika tidak, pasang Python 3 dari python.org (Windows: centang Add Python to PATH), atau di macOS terima tawaran memasang Command Line Tools. Lalu jalankan perintah lagi.
  • python tidak dikenali, atau membuka Microsoft Store (Windows): Python belum terpasang, atau opsi PATH terlewat. Pasang dari python.org, atau ganti python dengan py pada perintah. Anda juga dapat mematikan pintasan Store di Settings → Apps → Advanced app settings → App execution aliases.
  • Perintah salin mengatakan file tidak ditemukan: browser menyimpan adb-bridge.py di tempat selain Downloads. Ubah bagian itu pada perintah, atau ganti nama file .txt.
  • “Something is already listening on port 5038”: bridge lain sedang berjalan. Hapus yang lama (--uninstall atau uninstall.cmd) atau pilih port lain dengan --port.
  • Bridge berjalan tetapi tidak ada ponsel yang muncul: server ADB harus melihat ponsel. Jalankan adb devices, aktifkan USB debugging, dan terima permintaan “Allow USB debugging” di ponsel.
  • “The bridge is running, but ADB is not installed”: pasang ADB dengan perintah di bagian Apakah saya punya ADB? di atas (atau pasang Android Studio). Halaman mendeteksinya sendiri beberapa detik kemudian.
  • Chrome meminta izin mengakses perangkat di jaringan Anda: izinkan. Begitulah cara halaman menjangkau bridge di komputer Anda sendiri.
  • Antivirus atau Windows memblokir penginstal: penginstal hanya membangun program kecil dari sumber yang dapat Anda baca, dan menulis ke folder pengguna Anda sendiri. Izinkan, atau gunakan jalur Python.
