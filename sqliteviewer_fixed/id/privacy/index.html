Privasi

Database Anda tetap berada di browser Anda

SQLite Viewer dirancang untuk membuka dan memproses file database yang dipilih di perangkat pengguna, bukan mengunggah isinya untuk diproses di server.

Pemrosesan database secara lokal

Saat Anda memilih file SQLite, JavaScript browser membacanya ke memori lokal. Penelusuran tabel, eksekusi SQL, pengeditan baris, pemeriksaan skema, dan ekspor database terjadi di sesi browser. Aplikasi tidak perlu mengirim file database yang dipilih ke server untuk menyediakan fitur-fitur ini.

Apa yang dapat diterima situs web

Seperti kebanyakan situs web, infrastruktur hosting dapat menerima informasi permintaan biasa seperti alamat IP, jenis browser, halaman yang diminta, stempel waktu, dan log kesalahan. Situs dapat menggunakan analitik untuk memahami kunjungan halaman dan penggunaan secara umum. Nama file database, isi tabel, dan teks kueri SQL seharusnya tidak sengaja dikirim sebagai peristiwa analitik.

Penyimpanan browser

Aplikasi dapat menggunakan penyimpanan browser untuk preferensi lokal dan informasi ruang kerja, seperti tab kueri atau riwayat kueri. Informasi ini tetap terkait dengan profil browser sampai dihapus oleh pengguna atau browser.

Unduhan dan file asli

Pengeditan terjadi pada database di memori. Simpan DB membuat unduhan dari kondisi saat ini. Aplikasi tidak menimpa file database asli di disk secara diam-diam.

Tanggung jawab Anda

Gunakan database yang Anda berwenang untuk mengaksesnya. Pertimbangkan keamanan perangkat, profil browser, dan ekstensi yang terpasang saat membuka file sensitif. Hapus penyimpanan browser dan salinan yang diunduh saat bekerja di perangkat bersama.

Sumber daya pihak ketiga

Halaman dapat memuat pustaka, analitik, atau sumber daya situs web lain dari layanan pihak ketiga. Layanan ini dapat menerima data permintaan web biasa, tetapi database yang dipilih tidak sengaja disertakan dalam permintaan tersebut.

Untuk data yang sangat sensitif atau diatur regulasi, gunakan lingkungan dan konfigurasi browser yang disetujui organisasi Anda, dan tinjau perilaku jaringan aplikasi yang diterapkan sebelum digunakan.
