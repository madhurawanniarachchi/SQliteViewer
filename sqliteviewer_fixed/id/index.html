Do you have ADB? Install it if not

The bridge talks to ADB (Android Platform Tools). Android Studio already includes it. If you do not use Android Studio, install ADB with one of these commands. Open a terminal first.

Your terminal:

On the phone: open Settings → About phone, tap Build number 7 times, then Settings → Developer options → turn on USB debugging. Plug the phone in and tap Allow when it asks.

You opened this page from a file, so browsers hide its origin ('null') and the bridge must allow every local file page. It is safer to serve the folder with python -m http.server 8000 and open http://localhost:8000 instead.

Advanced
  • Enable USB debugging on the phone and accept the prompt when connecting.
  • Only debuggable apps (debug builds) can be read. Release apps are protected by Android.
  • If the device is busy, run adb kill-server and close Android Studio, then connect again.
  • Use Chrome or Edge on desktop. The view is read-only and re-copies the file on each refresh.

Ruang kerja database pribadi di browser

Periksa dan edit file SQLite tanpa mengunggah data Anda

SQLite Viewer berjalan langsung di browser Anda. Buka file lokal .db, .sqlite, .sqlite3, atau .db3, jelajahi skema dan barisnya, jalankan SQL, buat perubahan, lalu unduh database terbaru—semuanya tanpa mengirim file ke server.

Jelajahi dan cari tabel

Telusuri skema besar, urutkan daftar tabel menurut nama, baris, sel, atau perkiraan ukuran, dan sematkan kolom hasil yang penting.

Edit baris database sebenarnya

Tambah, ubah, dan hapus baris dengan kontrol yang memahami primary key. Perubahan tetap berada di database dalam browser sampai Anda mengunduhnya.

Ruang kerja SQL multi-tab

Buka tab baru untuk setiap tabel atau kueri, beralih antar beberapa database, dan jaga setiap hasil tetap terhubung dengan kuerinya.

Buat diagram ER

Visualisasikan entitas, kolom, tipe data, primary key, dan relasi foreign key, lalu sesuaikan diagram dengan jendela.

Ekspor skema dan hasil

Ekspor skema ER sebagai SQL DDL, DBML, Mermaid, atau GraphQL SDL, dan ekspor hasil kueri dalam format data umum.

Simpan file SQLite yang diubah

Perubahan diterapkan secara lokal. Pilih Simpan DB kapan saja untuk mengunduh database saat ini sebagai file SQLite yang dapat digunakan.

Cara kerjanya

Dari file database ke jawaban berguna dalam tiga langkah

  1. Buka database.Letakkan file SQLite yang didukung ke halaman atau gunakan pemilih file.
  2. Jelajahi atau kueri.Pilih tabel, periksa kolom, edit baris, atau jalankan SQL Anda sendiri.
  3. Ekspor yang Anda butuhkan.Unduh hasil, definisi skema, atau seluruh database yang telah diubah.

FAQ SQLite Viewer

Apakah database SQLite saya diunggah?

Tidak. Database dibuka dan diproses secara lokal oleh JavaScript di browser Anda. Alat ini tidak perlu mengunggah file untuk memeriksanya.

Bisakah saya mengedit dan menyimpan database SQLite?

Bisa. Anda dapat mengedit baris tabel yang didukung atau menjalankan kueri tulis, lalu gunakan Simpan DB untuk mengunduh kondisi database terbaru.

Ekstensi file SQLite apa yang didukung?

Pemilih file menerima .db, .sqlite, .sqlite3, dan .db3. Database SQLite yang valid mungkin memakai ekstensi lain, tetapi mungkin perlu diganti namanya sebelum dipilih.

Apakah berfungsi dengan database besar?

File besar bergantung pada memori browser yang tersedia. Penampil membatasi baris hasil yang dirender dan mengambil sampel metadata tabel yang mahal agar tetap responsif.
