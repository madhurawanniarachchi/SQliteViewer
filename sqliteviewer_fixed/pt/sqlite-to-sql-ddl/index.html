Exportação de esquema

Converter um esquema do SQLite para SQL DDL

Extraia definições de esquema legíveis para documentação, revisão, planejamento de migração ou controle de versão.

Abrir o exportador de esquema SQLite

Exporte SQL DDL de um arquivo de banco de dados

  1. Abra o banco de dados SQLite.
  2. Abra o diagrama ER.
  3. Selecione SQL DDL como formato de exportação.
  4. Exporte e salve o texto do esquema gerado.

O resultado representa a estrutura do banco de dados, não os dados das tabelas. Inclui definições de entidades, tipos de coluna declarados e informações de chave que podem ser inferidas dos metadados do esquema do SQLite.

Exemplo de saída

CREATE TABLE "orders" (
  "id" INTEGER PRIMARY KEY,
  "customer_id" INTEGER NOT NULL,
  "created_at" TEXT,
  FOREIGN KEY ("customer_id") REFERENCES "customers" ("id")
);

Para que o SQL DDL é útil

  • Revisar o esquema de um banco de dados em uma revisão de código.
  • Manter as mudanças de estrutura no controle de versão.
  • Documentar tabelas sem expor linhas de produção.
  • Preparar uma migração para outro sistema de banco de dados.
  • Comparar as definições de tabela esperadas e reais.
Nota sobre migração: a sintaxe e a afinidade de tipos do SQLite diferem do PostgreSQL, MySQL e SQL Server. Trate o DDL exportado como uma descrição confiável do esquema do SQLite e depois adapte tipos, comportamento de autoincremento, aspas e restrições para o mecanismo de destino.

Exportação de esquema versus salvar o banco de dados

O SQL DDL contém apenas a estrutura. Se precisar do banco de dados com suas linhas e edições locais, use Salvar BD. Se precisar das linhas em um formato de texto portátil, use os controles de exportação de resultados.
