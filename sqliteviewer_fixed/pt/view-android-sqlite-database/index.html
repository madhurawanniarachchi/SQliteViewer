Ver um banco de dados SQLite do Android

Abra um banco de dados de app exportado de um emulador, de uma versão de depuração ou de um dispositivo autorizado e inspecione-o sem instalar um navegador de banco de dados de desktop.

Abrir banco de dados Android

Primeiro exporte o banco de dados de forma legal e segura

O SQLite Viewer abre um arquivo que você já possui; ele não extrai bancos de dados de um telefone. Use o Device Explorer do Android Studio, um emulador, um backup do aplicativo ou suas próprias ferramentas de depuração para obter um banco de dados que você esteja autorizado a inspecionar.

Os bancos de dados de apps Android geralmente ficam em um diretório databases específico do aplicativo e podem usar .db ou não ter extensão. Se o seletor do navegador não mostrar uma cópia sem extensão, renomeie o arquivo exportado para terminar em .db.

Abra e inspecione o esquema do app

  1. Solte o banco de dados exportado no SQLite Viewer.
  2. Pesquise na barra lateral de tabelas o recurso que você está depurando.
  3. Abra as tabelas prováveis e inspecione as linhas recentes.
  4. Use o diagrama ER para entender chaves estrangeiras e relações no estilo Room.
  5. Execute SQL focado em vez de rolar por grandes tabelas de eventos ou de cache.
SELECT *
FROM "sync_queue"
ORDER BY "created_at" DESC
LIMIT 0, 100;

Veja o banco de dados de um app de depuração ao vivo via USB

No Chrome ou Edge de desktop, escolha Android na barra de ferramentas, conecte o telefone com a depuração USB ativada e escolha um dos seus apps depuráveis. O SQLite Viewer copia o banco de dados com run-as, mescla o log de gravação antecipada para incluir as gravações recentes e pode atualizá-lo a cada poucos segundos enquanto você testa. Tudo permanece no seu navegador. As versões de release são protegidas pelo Android e não podem ser lidas dessa forma.

O Android Studio mantém a conexão USB ocupada, então o visualizador também tem um modo de servidor ADB: no Windows, baixe o instalador da ponte de um clique e dê um duplo clique nele uma vez. Ele configura um pequeno auxiliar que inicia sozinho a cada login, e a página compartilha o servidor ADB com o Android Studio para que ambos funcionem ao mesmo tempo. No macOS e no Linux, execute o auxiliar adb-bridge.py. A página detecta a ponte automaticamente. Ajuda completa: guia de configuração da ponte ADB.

Quer alterar dados sem reiniciar o app? Adicione um pequeno auxiliar apenas de depuração e siga o guia de configuração da edição ao vivo.

Trate bancos de dados WAL corretamente

O SQLite pode usar registro de gravação antecipada (WAL), gerando arquivos auxiliares -wal e -shm. Copiar apenas o banco de dados principal enquanto o app grava pode omitir transações recentes. Prefira uma exportação consistente criada com o banco de dados fechado ou com checkpoint.

Dados sensíveis: bancos de dados de apps podem conter informações pessoais, tokens ou registros comerciais. Use apenas arquivos que você esteja autorizado a inspecionar e exclua as cópias exportadas quando a depuração terminar.

Editar bancos de dados Android

Você pode editar uma cópia e baixá-la, mas substituir o banco de dados de um app pode violar as expectativas do esquema ou corromper o estado da aplicação. Mantenha o original, valide as restrições e use ferramentas de migração ou depuração compatíveis sempre que possível.
