Quando uma ferramenta de navegador é útil

Um visualizador web é conveniente para inspeções pontuais de banco de dados, trabalho de suporte, exercícios em sala de aula, bancos de dados de apps exportados e ambientes em que você não pode instalar software. O aplicativo é carregado da web, mas o banco de dados selecionado é processado localmente no navegador.

Recursos disponíveis sem instalação

  • Pesquisar e navegar por tabelas e views.
  • Executar instruções SELECT e inspecionar resultados paginados.
  • Usar várias abas de consulta e de banco de dados.
  • Adicionar, editar ou excluir linhas identificáveis com segurança.
  • Gerar um diagrama ER com colunas, tipos e chaves.
  • Exportar resultados ou formatos de esquema.
  • Baixar o banco de dados modificado atual.

Ferramenta de navegador ou aplicativo de desktop?

Um aplicativo de desktop continua sendo a melhor escolha para bancos de dados extremamente grandes, extensões de criptografia, administração contínua de produção, análise avançada de índices ou bloqueio direto do sistema de arquivos. Uma ferramenta de navegador é mais forte quando você valoriza velocidade, portabilidade e processamento local de um arquivo SQLite comum.

Como o banco de dados fica na memória do navegador, mantenha o arquivo original e baixe as alterações antes de fechar ou atualizar a página.

Considerações de privacidade

Confirme que a página é servida por HTTPS e use uma cópia confiável do aplicativo. O SQLite Viewer não exige envio do banco de dados, mas as extensões do navegador e o próprio dispositivo continuam fazendo parte do seu ambiente de segurança.
