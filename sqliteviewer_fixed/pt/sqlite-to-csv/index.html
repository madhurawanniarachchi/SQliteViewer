Converter SQLite para CSV

Transforme uma tabela ou o resultado de qualquer consulta SQL em um arquivo CSV que você pode abrir no Excel, no Google Planilhas ou importar para outro banco de dados.

Exportar para CSV

Exportar uma tabela do SQLite para CSV

  1. Abra seu arquivo .db, .sqlite, .sqlite3 ou .db3 no SQLite Viewer. Ele permanece no seu navegador.
  2. Selecione uma tabela ou escreva uma consulta que retorne exatamente as linhas de que você precisa.
  3. Clique em Exportar acima dos resultados e escolha as colunas a incluir.
  4. Escolha CSV e o arquivo é baixado imediatamente.

Exporte apenas o que você precisa

Como a exportação segue a consulta atual, você pode filtrar com WHERE, juntar tabelas, ordenar ou limitar linhas primeiro e depois exportar exatamente esse resultado. O seletor de colunas permite deixar de fora as colunas que você não quer no arquivo.

Dica: para exportar uma tabela inteira, selecione-a e remova qualquer LIMIT da consulta antes de clicar em Exportar.

Seus dados nunca saem do seu dispositivo

A conversão é executada como JavaScript na aba do seu navegador. O banco de dados não é enviado a um servidor, portanto é seguro usá-lo com dados de clientes, bancos de dados de apps e arquivos internos.

Quando usar CSV

CSV é o formato mais portátil para planilhas, ferramentas de BI e importações em massa. Se precisar de valores tipados ou dados aninhados, use JSON; para uma pasta de trabalho formatada, use Excel.
