Abrir o editor SQLite

Edite linhas com proteção por chave primária

Abra um banco de dados e selecione uma tabela. Quando a tabela tem uma chave primária utilizável, o resultado inclui ações para editar e excluir linhas individuais. O editor usa os valores da chave primária para atingir a linha pretendida em vez de depender da posição visual dela.

  1. Escolha Editar na linha.
  2. Altere os valores dos campos necessários. Use a opção nulo quando a coluna permitir.
  3. Salve a linha e confirme o resultado atualizado.
  4. Escolha Salvar BD para baixar o banco de dados quando terminar.
Importante: as alterações são feitas no banco de dados mantido na memória do navegador. Elas não sobrescrevem o arquivo original automaticamente. Baixe o banco de dados mais recente antes de fechar a página.

Use SQL para alterações em massa

O espaço de consultas também aceita instruções de gravação do SQLite. Por exemplo:

UPDATE "products"
SET "active" = 0
WHERE "last_order_at" < '2025-01-01';

Revise com cuidado a condição WHERE antes de executar uma atualização ou exclusão. Um bom fluxo de trabalho é executar primeiro a mesma condição como SELECT, confirmar as linhas afetadas e só então executar a consulta de gravação.

O que pode impedir a edição de linhas?

As ações seguras em linhas exigem que o visualizador identifique os registros de forma confiável. Tabelas sem chaves primárias podem aparecer como somente leitura na interface de linhas. Views, resultados calculados, junções e consultas de agregação geralmente não podem ser mapeados com segurança para uma única linha de origem, embora você ainda possa inspecioná-los ou exportá-los.

Baixe o banco de dados finalizado

A ação Salvar BD exporta o estado atual do banco de dados SQLite, incluindo edições de linhas e consultas de gravação bem-sucedidas. Mantenha o original como backup até testar o arquivo baixado no aplicativo que o utiliza.
