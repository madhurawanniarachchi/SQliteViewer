Privacidade

Seu banco de dados permanece no seu navegador

O SQLite Viewer foi projetado para abrir e processar os arquivos de banco de dados selecionados no dispositivo do usuário, em vez de enviar seu conteúdo para processamento no servidor.

Processamento local do banco de dados

Quando você seleciona um arquivo SQLite, o JavaScript do navegador o lê na memória local. A navegação por tabelas, a execução de SQL, a edição de linhas, a inspeção do esquema e a exportação do banco de dados acontecem na sessão do navegador. O aplicativo não precisa transmitir o arquivo selecionado a um servidor para oferecer esses recursos.

O que o site pode receber

Como a maioria dos sites, a infraestrutura de hospedagem pode receber informações comuns de solicitação, como endereço IP, tipo de navegador, páginas solicitadas, carimbos de data e hora e registros de erro. O site pode usar análises para entender as visitas às páginas e o uso geral. Nomes de arquivos de banco de dados, conteúdo de tabelas e texto de consultas SQL não devem ser enviados intencionalmente como eventos de análise.

Armazenamento do navegador

O aplicativo pode usar o armazenamento do navegador para preferências locais e informações do espaço de trabalho, como abas de consulta ou histórico de consultas. Essas informações permanecem associadas ao perfil do navegador até serem apagadas pelo usuário ou pelo navegador.

Downloads e arquivos originais

A edição ocorre no banco de dados em memória. Salvar BD cria um download do estado atual. O aplicativo não substitui silenciosamente o arquivo de banco de dados original no disco.

Suas responsabilidades

Use bancos de dados que você tem autorização para acessar. Considere a segurança do dispositivo, do perfil do navegador e das extensões instaladas ao abrir arquivos sensíveis. Limpe o armazenamento do navegador e as cópias baixadas ao trabalhar em um dispositivo compartilhado.

Recursos de terceiros

A página pode carregar bibliotecas, análises ou outros recursos de sites de serviços de terceiros. Esses serviços podem receber dados normais de solicitações da web, mas o banco de dados selecionado não é incluído intencionalmente nessas solicitações.

Para dados altamente sensíveis ou regulamentados, use um ambiente e uma configuração de navegador aprovados pela sua organização e revise o comportamento de rede do aplicativo implantado antes de usá-lo.

Perguntas

Dúvidas sobre privacidade e segurança podem ser enviadas ao operador do site, CodeMasterLk. Esta página deve ser atualizada quando o comportamento de processamento de dados do serviço mudar.
