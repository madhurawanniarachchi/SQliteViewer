Converter SQLite para DBML

Transforme um esquema SQLite existente em DBML legível para documentação e fluxos de design de banco de dados.

Abrir o exportador DBML

Gere DBML a partir de um arquivo SQLite

  1. Abra seu banco de dados no SQLite Viewer.
  2. Escolha Diagrama ER.
  3. Selecione DBML na lista de formatos de exportação.
  4. Exporte o texto gerado e revise-o na sua ferramenta DBML preferida.

O que a conversão inclui

A exportação descreve tabelas, nomes de colunas, tipos de dados declarados no SQLite, chaves primárias e relações de chave estrangeira declaradas. Ela dá às ferramentas de design estrutura suficiente para renderizar um modelo útil sem expor as linhas das tabelas.

Table orders {
  id integer [pk]
  customer_id integer [not null]
  created_at text
}

Ref: orders.customer_id > customers.id

Por que usar DBML?

O DBML é mais fácil de revisar do que um binário de banco de dados e mais focado em modelagem de dados do que o SQL executável. As equipes o usam para discutir esquemas, criar diagramas, documentar relações e planejar mudanças antes de escrever migrações.

DBML é uma representação de design, não um backup byte a byte do banco de dados. Mantenha o arquivo SQLite original e use Salvar BD quando precisar de um banco de dados funcional com seus dados.

Revise o modelo gerado

O SQLite permite declarações de tipo flexíveis e os esquemas podem omitir chaves estrangeiras. Verifique tipos personalizados, restrições compostas, colunas geradas, índices e relações que existem apenas no código da aplicação. Adicione anotações de design após a exportação quando necessário.
