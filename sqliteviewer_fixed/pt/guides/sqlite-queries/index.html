Guia de consultas SQLite

Consultas úteis para inspecionar bancos de dados SQLite

Comece com SQL seguro e focado quando precisar entender tabelas, índices, relações e qualidade dos dados.

Abrir o espaço SQL

Listar tabelas e views do usuário

SELECT type, name, sql
FROM sqlite_master
WHERE type IN ('table', 'view')
  AND name NOT LIKE 'sqlite_%'
ORDER BY type, name;

Inspecionar as colunas de uma tabela

PRAGMA table_info('orders');

Isso retorna o tipo declarado, a nulidade, o valor padrão e a posição na chave primária de cada coluna.

Revisar chaves estrangeiras

PRAGMA foreign_key_list('orders');
PRAGMA foreign_key_check;

A primeira instrução descreve as referências declaradas de uma tabela. A segunda informa as linhas que violam as relações de chave estrangeira habilitadas.

Encontrar valores duplicados

SELECT email, COUNT(*) AS occurrences
FROM customers
WHERE email IS NOT NULL
GROUP BY email
HAVING COUNT(*) > 1
ORDER BY occurrences DESC;

Inspecionar índices

PRAGMA index_list('orders');

Depois de encontrar o nome de um índice, inspecione suas colunas com PRAGMA index_info('nome_do_indice').

Verificar o comportamento da consulta

EXPLAIN QUERY PLAN
SELECT *
FROM orders
WHERE customer_id = 42
ORDER BY created_at DESC;

O plano pode revelar varreduras completas da tabela e se o SQLite consegue usar um índice relevante.

Fluxo de trabalho seguro: comece com consultas de inspeção SELECT ou PRAGMA. Antes de UPDATE ou DELETE, execute um SELECT com a mesma condição WHERE e mantenha uma cópia original do banco de dados.

Paginar tabelas grandes

SELECT *
FROM events
ORDER BY id
LIMIT 100 OFFSET 0;

Para navegar repetidamente por tabelas muito grandes, a paginação por chave, como WHERE id > ? ORDER BY id LIMIT 100, costuma ser mais eficiente do que um deslocamento muito grande.
