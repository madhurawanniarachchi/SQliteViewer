Configure a ponte ADB (funciona junto com o Android Studio)

Um pequeno auxiliar permite que o SQLite Viewer e o Android Studio usem seu telefone ao mesmo tempo. Baixe-o, coloque-o no lugar, faça-o iniciar sozinho e pronto.

Abrir o visualizador

Preciso da ponte?

Muitas vezes não. O SQLite Viewer pode falar com o telefone diretamente por USB (modo USB direto no Chrome ou Edge), sem instalar nada. A ponte serve para uma situação: o Android Studio (ou outra ferramenta ADB) já está usando o telefone. Apenas um programa pode ter a conexão USB, então a ponte permite que o SQLite Viewer compartilhe o servidor ADB do Android Studio. Assim, os dois funcionam ao mesmo tempo.

Windows: instalador de um clique

  1. Baixe o instalador. No SQLite Viewer, abra Live Android, escolha Servidor ADB e clique em Baixar o instalador (Windows).
  2. Mantenha o arquivo. O Chrome pode dizer que o arquivo não pode ser verificado. Escolha Manter (ou Baixar arquivo não verificado). O arquivo é texto simples, então você pode abri-lo no Bloco de Notas para ler exatamente o que ele faz.
  3. Execute uma vez. Dê um duplo clique em Install-ADB-Bridge.cmd. Se o Windows mostrar O Windows protegeu o computador, clique em Mais informações e depois em Executar assim mesmo.
  4. Volte para a página. O instalador cria a ponte no seu PC, faz com que ela inicie sozinha a cada login e a inicia. O SQLite Viewer a percebe em alguns segundos. Clique em Conectar pela ponte.

A ponte é instalada em %LOCALAPPDATA%\SQLiteViewerBridge e um atalho na pasta Inicializar a inicia no login. Para removê-la, execute uninstall.cmd dessa pasta.

Qualquer sistema: configure com Python

  1. Instale o Python 3. Baixe em python.org. No Windows, marque Add Python to PATH no instalador. A maioria dos sistemas Linux já tem python3. O macOS não o inclui por padrão: na primeira vez que você digitar python3, o macOS oferece instalar as Command Line Tools da Apple (aceite) ou você pode usar o instalador do python.org.
  2. Baixe o arquivo. Baixe adb-bridge.py. O navegador o salva na pasta Downloads. Se terminar em .txt, renomeie para adb-bridge.py.
  3. Copie-o para o lugar permanente. Abra um terminal (qualquer pasta serve, os comandos usam caminhos completos) e execute o comando do seu sistema. Ele cria a pasta e copia o arquivo para ela. Se o navegador salvou o arquivo em outro lugar que não Downloads, altere essa parte do comando.
  4. Faça-o iniciar sozinho. Execute o comando do seu sistema. Ele configura a entrada de início no login para o arquivo onde você o copiou e inicia a ponte agora.
  5. Conecte. Volte ao SQLite Viewer. Ele encontra a ponte sozinho. Clique em Conectar pela ponte.

Etapa 3: copie o arquivo (execute uma vez)

Windows (PowerShell; pressione a tecla Windows, digite powershell e pressione Enter):

New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\SQLiteViewerBridgePython" | Out-Null; Copy-Item "$env:USERPROFILE\Downloads\adb-bridge.py" "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py"

Windows (Prompt de Comando; pressione a tecla Windows, digite cmd e pressione Enter):

mkdir "%LOCALAPPDATA%\SQLiteViewerBridgePython" & copy "%USERPROFILE%\Downloads\adb-bridge.py" "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

macOS (Terminal):

mkdir -p "$HOME/Library/Application Support/SQLiteViewerBridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py"

Linux:

mkdir -p "$HOME/.local/share/sqliteviewer-bridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py"

Etapa 4: faça-o iniciar sozinho no login (execute uma vez)

Windows (PowerShell):

python "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

Windows (Prompt de Comando):

python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

macOS:

python3 "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py" --add-to-startup

Linux:

python3 "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py" --add-to-startup

No Windows, isso cria um atalho oculto na pasta Inicializar; no macOS, um Launch Agent; e no Linux, um serviço de usuário do systemd (ou uma entrada de inicialização automática da área de trabalho). Nenhum deles precisa de direitos de administrador. Deixe o arquivo onde está; se você movê-lo, execute o comando de novo.

Com pressa? Um comando faz as etapas 3 e 4

Abra um terminal na pasta onde você baixou o arquivo e execute:

python adb-bridge.py --install      # Windows
python3 adb-bridge.py --install     # macOS and Linux

Prefere adicioná-lo à inicialização manualmente?

Windows: pressione Win + R, digite shell:startup e pressione Enter. Na pasta que abrir, clique com o botão direito, escolha Novo → Atalho e defina o local como:

pythonw "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

Dê o nome SQLite Viewer ADB Bridge. Usar pythonw em vez de python evita a janela preta. Saia e entre de novo, ou dê um duplo clique no atalho para iniciá-lo agora.

macOS: o comando acima cria ~/Library/LaunchAgents/com.sqliteviewer.adbbridge.plist. Linux: ele cria ~/.config/systemd/user/sqliteviewer-bridge.service (ou ~/.config/autostart/sqliteviewer-bridge.desktop). É possível escrever esses arquivos à mão, mas o comando é mais seguro.

Verificar, parar e remover

python adb-bridge.py --status                  # is it running?
python adb-bridge.py --remove-from-startup      # stop starting at sign-in (keeps the file)
python adb-bridge.py --uninstall                # stop it and delete everything
# add the full path to the file if you are not in its folder, as in the commands above

Tenho o ADB? Instale se não tiver

A ponte repassa para o ADB (Android Platform Tools). O Android Studio já o inclui, então, se você usa o Android Studio, pode pular esta seção. Para verificar, abra um terminal e execute adb version. Se o sistema não reconhecer o comando, instale o ADB com um dos comandos abaixo. O SQLite Viewer também avisa quando a ponte está em execução mas não encontra o ADB. A ponte procura o ADB no seu PATH e nas pastas usuais do Android Studio, winget, Homebrew e downloads manuais, então você não precisa alterar o PATH, e ela inicia o servidor ADB para você.

Windows

O mais fácil (Windows 10 e 11, PowerShell ou Prompt de Comando):

winget install --id Google.PlatformTools -e

Sem winget? Baixe diretamente (PowerShell):

Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile "$env:TEMP\pt.zip"; Expand-Archive "$env:TEMP\pt.zip" "$env:LOCALAPPDATA\Android\Sdk" -Force; Remove-Item "$env:TEMP\pt.zip"

O mesmo no Prompt de Comando:

powershell -NoProfile -Command "Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile \"$env:TEMP\pt.zip\"; Expand-Archive \"$env:TEMP\pt.zip\" \"$env:LOCALAPPDATA\Android\Sdk\" -Force; Remove-Item \"$env:TEMP\pt.zip\""

Verifique se funcionou (PowerShell):

& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" version

macOS

Com o Homebrew:

brew install --cask android-platform-tools

Sem o Homebrew:

mkdir -p "$HOME/Library/Android/sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-darwin.zip && unzip -o /tmp/pt.zip -d "$HOME/Library/Android/sdk" && rm /tmp/pt.zip

Linux

Debian, Ubuntu, Mint:

sudo apt install adb

Fedora:

sudo dnf install android-tools

Arch, Manjaro:

sudo pacman -S android-tools

Qualquer outra distribuição:

mkdir -p "$HOME/Android/Sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-linux.zip && unzip -o /tmp/pt.zip -d "$HOME/Android/Sdk" && rm /tmp/pt.zip

Depois, prepare o telefone

  1. No telefone, abra Configurações → Sobre o telefone e toque em Número da versão sete vezes.
  2. Abra Configurações → Opções do desenvolvedor e ative a Depuração USB.
  3. Conecte o telefone e toque em Permitir no aviso. Executar adb devices deve listá-lo como device.

Preciso configurar alguma coisa?

Não. A ponte só aceita conexões do site do SQLite Viewer, escuta apenas no seu próprio computador (127.0.0.1) e só repassa para o servidor ADB do mesmo computador. Nada é armazenado ou enviado para outro lugar.

Você só precisa de uma configuração em dois casos:

  • Você usa o SQLite Viewer de outro endereço (sua própria cópia, ou localhost durante o desenvolvimento). Permita esse endereço nos mesmos comandos:
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --allow-origin https://your-address.example
  • A porta 5038 já está em uso. Use outra porta e depois informe a mesma porta em Avançado no painel Android:
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --port 5040

Os endereços permitidos ficam salvos em um arquivo chamado origins.txt (um endereço por linha) ao lado da ponte: no Windows, %LOCALAPPDATA%\SQLiteViewerBridge (instalador) ou %LOCALAPPDATA%\SQLiteViewerBridgePython (Python); no macOS, ~/Library/Application Support/SQLiteViewerBridge; no Linux, ~/.local/share/sqliteviewer-bridge.

Solução de problemas

  • “A ponte não está em execução neste computador”: execute o instalador ou os comandos acima, ou saia e entre de novo. Depois reabra o painel Android.
  • Não tenho Python: no Windows você não precisa dele, use o instalador de um clique acima. Caso contrário, instale o Python 3 do python.org (Windows: marque Add Python to PATH) ou, no macOS, aceite a oferta de instalar as Command Line Tools. Depois execute os comandos novamente.
  • python não é reconhecido ou abre a Microsoft Store (Windows): o Python ainda não está instalado ou a opção PATH foi esquecida. Instale pelo python.org ou substitua python por py nos comandos. Você também pode desativar o atalho da Store em Configurações → Aplicativos → Configurações avançadas de aplicativos → Aliases de execução de aplicativo.
  • O comando de cópia diz que o arquivo não foi encontrado: o navegador salvou adb-bridge.py em outro lugar que não Downloads. Altere essa parte do comando ou renomeie um arquivo .txt.
  • “Something is already listening on port 5038”: há outra ponte em execução. Remova a antiga (--uninstall ou uninstall.cmd) ou escolha outra porta com --port.
  • A ponte funciona, mas nenhum telefone aparece: o servidor ADB precisa enxergar o telefone. Execute adb devices, ative a depuração USB e aceite o aviso “Permitir depuração USB” no telefone.
  • “The bridge is running, but ADB is not installed”: instale o ADB com os comandos da seção Tenho o ADB? acima (ou instale o Android Studio). A página percebe sozinha alguns segundos depois.
  • O Chrome pede permissão para acessar dispositivos na sua rede: permita. É assim que a página alcança a ponte no seu próprio computador.
  • O antivírus ou o Windows bloqueia o instalador: o instalador apenas cria um pequeno programa a partir de um código-fonte que você pode ler e grava nas suas próprias pastas de usuário. Permita-o ou use o caminho do Python.
