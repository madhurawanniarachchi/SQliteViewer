Gere um diagrama ER a partir do SQLite

Transforme um banco de dados desconhecido em um mapa legível de tabelas, colunas, tipos, chaves primárias e conexões de chave estrangeira.

Abrir a ferramenta de diagrama ER

Crie o diagrama

  1. Abra o banco de dados SQLite no visualizador.
  2. Selecione Diagrama ER na barra lateral de tabelas.
  3. Use Ajustar para trazer todas as entidades para a área visível da caixa de diálogo.
  4. Inspecione os nomes das colunas, os tipos de dados do SQLite e os marcadores de chave de cada entidade.

As linhas de relacionamento são derivadas das chaves estrangeiras declaradas no SQLite. Se uma relação lógica não for definida com uma restrição de chave estrangeira, um leitor de esquema não consegue identificá-la de forma confiável apenas pelos nomes das colunas.

Como ler o resultado

  • PK identifica uma coluna de chave primária usada para endereçar uma linha de forma única.
  • FK identifica uma coluna que referencia uma chave em outra tabela.
  • Os tipos de coluna mostram o tipo declarado no SQLite. Como o sistema de tipos do SQLite é flexível, os valores armazenados às vezes podem diferir dessa declaração.
  • As linhas de conexão mostram as entidades referenciadas e as que referenciam.
Um diagrama é mais útil quando o banco de dados declara chaves primárias e estrangeiras de forma consistente. Linhas ausentes costumam indicar restrições ausentes, e não um problema de renderização.

Exporte o esquema

Depois de revisar o diagrama, exporte o esquema como SQL DDL, DBML, Mermaid ou GraphQL SDL. O SQL DDL é o mais próximo da definição original do banco. DBML e Mermaid são úteis para documentação. O GraphQL SDL é um ponto de partida para um modelo de API e pode exigir ajustes específicos da aplicação.

Perguntas úteis para a revisão

Procure tabelas sem chaves primárias, chaves estrangeiras apontando para entidades inesperadas, nomes inconsistentes, colunas que aceitam nulos mas deveriam ser obrigatórias e tabelas de junção que representam relações muitos-para-muitos. Essas verificações ajudam ao herdar o banco de dados de uma aplicação ou ao planejar uma migração.
