Exportar para Excel

Exportar uma tabela do SQLite para Excel

  1. Abra seu arquivo .db, .sqlite, .sqlite3 ou .db3 no SQLite Viewer. Ele permanece no seu navegador.
  2. Selecione uma tabela ou escreva uma consulta que retorne exatamente as linhas de que você precisa.
  3. Clique em Exportar acima dos resultados e escolha as colunas a incluir.
  4. Escolha Excel e o arquivo é baixado imediatamente.

Use SQL antes de exportar

Filtre, ordene, agregue ou junte tabelas com SQL primeiro e depois exporte o resultado. O Excel recebe exatamente as linhas e colunas selecionadas, e o nome da tabela é usado como nome da planilha.

A exportação para Excel carrega sua biblioteca de planilhas sob demanda, então a primeira exportação precisa de conexão com a internet. Seu banco de dados continua sem sair do navegador.

Seus dados nunca saem do seu dispositivo

A conversão é executada como JavaScript na aba do seu navegador. O banco de dados não é enviado a um servidor, portanto é seguro usá-lo com dados de clientes, bancos de dados de apps e arquivos internos.

Importe do Excel também

O SQLite Viewer também pode importar um arquivo .xlsx ou .xls para um novo banco de dados SQLite, para que você consulte uma planilha com SQL. Prefere um formato de texto simples? Experimente CSV ou JSON.
