Como abrir um arquivo SQLite online com segurança

Inspecione um banco de dados SQLite local no navegador sem instalar software de desktop nem enviar o arquivo a um servidor remoto.

Abrir o SQLite Viewer

Abra seu banco de dados em três etapas

  1. Abra o SQLite Viewer em um navegador de desktop moderno.
  2. Solte o banco de dados no cartão inicial ou clique nele e selecione um arquivo .db, .sqlite, .sqlite3 ou .db3.
  3. Selecione uma tabela na barra lateral. O visualizador cria uma aba de consulta e exibe a primeira página de linhas.
Privacidade: o arquivo é lido localmente pelo JavaScript do navegador. Não é preciso enviá-lo para inspecionar tabelas, executar SQL ou gerar um diagrama ER.

O que você pode inspecionar

A lista de tabelas dá acesso rápido a tabelas e views. Você pode pesquisar esquemas longos, ordenar tabelas por várias medidas, inspecionar informações das colunas, controlar quais colunas ficam visíveis e fixar colunas ao revisar resultados largos.

Para um trabalho mais detalhado, use o editor SQL. Uma consulta básica é assim:

SELECT *
FROM "customers"
LIMIT 0, 30;

Se o arquivo não abrir

  • Confirme que é um banco de dados SQLite de verdade e não um dump de texto SQL.
  • Tente renomear uma extensão incomum para .db para que ela apareça no seletor de arquivos.
  • Verifique se o arquivo está criptografado; um banco de dados criptografado exige a extensão ou a chave correspondente e não pode ser lido como SQLite comum.
  • Para arquivos muito grandes, feche as abas do navegador que consomem muita memória antes de tentar de novo.

Salve ou exporte suas descobertas

Os resultados das consultas podem ser exportados em formatos comuns. Se você editar linhas ou executar instruções de gravação, use Salvar BD para baixar o banco de dados atual. O arquivo local original não é sobrescrito silenciosamente.
