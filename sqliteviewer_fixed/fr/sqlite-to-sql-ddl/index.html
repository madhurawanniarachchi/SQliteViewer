Convertir un schéma SQLite en SQL DDL

Extrayez des définitions de schéma lisibles pour la documentation, la revue, la planification de migrations ou le contrôle de version.

Ouvrir l'exportateur de schéma SQLite

Exporter du SQL DDL depuis un fichier de base de données

  1. Ouvrez la base SQLite.
  2. Ouvrez le diagramme ER.
  3. Sélectionnez SQL DDL comme format d'export.
  4. Exportez et enregistrez le texte du schéma généré.

Le résultat représente la structure de la base de données, pas les données des tables. Il comprend les définitions d'entités, les types de colonnes déclarés et les informations de clés pouvant être déduites des métadonnées du schéma SQLite.

Exemple de sortie

CREATE TABLE "orders" (
  "id" INTEGER PRIMARY KEY,
  "customer_id" INTEGER NOT NULL,
  "created_at" TEXT,
  FOREIGN KEY ("customer_id") REFERENCES "customers" ("id")
);

À quoi sert le SQL DDL

  • Relire un schéma de base de données lors d'une revue de code.
  • Conserver les changements de structure dans le contrôle de version.
  • Documenter les tables sans exposer les lignes de production.
  • Préparer une migration vers un autre système de base de données.
  • Comparer les définitions de tables attendues et réelles.
Remarque sur la migration : la syntaxe et l'affinité de types de SQLite diffèrent de PostgreSQL, MySQL et SQL Server. Considérez le DDL exporté comme une description fiable du schéma SQLite, puis adaptez les types, le comportement de l'auto-incrément, les guillemets et les contraintes au moteur cible.

Export du schéma ou enregistrement de la base

Le SQL DDL ne contient que la structure. Si vous avez besoin de la base avec ses lignes et ses modifications locales, utilisez Enregistrer la BD. Si vous avez besoin des lignes dans un format texte portable, utilisez les commandes d'export des résultats.
