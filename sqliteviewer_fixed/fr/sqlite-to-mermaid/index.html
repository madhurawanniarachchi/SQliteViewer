Créer la syntaxe Mermaid

  1. Ouvrez le fichier SQLite.
  2. Lancez le diagramme ER pour vérifier les entités et les relations.
  3. Sélectionnez Mermaid et exportez le schéma.
  4. Collez le résultat dans un Markdown ou un système de documentation compatible Mermaid.

Avantages des diagrammes textuels

La syntaxe Mermaid peut être versionnée, relue comme du texte et régénérée quand le schéma change. Elle est utile dans les README de projets, la documentation d'architecture et les notes techniques, où un fichier de diagramme binaire serait difficile à maintenir.

Comprendre les limites des relations

Le convertisseur lit les clés étrangères déclarées. Il ne peut pas inventer de relations de façon fiable à partir de noms de colonnes similaires. Si un lien attendu manque, inspectez le schéma SQLite et vérifiez que la relation est déclarée par une contrainte de clé étrangère.

Les moteurs de rendu Mermaid peuvent différer légèrement selon les plateformes. Testez la syntaxe exportée dans le système de documentation où elle sera publiée.

Gardez des diagrammes ciblés

Les grandes bases peuvent produire des diagrammes surchargés. Envisagez de documenter séparément des domaines délimités — par exemple l'authentification, la facturation ou l'inventaire — tout en gardant un export complet du schéma comme référence.
