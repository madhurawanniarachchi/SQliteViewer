Modifiez les lignes avec protection par clé primaire

Ouvrez une base de données et sélectionnez une table. Lorsque la table possède une clé primaire exploitable, le résultat propose des actions pour modifier et supprimer chaque ligne. L'éditeur utilise les valeurs de clé primaire pour cibler la bonne ligne plutôt que de se fier à sa position affichée.

  1. Choisissez Modifier sur la ligne.
  2. Changez les valeurs de champ nécessaires. Utilisez l'option null lorsque la colonne l'autorise.
  3. Enregistrez la ligne et vérifiez le résultat mis à jour.
  4. Choisissez Enregistrer la BD pour télécharger la base une fois terminé.
Important : les modifications s'appliquent à la base conservée en mémoire dans le navigateur. Elles n'écrasent pas automatiquement le fichier d'origine. Téléchargez la dernière base avant de fermer la page.

Utilisez SQL pour les changements en masse

L'espace de requêtes prend aussi en charge les instructions d'écriture SQLite. Par exemple :

UPDATE "products"
SET "active" = 0
WHERE "last_order_at" < '2025-01-01';

Relisez attentivement la condition WHERE avant d'exécuter une mise à jour ou une suppression. Une bonne pratique consiste à exécuter d'abord la même condition en SELECT, à vérifier les lignes concernées, puis seulement à lancer la requête d'écriture.

Qu'est-ce qui peut empêcher la modification de lignes ?

Les actions sûres sur les lignes exigent que la visionneuse identifie les enregistrements de façon fiable. Les tables sans clé primaire peuvent s'afficher en lecture seule dans l'interface des lignes. Les vues, résultats calculés, jointures et requêtes d'agrégation ne peuvent généralement pas être rattachés en toute sécurité à une seule ligne source, même si vous pouvez toujours les inspecter ou les exporter.

Téléchargez la base terminée

L'action Enregistrer la BD exporte l'état actuel de la base SQLite, y compris les modifications de lignes et les requêtes d'écriture réussies. Conservez l'original comme sauvegarde jusqu'à ce que vous ayez testé le fichier téléchargé dans l'application qui l'utilise.
