Créez un classeur Excel à partir de n'importe quelle table ou résultat de requête pour vos rapports, vos partages et vos analyses.

Exporter vers Excel

Exporter une table SQLite vers Excel

  1. Ouvrez votre fichier .db, .sqlite, .sqlite3 ou .db3 dans SQLite Viewer. Il reste dans votre navigateur.
  2. Sélectionnez une table, ou écrivez une requête qui renvoie exactement les lignes dont vous avez besoin.
  3. Cliquez sur Exporter au-dessus des résultats et choisissez les colonnes à inclure.
  4. Choisissez Excel et le fichier se télécharge immédiatement.

Utilisez SQL avant d'exporter

Filtrez, triez, agrégez ou joignez des tables avec SQL d'abord, puis exportez le résultat. Excel reçoit exactement les lignes et colonnes sélectionnées, et le nom de la table sert de nom de feuille.

L'export Excel charge sa bibliothèque de tableur à la demande ; le premier export Excel nécessite donc une connexion internet. Votre base de données ne quitte toujours pas votre navigateur.

Vos données ne quittent jamais votre appareil

La conversion s'exécute en JavaScript dans l'onglet de votre navigateur. La base de données n'est pas envoyée à un serveur ; vous pouvez donc l'utiliser en toute sécurité avec des données clients, des bases d'applications et des fichiers internes.

Importez aussi depuis Excel

SQLite Viewer peut aussi importer un fichier .xlsx ou .xls dans une nouvelle base SQLite, pour interroger un tableur avec SQL. Vous préférez un format texte brut ? Essayez CSV ou JSON.
