Quand un outil de navigateur est utile

Une visionneuse web est pratique pour une inspection ponctuelle, le support, les exercices en classe, les bases d'applications exportées et les environnements où l'on ne peut pas installer de logiciel. L'application se charge depuis le web, mais la base sélectionnée est traitée localement dans le navigateur.

Fonctionnalités disponibles sans installation

  • Rechercher et parcourir les tables et vues.
  • Exécuter des instructions SELECT et inspecter des résultats paginés.
  • Utiliser plusieurs onglets de requêtes et de bases de données.
  • Ajouter, modifier ou supprimer des lignes identifiables en toute sécurité.
  • Générer un diagramme ER avec colonnes, types et clés.
  • Exporter les résultats ou les formats de schéma.
  • Télécharger la base de données modifiée actuelle.

Outil de navigateur ou application de bureau ?

Une application de bureau reste préférable pour les bases extrêmement volumineuses, les extensions de chiffrement, l'administration continue en production, l'analyse avancée des index ou le verrouillage direct du système de fichiers. Un outil de navigateur est le plus efficace quand vous privilégiez la rapidité, la portabilité et le traitement local d'un fichier SQLite ordinaire.

Comme la base réside dans la mémoire du navigateur, conservez le fichier d'origine et téléchargez les modifications avant de fermer ou d'actualiser la page.

Considérations de confidentialité

Vérifiez que la page est servie en HTTPS et utilisez une copie fiable de l'application. SQLite Viewer n'exige pas d'envoyer la base, mais les extensions du navigateur et l'appareil lui-même font partie de votre environnement de sécurité.
