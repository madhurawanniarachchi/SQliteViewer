Convertir SQLite en DBML

Transformez un schéma SQLite existant en DBML lisible pour la documentation et les flux de conception de bases de données.

Ouvrir l'exportateur DBML

Générer du DBML à partir d'un fichier SQLite

  1. Ouvrez votre base de données dans SQLite Viewer.
  2. Choisissez Diagramme ER.
  3. Sélectionnez DBML dans la liste des formats d'export.
  4. Exportez le texte généré et examinez-le dans votre outil DBML préféré.

Ce que comprend la conversion

L'export décrit les tables, noms de colonnes, types de données SQLite déclarés, clés primaires et relations de clés étrangères déclarées. Il donne aux outils de conception assez de structure pour afficher un modèle utile sans exposer les lignes des tables.

Table orders {
  id integer [pk]
  customer_id integer [not null]
  created_at text
}

Ref: orders.customer_id > customers.id

Pourquoi utiliser DBML ?

Le DBML est plus facile à relire qu'un binaire de base de données et plus centré sur la modélisation que le SQL exécutable. Les équipes l'utilisent pour discuter des schémas, créer des diagrammes, documenter les relations et planifier les changements avant d'écrire des migrations.

Le DBML est une représentation de conception, pas une sauvegarde octet par octet de la base. Conservez le fichier SQLite d'origine et utilisez Enregistrer la BD quand vous avez besoin d'une base fonctionnelle avec ses données.

Vérifiez le modèle généré

SQLite autorise des déclarations de type souples et les schémas peuvent omettre des clés étrangères. Vérifiez les types personnalisés, les contraintes composites, les colonnes générées, les index et les relations qui n'existent que dans le code de l'application. Ajoutez des annotations de conception après l'export si nécessaire.
