Convertir SQLite en JSON

Exportez les lignes sous forme de tableau JSON d'objets, prêt pour les API, les prototypes front-end, les jeux de test et les bases documentaires.

Exporter en JSON

Exporter une table SQLite en JSON

  1. Ouvrez votre fichier .db, .sqlite, .sqlite3 ou .db3 dans SQLite Viewer. Il reste dans votre navigateur.
  2. Sélectionnez une table, ou écrivez une requête qui renvoie exactement les lignes dont vous avez besoin.
  3. Cliquez sur Exporter au-dessus des résultats et choisissez les colonnes à inclure.
  4. Choisissez JSON et le fichier se télécharge immédiatement.

À quoi ressemble le JSON

Chaque ligne devient un objet dont les clés sont les noms de colonnes, et le fichier est un tableau de ces objets.

[
  { "id": 1, "name": "Ada", "email": "ada@example.com" },
  { "id": 2, "name": "Linus", "email": "linus@example.com" }
]

Façonnez la sortie avec SQL

Utilisez une requête pour renommer des colonnes avec AS, joindre des tables liées ou filtrer des lignes avant l'export, afin que le JSON corresponde à la structure attendue par votre application.

Vos données ne quittent jamais votre appareil

La conversion s'exécute en JavaScript dans l'onglet de votre navigateur. La base de données n'est pas envoyée à un serveur ; vous pouvez donc l'utiliser en toute sécurité avec des données clients, des bases d'applications et des fichiers internes.
