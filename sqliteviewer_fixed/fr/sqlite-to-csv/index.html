Convertir SQLite en CSV

Transformez une table ou n'importe quel résultat de requête SQL en fichier CSV que vous pouvez ouvrir dans Excel, Google Sheets ou importer dans une autre base.

Exporter en CSV

Exporter une table SQLite en CSV

  1. Ouvrez votre fichier .db, .sqlite, .sqlite3 ou .db3 dans SQLite Viewer. Il reste dans votre navigateur.
  2. Sélectionnez une table, ou écrivez une requête qui renvoie exactement les lignes dont vous avez besoin.
  3. Cliquez sur Exporter au-dessus des résultats et choisissez les colonnes à inclure.
  4. Choisissez CSV et le fichier se télécharge immédiatement.

N'exportez que ce dont vous avez besoin

Comme l'export suit la requête en cours, vous pouvez d'abord filtrer avec WHERE, joindre des tables, trier ou limiter les lignes, puis exporter exactement ce résultat. Le sélecteur de colonnes permet d'exclure les colonnes dont vous ne voulez pas dans le fichier.

Astuce : pour exporter une table entière, sélectionnez-la et retirez tout LIMIT de la requête avant de cliquer sur Exporter.

Vos données ne quittent jamais votre appareil

La conversion s'exécute en JavaScript dans l'onglet de votre navigateur. La base de données n'est pas envoyée à un serveur ; vous pouvez donc l'utiliser en toute sécurité avec des données clients, des bases d'applications et des fichiers internes.

Quand utiliser le CSV

Le CSV est le format le plus portable pour les tableurs, les outils de BI et les imports en masse. Si vous avez besoin de valeurs typées ou de données imbriquées, utilisez JSON ; pour un classeur mis en forme, utilisez Excel.
