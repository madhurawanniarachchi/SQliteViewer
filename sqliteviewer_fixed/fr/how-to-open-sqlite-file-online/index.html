Pour commencer

Comment ouvrir un fichier SQLite en ligne en toute sécurité

Inspectez une base SQLite locale dans votre navigateur sans installer de logiciel de bureau ni envoyer le fichier à un serveur distant.

Ouvrir SQLite Viewer

Ouvrez votre base en trois étapes

  1. Ouvrez SQLite Viewer dans un navigateur de bureau moderne.
  2. Déposez votre base sur la carte d'accueil, ou cliquez dessus et sélectionnez un fichier .db, .sqlite, .sqlite3 ou .db3.
  3. Sélectionnez une table dans la barre latérale. La visionneuse crée un onglet de requête et affiche la première page de lignes.
Confidentialité : le fichier est lu localement par le JavaScript du navigateur. Il n'a pas besoin d'être envoyé pour inspecter les tables, exécuter du SQL ou générer un diagramme ER.

Ce que vous pouvez inspecter

La liste des tables donne un accès rapide aux tables et aux vues. Vous pouvez rechercher dans de longs schémas, trier les tables selon plusieurs mesures, consulter les informations de colonnes, contrôler les colonnes visibles et épingler des colonnes pour examiner de larges jeux de résultats.

Pour un travail plus détaillé, utilisez l'éditeur SQL. Une requête de base ressemble à ceci :

SELECT *
FROM "customers"
LIMIT 0, 30;

Si le fichier ne s'ouvre pas

  • Vérifiez qu'il s'agit bien d'une base SQLite et non d'un export texte SQL.
  • Essayez de renommer une extension inhabituelle en .db pour qu'elle apparaisse dans le sélecteur de fichiers.
  • Vérifiez si le fichier est chiffré ; une base chiffrée nécessite l'extension ou la clé correspondante et ne peut pas être lue comme du SQLite ordinaire.
  • Pour les fichiers très volumineux, fermez les onglets gourmands en mémoire avant de réessayer.

Enregistrez ou exportez vos résultats

Les résultats des requêtes peuvent être exportés dans des formats courants. Si vous modifiez des lignes ou exécutez des instructions d'écriture, utilisez Enregistrer la BD pour télécharger la base actuelle. Le fichier local d'origine n'est pas écrasé en silence.
