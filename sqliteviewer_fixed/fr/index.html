Android Studio keeps the USB connection busy, so this mode talks to its ADB server through a small helper (the bridge) that runs on your computer. Set it up once and it starts by itself from then on.

Do you have ADB? Install it if not

The bridge talks to ADB (Android Platform Tools). Android Studio already includes it. If you do not use Android Studio, install ADB with one of these commands. Open a terminal first.

Your terminal:

On the phone: open Settings → About phone, tap Build number 7 times, then Settings → Developer options → turn on USB debugging. Plug the phone in and tap Allow when it asks.

You opened this page from a file, so browsers hide its origin ('null') and the bridge must allow every local file page. It is safer to serve the folder with python -m http.server 8000 and open http://localhost:8000 instead.

Advanced
  • Enable USB debugging on the phone and accept the prompt when connecting.
  • Only debuggable apps (debug builds) can be read. Release apps are protected by Android.
  • If the device is busy, run adb kill-server and close Android Studio, then connect again.
  • Use Chrome or Edge on desktop. The view is read-only and re-copies the file on each refresh.

Espace de travail de base de données privé dans le navigateur

Inspectez et modifiez des fichiers SQLite sans envoyer vos données

SQLite Viewer s'exécute directement dans votre navigateur. Ouvrez un fichier local .db, .sqlite, .sqlite3 ou .db3, explorez son schéma et ses lignes, exécutez du SQL, effectuez des modifications et téléchargez la dernière base de données — le tout sans envoyer le fichier à un serveur.

Parcourez et recherchez les tables

Naviguez dans de grands schémas, triez la liste des tables par nom, lignes, cellules ou taille estimée, et épinglez les colonnes de résultat importantes.

Modifiez de vraies lignes de base de données

Ajoutez, mettez à jour et supprimez des lignes grâce à des contrôles tenant compte de la clé primaire. Les modifications restent dans la base du navigateur jusqu'au téléchargement.

Un espace SQL à onglets multiples

Ouvrez un nouvel onglet pour chaque table ou requête, passez d'une base à l'autre et gardez chaque résultat lié à sa requête.

Générez un diagramme ER

Visualisez les entités, colonnes, types de données, clés primaires et relations de clés étrangères, puis ajustez le diagramme à la fenêtre.

Exportez le schéma et les résultats

Exportez les schémas ER en SQL DDL, DBML, Mermaid ou GraphQL SDL, et les résultats de requêtes dans des formats de données courants.

Enregistrez le fichier SQLite modifié

Les modifications sont appliquées localement. Choisissez Enregistrer la BD quand vous voulez télécharger la base actuelle sous forme de fichier SQLite utilisable.

Questions fréquentes

FAQ de SQLite Viewer

Ma base de données SQLite est-elle envoyée ?

Non. La base est ouverte et traitée localement par JavaScript dans votre navigateur. L'outil n'a pas besoin d'envoyer le fichier pour l'inspecter.

Puis-je modifier et enregistrer une base SQLite ?

Oui. Vous pouvez modifier les lignes des tables prises en charge ou exécuter des requêtes d'écriture, puis utiliser Enregistrer la BD pour télécharger l'état le plus récent.

Quelles extensions de fichier SQLite sont prises en charge ?

Le sélecteur de fichiers accepte .db, .sqlite, .sqlite3 et .db3. Une base SQLite valide peut utiliser une autre extension, mais il faudra peut-être la renommer avant de la sélectionner.

Fonctionne-t-il avec de grandes bases de données ?

Les gros fichiers dépendent de la mémoire disponible du navigateur. La visionneuse limite les lignes affichées et échantillonne les métadonnées de table coûteuses pour rester réactive.
