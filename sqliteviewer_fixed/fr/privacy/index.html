Confidentialité

Votre base de données reste dans votre navigateur

SQLite Viewer est conçu pour ouvrir et traiter les fichiers de base de données sélectionnés sur l'appareil de l'utilisateur plutôt que d'envoyer leur contenu pour un traitement côté serveur.

Traitement local de la base de données

Lorsque vous sélectionnez un fichier SQLite, le JavaScript du navigateur le lit dans la mémoire locale. La navigation dans les tables, l'exécution de SQL, la modification de lignes, l'inspection du schéma et l'export de la base ont lieu dans la session du navigateur. L'application n'a pas besoin de transmettre le fichier sélectionné à un serveur pour fournir ces fonctionnalités.

Ce que le site peut recevoir

Comme la plupart des sites, l'infrastructure d'hébergement peut recevoir des informations de requête ordinaires telles que l'adresse IP, le type de navigateur, les pages demandées, les horodatages et les journaux d'erreurs. Le site peut utiliser des outils d'analyse pour comprendre les visites et l'usage général. Les noms de fichiers de base de données, le contenu des tables et le texte des requêtes SQL ne devraient pas être envoyés volontairement comme événements d'analyse.

Stockage du navigateur

L'application peut utiliser le stockage du navigateur pour des préférences locales et des informations d'espace de travail, comme les onglets de requêtes ou l'historique des requêtes. Ces informations restent associées au profil du navigateur jusqu'à ce que l'utilisateur ou le navigateur les efface.

Téléchargements et fichiers d'origine

La modification s'effectue sur la base en mémoire. Enregistrer la BD crée un téléchargement de l'état actuel. L'application ne remplace pas silencieusement le fichier de base de données d'origine sur le disque.

Vos responsabilités

Utilisez des bases de données auxquelles vous êtes autorisé à accéder. Tenez compte de la sécurité de l'appareil, du profil du navigateur et des extensions installées lorsque vous ouvrez des fichiers sensibles. Effacez le stockage du navigateur et les copies téléchargées lorsque vous travaillez sur un appareil partagé.

Ressources tierces

La page peut charger des bibliothèques, des outils d'analyse ou d'autres ressources web depuis des services tiers. Ces services peuvent recevoir les données habituelles des requêtes web, mais la base sélectionnée n'est pas volontairement incluse dans ces requêtes.

Pour des données très sensibles ou réglementées, utilisez un environnement et une configuration de navigateur approuvés par votre organisation et examinez le comportement réseau de l'application déployée avant de l'utiliser.

Questions

Les questions de confidentialité et de sécurité peuvent être adressées à l'exploitant du site, CodeMasterLk. Cette page doit être mise à jour lorsque le traitement des données par le service change.
