SQLite 파일을 온라인에서 안전하게 여는 방법

데스크톱 소프트웨어를 설치하거나 파일을 원격 서버로 보내지 않고 브라우저에서 로컬 SQLite 데이터베이스를 확인하세요.

SQLite Viewer 열기

세 단계로 데이터베이스 열기

  1. 최신 데스크톱 브라우저에서 SQLite Viewer를 엽니다.
  2. 데이터베이스를 시작 카드에 놓거나, 카드를 클릭하여 .db, .sqlite, .sqlite3 또는 .db3 파일을 선택합니다.
  3. 사이드바에서 테이블을 선택합니다. 뷰어가 쿼리 탭을 만들고 첫 페이지의 행을 표시합니다.
개인정보 보호: 파일은 브라우저 JavaScript가 로컬에서 읽습니다. 테이블 확인, SQL 실행, ER 다이어그램 생성을 위해 업로드할 필요가 없습니다.

확인할 수 있는 것

테이블 목록에서 테이블과 뷰에 빠르게 접근할 수 있습니다. 긴 스키마를 검색하고, 여러 기준으로 테이블을 정렬하고, 열 정보를 확인하고, 표시할 열을 제어하고, 넓은 결과 집합을 볼 때 열을 고정할 수 있습니다.

더 자세한 작업에는 SQL 편집기를 사용하세요. 기본적인 쿼리는 다음과 같습니다.

SELECT *
FROM "customers"
LIMIT 0, 30;

파일이 열리지 않을 때

  • SQL 텍스트 덤프가 아니라 실제 SQLite 데이터베이스인지 확인하세요.
  • 흔하지 않은 확장자는 .db로 이름을 바꾸면 파일 선택기에 표시됩니다.
  • 파일이 암호화되었는지 확인하세요. 암호화된 데이터베이스는 해당 확장 기능이나 키가 필요하며 일반 SQLite로 읽을 수 없습니다.
  • 매우 큰 파일은 메모리를 많이 쓰는 브라우저 탭을 닫은 뒤 다시 시도하세요.

결과 저장 또는 내보내기

쿼리 결과는 일반적인 형식으로 내보낼 수 있습니다. 행을 편집하거나 쓰기 문을 실행했다면 DB 저장으로 현재 데이터베이스를 다운로드하세요. 원본 로컬 파일은 조용히 덮어쓰이지 않습니다.
