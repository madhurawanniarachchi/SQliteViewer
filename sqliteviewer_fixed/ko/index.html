멀티 탭 SQL 작업 공간

테이블이나 쿼리마다 새 탭을 열고, 여러 데이터베이스 사이를 전환하며, 각 결과를 해당 쿼리와 연결된 상태로 유지하세요.

ER 다이어그램 생성

엔터티, 열, 데이터 형식, 기본 키, 외래 키 관계를 시각화하고 다이어그램을 창 크기에 맞출 수 있습니다.

스키마 및 결과 내보내기

ER 스키마를 SQL DDL, DBML, Mermaid, GraphQL SDL로, 쿼리 결과를 일반적인 데이터 형식으로 내보낼 수 있습니다.

실용적인 SQLite 가이드

작업 흐름을 배우거나 전문 도구를 열어 보세요

SQLite 파일을 온라인에서 여는 방법안전하고 단계별로 진행하는 브라우저 작업 흐름. 온라인 SQLite 편집기행을 편집하고 수정한 데이터베이스를 저장합니다. SQLite ER 다이어그램 생성기테이블, 키, 관계를 이해합니다. SQLite를 CSV로모든 테이블이나 쿼리 결과를 CSV로 내보냅니다. SQLite를 JSON으로행을 객체의 JSON 배열로 가져옵니다. SQLite를 Excel로데이터로 XLSX 통합 문서를 만듭니다. SQLite를 SQL DDL로이식 가능한 스키마 정의를 내보냅니다. SQLite를 DBML로스키마를 데이터베이스 설계 도구로 옮깁니다. SQLite를 Mermaid로텍스트 기반 ER 다이어그램을 만듭니다. SQLite를 GraphQL SDL로유용한 GraphQL 스키마 출발점을 생성합니다. Android SQLite 데이터베이스 보기내보낸 앱 데이터베이스를 안전하게 확인합니다. 설치 없는 SQLite 브라우저로컬 브라우저 도구가 적합한 경우를 알아봅니다. Android 앱 데이터베이스 실시간 편집실행 중인 디버그 앱의 행을 브라우저에서 변경합니다. 유용한 SQLite 쿼리테이블, 키, 중복, 쿼리 계획을 확인합니다.

SQLite Viewer FAQ

내 SQLite 데이터베이스가 업로드되나요?

아니요. 데이터베이스는 브라우저의 JavaScript로 로컬에서 열고 처리됩니다. 확인을 위해 파일을 업로드할 필요가 없습니다.

SQLite 데이터베이스를 편집하고 저장할 수 있나요?

네. 지원되는 테이블의 행을 편집하거나 쓰기 쿼리를 실행한 뒤, DB 저장으로 최신 상태를 다운로드할 수 있습니다.

어떤 SQLite 파일 확장자를 지원하나요?

파일 선택기는 .db, .sqlite, .sqlite3, .db3를 받습니다. 유효한 SQLite 데이터베이스가 다른 확장자를 쓸 수도 있지만, 선택 전에 이름을 바꿔야 할 수 있습니다.

대용량 데이터베이스에서도 작동하나요?

큰 파일은 브라우저의 사용 가능한 메모리에 따라 달라집니다. 뷰어는 렌더링되는 결과 행을 제한하고 비용이 큰 테이블 메타데이터는 샘플링하여 반응성을 유지합니다.
