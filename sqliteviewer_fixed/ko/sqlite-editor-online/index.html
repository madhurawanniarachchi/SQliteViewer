기본 키로 보호되는 행 편집

데이터베이스를 열고 테이블을 선택하세요. 테이블에 사용할 수 있는 기본 키가 있으면 결과에 개별 행을 편집하고 삭제하는 작업이 표시됩니다. 편집기는 화면상의 위치가 아니라 기본 키 값을 사용해 대상 행을 정확히 지정합니다.

  1. 행에서 편집을 선택합니다.
  2. 필요한 필드 값을 변경합니다. 열이 허용하면 null 옵션을 사용할 수 있습니다.
  3. 행을 저장하고 업데이트된 결과를 확인합니다.
  4. 완료되면 DB 저장을 선택해 데이터베이스를 다운로드합니다.
중요: 변경 사항은 브라우저 메모리에 있는 데이터베이스에 적용됩니다. 원본 파일을 자동으로 덮어쓰지 않습니다. 페이지를 닫기 전에 최신 데이터베이스를 다운로드하세요.

대량 변경에는 SQL 사용

쿼리 작업 공간은 SQLite 쓰기 문도 지원합니다. 예를 들면 다음과 같습니다.

UPDATE "products"
SET "active" = 0
WHERE "last_order_at" < '2025-01-01';

업데이트나 삭제를 실행하기 전에 WHERE 조건을 꼼꼼히 확인하세요. 먼저 같은 조건을 SELECT로 실행해 영향받는 행을 확인한 뒤 쓰기 쿼리를 실행하는 것이 좋은 방법입니다.

행 편집을 막을 수 있는 요인

안전한 행 작업을 하려면 뷰어가 레코드를 확실히 식별할 수 있어야 합니다. 기본 키가 없는 테이블은 행 인터페이스에서 읽기 전용으로 표시될 수 있습니다. 뷰, 계산된 결과, 조인, 집계 쿼리는 일반적으로 하나의 원본 행에 안전하게 대응시킬 수 없지만, 확인하거나 내보낼 수는 있습니다.

완성된 데이터베이스 다운로드

DB 저장 작업은 성공한 행 편집과 쓰기 쿼리를 포함한 현재 SQLite 데이터베이스 상태를 내보냅니다. 다운로드한 파일을 실제로 사용하는 애플리케이션에서 테스트하기 전까지 원본을 백업으로 보관하세요.
