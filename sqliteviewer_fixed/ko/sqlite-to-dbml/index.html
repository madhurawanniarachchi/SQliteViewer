DBML 내보내기 열기

SQLite 파일에서 DBML 생성

  1. SQLite Viewer에서 데이터베이스를 엽니다.
  2. ER 다이어그램을 선택합니다.
  3. 내보내기 형식 목록에서 DBML을 선택합니다.
  4. 생성된 텍스트를 내보내고 선호하는 DBML 도구에서 검토합니다.

변환에 포함되는 내용

내보내기에는 테이블, 열 이름, 선언된 SQLite 데이터 형식, 기본 키, 선언된 외래 키 관계가 담깁니다. 테이블 행을 노출하지 않고도 설계 도구가 유용한 모델을 그릴 수 있을 만큼의 구조를 제공합니다.

Table orders {
  id integer [pk]
  customer_id integer [not null]
  created_at text
}

Ref: orders.customer_id > customers.id

DBML을 사용하는 이유

DBML은 데이터베이스 바이너리보다 검토하기 쉽고, 실행 가능한 SQL보다 데이터 모델링에 집중되어 있습니다. 팀들은 스키마를 논의하고, 다이어그램을 만들고, 관계를 문서화하고, 마이그레이션을 작성하기 전에 변경을 계획하는 데 사용합니다.

DBML은 설계 표현이며 바이트 단위의 데이터베이스 백업이 아닙니다. 원본 SQLite 파일을 보관하고, 데이터가 포함된 작동하는 데이터베이스가 필요하면 DB 저장을 사용하세요.

생성된 모델 검토

SQLite는 유연한 형식 선언을 허용하며 스키마에 외래 키가 빠져 있을 수 있습니다. 사용자 정의 형식, 복합 제약 조건, 생성된 열, 인덱스, 애플리케이션 코드에만 존재하는 관계를 확인하세요. 필요하면 내보낸 뒤 설계 수준의 주석을 추가하세요.
