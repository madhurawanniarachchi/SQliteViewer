Excel로 내보내기

SQLite 테이블을 Excel로 내보내기

  1. .db, .sqlite, .sqlite3 또는 .db3 파일을 SQLite Viewer에서 엽니다. 파일은 브라우저 안에만 있습니다.
  2. 테이블을 선택하거나 필요한 행만 정확히 반환하는 쿼리를 작성합니다.
  3. 결과 위의 내보내기를 클릭하고 포함할 열을 선택합니다.
  4. Excel을 선택하면 파일이 바로 다운로드됩니다.

내보내기 전에 SQL 활용

먼저 SQL로 테이블을 필터링, 정렬, 집계 또는 조인한 다음 결과를 내보내세요. Excel은 선택한 행과 열을 그대로 받으며 테이블 이름이 시트 이름으로 사용됩니다.

Excel 내보내기는 스프레드시트 라이브러리를 필요할 때 불러오므로, 처음 Excel로 내보낼 때는 인터넷 연결이 필요합니다. 데이터베이스는 여전히 브라우저를 벗어나지 않습니다.

데이터가 기기 밖으로 나가지 않습니다

변환은 브라우저 탭에서 JavaScript로 실행됩니다. 데이터베이스가 서버에 업로드되지 않으므로 고객 데이터, 앱 데이터베이스, 내부 파일에도 안전하게 사용할 수 있습니다.

Excel에서 가져오기도 가능

SQLite Viewer는 .xlsx 또는 .xls 파일을 새 SQLite 데이터베이스로 가져올 수도 있어, 스프레드시트를 SQL로 조회할 수 있습니다. 일반 텍스트 형식을 선호하시나요? CSV 또는 JSON을 사용해 보세요.
