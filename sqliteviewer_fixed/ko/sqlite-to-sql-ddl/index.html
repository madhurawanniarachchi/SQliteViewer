SQLite 스키마를 SQL DDL로 변환

문서화, 검토, 마이그레이션 계획, 버전 관리에 쓸 읽기 쉬운 스키마 정의를 추출하세요.

SQLite 스키마 내보내기 열기

데이터베이스 파일에서 SQL DDL 내보내기

  1. SQLite 데이터베이스를 엽니다.
  2. ER 다이어그램을 엽니다.
  3. 내보내기 형식으로 SQL DDL을 선택합니다.
  4. 생성된 스키마 텍스트를 내보내고 저장합니다.

결과는 테이블 데이터가 아니라 데이터베이스 구조를 나타냅니다. 엔터티 정의, 선언된 열 형식, SQLite 스키마 메타데이터에서 유추할 수 있는 키 정보가 포함됩니다.

출력 예시

CREATE TABLE "orders" (
  "id" INTEGER PRIMARY KEY,
  "customer_id" INTEGER NOT NULL,
  "created_at" TEXT,
  FOREIGN KEY ("customer_id") REFERENCES "customers" ("id")
);

SQL DDL이 유용한 경우

  • 코드 리뷰에서 데이터베이스 스키마를 검토할 때.
  • 구조 변경을 버전 관리에 보관할 때.
  • 운영 데이터 행을 노출하지 않고 테이블을 문서화할 때.
  • 다른 데이터베이스 시스템으로 마이그레이션을 준비할 때.
  • 예상 테이블 정의와 실제 정의를 비교할 때.
마이그레이션 참고: SQLite의 구문과 형식 친화도는 PostgreSQL, MySQL, SQL Server와 다릅니다. 내보낸 DDL은 SQLite 스키마에 대한 신뢰할 수 있는 설명으로 취급하고, 대상 엔진에 맞게 형식, 자동 증가 동작, 따옴표 처리, 제약 조건을 조정하세요.

스키마 내보내기와 데이터베이스 저장의 차이

SQL DDL에는 구조만 들어 있습니다. 행과 로컬 편집 내용이 포함된 데이터베이스가 필요하다면 DB 저장을 사용하세요. 행을 이식 가능한 텍스트 형식으로 받으려면 결과 내보내기 기능을 사용하세요.
