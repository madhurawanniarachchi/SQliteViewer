SQLite를 JSON으로 변환

행을 객체의 JSON 배열로 내보내 API, 프런트엔드 프로토타입, 테스트 픽스처, 문서 데이터베이스에 바로 사용하세요.

JSON으로 내보내기

SQLite 테이블을 JSON으로 내보내기

  1. .db, .sqlite, .sqlite3 또는 .db3 파일을 SQLite Viewer에서 엽니다. 파일은 브라우저 안에만 있습니다.
  2. 테이블을 선택하거나 필요한 행만 정확히 반환하는 쿼리를 작성합니다.
  3. 결과 위의 내보내기를 클릭하고 포함할 열을 선택합니다.
  4. JSON을 선택하면 파일이 바로 다운로드됩니다.

JSON의 모습

각 행은 열 이름을 키로 갖는 객체가 되고, 파일은 이러한 객체의 배열이 됩니다.

[
  { "id": 1, "name": "Ada", "email": "ada@example.com" },
  { "id": 2, "name": "Linus", "email": "linus@example.com" }
]

SQL로 출력 형태 다듬기

내보내기 전에 쿼리로 AS를 이용해 열 이름을 바꾸거나 관련 테이블을 조인하거나 행을 필터링하면, JSON을 애플리케이션이 기대하는 구조에 맞출 수 있습니다.

데이터가 기기 밖으로 나가지 않습니다

변환은 브라우저 탭에서 JavaScript로 실행됩니다. 데이터베이스가 서버에 업로드되지 않으므로 고객 데이터, 앱 데이터베이스, 내부 파일에도 안전하게 사용할 수 있습니다.
