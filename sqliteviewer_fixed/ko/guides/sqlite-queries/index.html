SQLite 쿼리 가이드

SQLite 데이터베이스를 점검하는 데 유용한 쿼리

테이블, 인덱스, 관계, 데이터 품질을 이해해야 할 때는 안전하고 목적이 분명한 SQL부터 시작하세요.

SQL 작업 공간 열기

사용자 테이블과 뷰 나열

SELECT type, name, sql
FROM sqlite_master
WHERE type IN ('table', 'view')
  AND name NOT LIKE 'sqlite_%'
ORDER BY type, name;

테이블의 열 확인

PRAGMA table_info('orders');

각 열의 선언된 형식, NULL 허용 여부, 기본값, 기본 키에서의 위치를 반환합니다.

외래 키 검토

PRAGMA foreign_key_list('orders');
PRAGMA foreign_key_check;

첫 번째 문은 한 테이블에 선언된 참조를 설명합니다. 두 번째 문은 활성화된 외래 키 관계를 위반하는 행을 보고합니다.

중복 값 찾기

SELECT email, COUNT(*) AS occurrences
FROM customers
WHERE email IS NOT NULL
GROUP BY email
HAVING COUNT(*) > 1
ORDER BY occurrences DESC;

인덱스 확인

PRAGMA index_list('orders');

인덱스 이름을 찾은 뒤에는 PRAGMA index_info('index_name')으로 해당 열을 확인하세요.

쿼리 동작 확인

EXPLAIN QUERY PLAN
SELECT *
FROM orders
WHERE customer_id = 42
ORDER BY created_at DESC;

실행 계획을 보면 전체 테이블 스캔이 발생하는지, SQLite가 적절한 인덱스를 사용할 수 있는지 알 수 있습니다.

안전한 작업 방식: SELECT 또는 PRAGMA 점검 쿼리로 시작하세요. UPDATE나 DELETE 전에 같은 WHERE 조건으로 SELECT를 실행하고 데이터베이스 원본 사본을 보관하세요.

큰 테이블 페이지 넘기기

SELECT *
FROM events
ORDER BY id
LIMIT 100 OFFSET 0;

매우 큰 테이블을 반복해서 탐색할 때는 WHERE id > ? ORDER BY id LIMIT 100 같은 키셋 페이지네이션이 매우 큰 오프셋보다 효율적인 경우가 많습니다.
