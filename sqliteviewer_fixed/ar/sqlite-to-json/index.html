تحويل SQLite إلى JSON

صدّر الصفوف كمصفوفة JSON من الكائنات، جاهزة لواجهات API ونماذج الواجهة الأمامية الأولية وبيانات الاختبار وقواعد بيانات المستندات.

التصدير إلى JSON

تصدير جدول SQLite إلى JSON

  1. افتح ملف .db أو .sqlite أو .sqlite3 أو .db3 في SQLite Viewer. يبقى الملف داخل متصفحك.
  2. اختر جدولًا، أو اكتب استعلامًا يعيد الصفوف التي تحتاجها بالضبط.
  3. انقر على تصدير أعلى النتائج واختر الأعمدة المراد تضمينها.
  4. اختر JSON ويُنزَّل الملف فورًا.

كيف يبدو JSON

يصبح كل صف كائنًا مفاتيحه أسماء الأعمدة، والملف عبارة عن مصفوفة من هذه الكائنات.

[
  { "id": 1, "name": "Ada", "email": "ada@example.com" },
  { "id": 2, "name": "Linus", "email": "linus@example.com" }
]

شكّل المخرجات باستخدام SQL

استخدم استعلامًا لإعادة تسمية الأعمدة بـ AS أو ربط الجداول ذات الصلة أو تصفية الصفوف قبل التصدير، ليتطابق JSON مع البنية التي يتوقعها تطبيقك.

بياناتك لا تغادر جهازك أبدًا

يعمل التحويل بلغة JavaScript داخل علامة تبويب المتصفح. لا تُرفع قاعدة البيانات إلى خادم، لذا يمكن استخدامه بأمان مع بيانات العملاء وقواعد بيانات التطبيقات والملفات الداخلية.
