افتح SQLite Viewer

افتح قاعدة بياناتك في ثلاث خطوات

  1. افتح SQLite Viewer في متصفح حديث لسطح المكتب.
  2. أفلت قاعدة بياناتك على البطاقة الافتتاحية، أو انقر عليها واختر ملف .db أو .sqlite أو .sqlite3 أو .db3.
  3. اختر جدولًا من الشريط الجانبي. ينشئ العارض تبويب استعلام ويعرض الصفحة الأولى من الصفوف.
الخصوصية: يُقرأ الملف محليًا بواسطة JavaScript في المتصفح. لا حاجة إلى رفعه لفحص الجداول أو تنفيذ SQL أو إنشاء مخطط ER.

ما الذي يمكنك فحصه

توفر قائمة الجداول وصولًا سريعًا إلى الجداول والعروض. يمكنك البحث في المخططات الطويلة، وترتيب الجداول حسب عدة مقاييس، وفحص معلومات الأعمدة، والتحكم في الأعمدة المرئية، وتثبيت الأعمدة أثناء مراجعة مجموعات النتائج العريضة.

للعمل الأكثر تفصيلًا استخدم محرر SQL. يبدو الاستعلام الأساسي هكذا:

SELECT *
FROM "customers"
LIMIT 0, 30;

إذا لم يُفتح الملف

  • تأكد من أنه قاعدة بيانات SQLite حقيقية وليس نسخة نصية من SQL.
  • جرّب إعادة تسمية امتداد غير شائع إلى .db ليظهر في أداة اختيار الملفات.
  • تحقق مما إذا كان الملف مشفّرًا؛ فقاعدة البيانات المشفرة تتطلب الامتداد أو المفتاح المناسب ولا يمكن قراءتها كـ SQLite عادي.
  • بالنسبة إلى الملفات الكبيرة جدًا، أغلق علامات تبويب المتصفح المستهلكة للذاكرة قبل إعادة المحاولة.

احفظ نتائجك أو صدّرها

يمكن تصدير نتائج الاستعلامات بصيغ شائعة. وإذا عدّلت الصفوف أو نفّذت عبارات كتابة، فاستخدم حفظ القاعدة لتنزيل قاعدة البيانات الحالية. ولا يُستبدل الملف المحلي الأصلي بصمت.
