تبقى قاعدة بياناتك في متصفحك

صُمّم SQLite Viewer لفتح ملفات قواعد البيانات المحددة ومعالجتها على جهاز المستخدم بدلًا من رفع محتوياتها لمعالجتها على الخادم.

المعالجة المحلية لقاعدة البيانات

عند اختيارك ملف SQLite، يقرؤه JavaScript في المتصفح إلى الذاكرة المحلية. وتتم عمليات تصفح الجداول وتنفيذ SQL وتعديل الصفوف وفحص البنية وتصدير قاعدة البيانات داخل جلسة المتصفح. ولا يحتاج التطبيق إلى إرسال ملف قاعدة البيانات المحدد إلى خادم لتوفير هذه الميزات.

ما قد يتلقاه الموقع

كمعظم المواقع، قد تتلقى البنية التحتية للاستضافة معلومات الطلبات المعتادة مثل عنوان IP ونوع المتصفح والصفحات المطلوبة والطوابع الزمنية وسجلات الأخطاء. وقد يستخدم الموقع التحليلات لفهم زيارات الصفحات والاستخدام العام. ولا ينبغي إرسال أسماء ملفات قواعد البيانات ومحتويات الجداول ونص استعلامات SQL عمدًا كأحداث تحليلية.

تخزين المتصفح

قد يستخدم التطبيق تخزين المتصفح لحفظ التفضيلات المحلية ومعلومات مساحة العمل، مثل تبويبات الاستعلامات أو سجل الاستعلامات. وتظل هذه المعلومات مرتبطة بملف تعريف المتصفح إلى أن يمسحها المستخدم أو المتصفح.

التنزيلات والملفات الأصلية

يتم التعديل على قاعدة البيانات الموجودة في الذاكرة. وينشئ «حفظ القاعدة» تنزيلًا للحالة الحالية. ولا يستبدل التطبيق ملف قاعدة البيانات الأصلي على القرص بصمت.

مسؤولياتك

استخدم قواعد البيانات المصرّح لك بالوصول إليها. ضع في الاعتبار أمان الجهاز وملف تعريف المتصفح والإضافات المثبّتة عند فتح ملفات حساسة. وامسح تخزين المتصفح والنسخ التي نزّلتها عند العمل على جهاز مشترك.

موارد الأطراف الثالثة

قد تحمّل الصفحة مكتبات أو تحليلات أو موارد موقع أخرى من خدمات تابعة لأطراف ثالثة. وقد تتلقى هذه الخدمات بيانات طلبات الويب العادية، لكن قاعدة البيانات المحددة لا تُضمَّن عمدًا في تلك الطلبات.

بالنسبة إلى البيانات شديدة الحساسية أو الخاضعة للوائح، استخدم بيئة وإعدادات متصفح معتمدة من مؤسستك وراجع سلوك الشبكة للتطبيق المنشور قبل الاستخدام.
