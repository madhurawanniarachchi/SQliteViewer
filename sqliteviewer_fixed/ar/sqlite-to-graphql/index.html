إنشاء البنية

  1. افتح قاعدة بيانات SQLite.
  2. راجع كياناتها في مخطط ER.
  3. اختر GraphQL SDL صيغةً للتصدير.
  4. صدّر تعريفات الأنواع وراجعها في مشروع API الخاص بك.
type Customer {

SDL ليس واجهة API كاملة

تصف بنية قاعدة البيانات التخزين، بينما يصف GraphQL عقدًا موجّهًا للتطبيق. ولا ينشئ SDL المولَّد محلِّلات (resolvers) ولا مصادقة ولا ترقيم صفحات ولا تحققًا ولا عمليات تعديل ولا تفويضًا على مستوى الحقول. اعتبره مسودة أولى منظمة.

راجع تعيينات الأنواع

لا تتطابق أنواع SQLite تمامًا مع قيم GraphQL العددية والأساسية. فقد تُخزَّن التواريخ كنص أو أرقام، وقد تحتاج الأعداد العشرية إلى نوع مخصص، وتحتاج البيانات الثنائية إلى تمثيل خاص بالتطبيق. أعد تسمية الحقول التقنية في قاعدة البيانات عندما يكون اسم API أوضح مناسبًا.

لا تكشف أبدًا كل جداول قاعدة البيانات تلقائيًا. اختر فقط الحقول والعمليات التي ينبغي للعملاء الوصول إليها، ثم طبّق التفويض في طبقة API.

استخدم العلاقات بتأنٍ

قد تقترح المفاتيح الخارجية المعلنة علاقات GraphQL، لكن سلوك المحلِّلات يعتمد على تنفيذ الخادم لديك. فكّر في التجميع على دفعات وترقيم الصفحات لتجنب وصول متداخل مكلف إلى قاعدة البيانات.
