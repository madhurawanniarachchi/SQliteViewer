دليل استعلامات SQLite

استعلامات مفيدة لفحص قواعد بيانات SQLite

ابدأ بـ SQL آمن ومحدد عندما تحتاج إلى فهم الجداول والفهارس والعلاقات وجودة البيانات.

افتح مساحة عمل SQL

سرد جداول المستخدم وعروضه

SELECT type, name, sql
FROM sqlite_master
WHERE type IN ('table', 'view')
  AND name NOT LIKE 'sqlite_%'
ORDER BY type, name;

افحص أعمدة جدول

PRAGMA table_info('orders');

يعيد هذا النوع المعلن وقابلية القيمة الفارغة والقيمة الافتراضية وموضع المفتاح الأساسي لكل عمود.

راجع المفاتيح الخارجية

PRAGMA foreign_key_list('orders');
PRAGMA foreign_key_check;

تصف العبارة الأولى المراجع المعلنة لجدول واحد. وتبلّغ الثانية عن الصفوف التي تخالف علاقات المفاتيح الخارجية المفعّلة.

ابحث عن القيم المكررة

SELECT email, COUNT(*) AS occurrences
FROM customers
WHERE email IS NOT NULL
GROUP BY email
HAVING COUNT(*) > 1
ORDER BY occurrences DESC;

افحص الفهارس

PRAGMA index_list('orders');

بعد العثور على اسم فهرس، افحص أعمدته باستخدام PRAGMA index_info('index_name').

تحقق من سلوك الاستعلام

EXPLAIN QUERY PLAN
SELECT *
FROM orders
WHERE customer_id = 42
ORDER BY created_at DESC;

قد تكشف الخطة عن مسح كامل للجدول وعما إذا كان SQLite قادرًا على استخدام فهرس مناسب.

أسلوب عمل آمن: ابدأ باستعلامات الفحص من نوع SELECT أو PRAGMA. وقبل UPDATE أو DELETE نفّذ SELECT بشرط WHERE نفسه واحتفظ بنسخة أصلية من قاعدة البيانات.

تصفّح الجداول الكبيرة صفحةً صفحة

SELECT *
FROM events
ORDER BY id
LIMIT 100 OFFSET 0;

عند التنقل المتكرر في جداول كبيرة جدًا، يكون الترقيم بالمفتاح مثل WHERE id > ? ORDER BY id LIMIT 100 غالبًا أكثر كفاءة من إزاحة كبيرة جدًا.
