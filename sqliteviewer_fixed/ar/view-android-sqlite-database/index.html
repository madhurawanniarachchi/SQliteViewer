عرض قاعدة بيانات SQLite لتطبيق Android

افتح قاعدة بيانات تطبيق مُصدَّرة من محاكٍ أو نسخة تصحيح أو جهاز مصرّح به، وافحصها دون تثبيت متصفح قواعد بيانات لسطح المكتب.

افتح قاعدة بيانات Android

صدّر قاعدة البيانات أولًا بشكل قانوني وآمن

يفتح SQLite Viewer ملفًا تملكه بالفعل؛ ولا يستخرج قواعد البيانات من الهاتف. استخدم Device Explorer في Android Studio أو محاكيًا أو نسخة احتياطية للتطبيق أو أدوات التصحيح الخاصة بك للحصول على قاعدة بيانات مصرّح لك بفحصها.

تظهر قواعد بيانات تطبيقات Android عادةً ضمن مجلد databases الخاص بالتطبيق، وقد تستخدم الامتداد .db أو لا تحمل امتدادًا. إذا لم تعرض أداة اختيار الملفات في المتصفح نسخة بلا امتداد، فأعد تسمية الملف المُصدَّر لينتهي بـ .db.

افتح بنية التطبيق وافحصها

  1. أفلت قاعدة البيانات المُصدَّرة على SQLite Viewer.
  2. ابحث في الشريط الجانبي للجداول عن الميزة التي تصحّحها.
  3. افتح الجداول المحتملة وافحص أحدث الصفوف.
  4. استخدم مخطط ER لفهم المفاتيح الخارجية والعلاقات على نمط Room.
  5. نفّذ SQL مركّزًا بدلًا من التمرير عبر جداول الأحداث أو التخزين المؤقت الكبيرة.

اعرض قاعدة بيانات تطبيق التصحيح مباشرة عبر USB

في Chrome أو Edge على سطح المكتب، اختر Android في شريط الأدوات، وصِل هاتفك مع تفعيل تصحيح USB، واختر أحد تطبيقاتك القابلة للتصحيح. ينسخ SQLite Viewer قاعدة البيانات باستخدام run-as ويدمج سجل الكتابة المسبقة ليشمل أحدث عمليات الكتابة، ويمكنه تحديثها كل بضع ثوانٍ أثناء الاختبار. كل شيء يبقى في متصفحك. نُسخ الإصدار محمية من Android ولا يمكن قراءتها بهذه الطريقة.

يُبقي Android Studio اتصال USB مشغولًا، لذا يوفر العارض أيضًا وضع خادم ADB: على Windows نزّل مثبّت الجسر بنقرة واحدة وانقر عليه نقرًا مزدوجًا مرة واحدة. يُعدّ مساعدًا صغيرًا يبدأ تلقائيًا عند كل تسجيل دخول، وتشارك الصفحة خادم ADB مع Android Studio ليعملا معًا. وعلى macOS وLinux شغّل المساعد adb-bridge.py بدلًا من ذلك. تكتشف الصفحة الجسر تلقائيًا. المساعدة الكاملة: دليل إعداد جسر ADB.

هل تريد تغيير البيانات دون إعادة تشغيل التطبيق؟ أضف مساعدًا صغيرًا للتصحيح فقط واتبع دليل إعداد التعديل المباشر.

تعامل مع قواعد بيانات WAL بشكل صحيح

قد يستخدم SQLite تسجيل الكتابة المسبقة منتجًا ملفين مساعدين -wal و-shm. ونسخ قاعدة البيانات الرئيسية وحدها أثناء كتابة التطبيق قد يُغفل معاملات حديثة. يُفضَّل تصدير متّسق يُنشأ أثناء إغلاق قاعدة البيانات أو بعد إجراء نقطة تحقق.

بيانات حساسة: قد تحتوي قواعد بيانات التطبيقات على معلومات شخصية أو رموز أو سجلات أعمال. استخدم فقط ملفات مصرّح لك بفحصها واحذف النسخ المُصدَّرة عند انتهاء التصحيح.

تعديل قواعد بيانات Android

يمكنك تعديل نسخة وتنزيلها، لكن استبدال قاعدة بيانات التطبيق قد يخالف توقعات البنية أو يفسد حالة التطبيق. احتفظ بالأصل وتحقق من القيود واستخدم أدوات الترحيل أو التصحيح المدعومة كلما أمكن.
