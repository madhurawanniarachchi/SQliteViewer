تحويل SQLite إلى DBML

حوّل بنية SQLite الحالية إلى DBML مقروء لأغراض التوثيق وسير عمل تصميم قواعد البيانات.

افتح مُصدّر DBML

إنشاء DBML من ملف SQLite

  1. افتح قاعدة بياناتك في SQLite Viewer.
  2. اختر مخطط ER.
  3. اختر DBML من قائمة صيغ التصدير.
  4. صدّر النص الناتج وراجعه في أداة DBML المفضلة لديك.

ما الذي يتضمنه التحويل

يصف التصدير الجداول وأسماء الأعمدة وأنواع بيانات SQLite المعلنة والمفاتيح الأساسية وعلاقات المفاتيح الخارجية المعلنة. ويمنح أدوات التصميم بنية كافية لعرض نموذج مفيد دون كشف صفوف الجداول.

Table orders {
  id integer [pk]
  customer_id integer [not null]
  created_at text
}

Ref: orders.customer_id > customers.id

لماذا تستخدم DBML؟

من الأسهل مراجعة DBML من ملف قاعدة بيانات ثنائي، وهو أكثر تركيزًا على نمذجة البيانات من SQL القابل للتنفيذ. تستخدمه الفرق لمناقشة البنى وإنشاء المخططات وتوثيق العلاقات وتخطيط التغييرات قبل كتابة عمليات الترحيل.

DBML تمثيل تصميمي وليس نسخة احتياطية بايتًا ببايت لقاعدة البيانات. احتفظ بملف SQLite الأصلي واستخدم «حفظ القاعدة» عندما تحتاج إلى قاعدة بيانات تعمل وتحتوي على بياناتها.

راجع النموذج الناتج

يسمح SQLite بتصريحات أنواع مرنة وقد تُغفل البنى المفاتيح الخارجية. افحص الأنواع المخصصة والقيود المركبة والأعمدة المولّدة والفهارس والعلاقات الموجودة في شفرة التطبيق فقط. وأضف ملاحظات على مستوى التصميم بعد التصدير عند الحاجة.
