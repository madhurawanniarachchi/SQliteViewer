تحويل SQLite إلى CSV

حوّل جدولًا أو نتيجة أي استعلام SQL إلى ملف CSV يمكنك فتحه في Excel أو جداول بيانات Google أو استيراده إلى قاعدة بيانات أخرى.

التصدير إلى CSV

تصدير جدول SQLite إلى CSV

  1. افتح ملف .db أو .sqlite أو .sqlite3 أو .db3 في SQLite Viewer. يبقى الملف داخل متصفحك.
  2. اختر جدولًا، أو اكتب استعلامًا يعيد الصفوف التي تحتاجها بالضبط.
  3. انقر على تصدير أعلى النتائج واختر الأعمدة المراد تضمينها.
  4. اختر CSV ويُنزَّل الملف فورًا.

صدّر ما تحتاجه فقط

لأن التصدير يتبع الاستعلام الحالي، يمكنك أولًا التصفية باستخدام WHERE أو ربط الجداول أو الترتيب أو تحديد عدد الصفوف، ثم تصدير هذه النتيجة بالضبط. ويتيح لك منتقي الأعمدة استبعاد الأعمدة التي لا تريدها في الملف.

نصيحة: لتصدير جدول كامل، اختر الجدول واحذف أي LIMIT من الاستعلام قبل النقر على تصدير.

بياناتك لا تغادر جهازك أبدًا

يعمل التحويل بلغة JavaScript داخل علامة تبويب المتصفح. لا تُرفع قاعدة البيانات إلى خادم، لذا يمكن استخدامه بأمان مع بيانات العملاء وقواعد بيانات التطبيقات والملفات الداخلية.

متى تستخدم CSV

CSV هو أكثر الصيغ قابلية للنقل لجداول البيانات وأدوات ذكاء الأعمال والاستيراد الجماعي. وإذا احتجت إلى قيم محددة النوع أو بيانات متداخلة فاستخدم JSON؛ ولمصنف منسّق استخدم Excel.
