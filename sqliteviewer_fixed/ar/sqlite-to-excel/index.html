تحويل SQLite إلى Excel (XLSX)

أنشئ مصنف Excel من أي جدول أو نتيجة استعلام للتقارير والمشاركة ومزيد من التحليل.

التصدير إلى Excel

تصدير جدول SQLite إلى Excel

  1. افتح ملف .db أو .sqlite أو .sqlite3 أو .db3 في SQLite Viewer. يبقى الملف داخل متصفحك.
  2. اختر جدولًا، أو اكتب استعلامًا يعيد الصفوف التي تحتاجها بالضبط.
  3. انقر على تصدير أعلى النتائج واختر الأعمدة المراد تضمينها.
  4. اختر Excel ويُنزَّل الملف فورًا.

استخدم SQL قبل التصدير

صفِّ الجداول أو رتّبها أو اجمع بياناتها أو اربطها باستخدام SQL أولًا، ثم صدّر النتيجة. يستلم Excel الصفوف والأعمدة التي حددتها بالضبط، ويُستخدم اسم الجدول اسمًا لورقة العمل.

يحمّل تصدير Excel مكتبة جداول البيانات عند الحاجة، لذا يتطلب أول تصدير إلى Excel اتصالًا بالإنترنت. وتبقى قاعدة بياناتك داخل متصفحك دائمًا.

بياناتك لا تغادر جهازك أبدًا

يعمل التحويل بلغة JavaScript داخل علامة تبويب المتصفح. لا تُرفع قاعدة البيانات إلى خادم، لذا يمكن استخدامه بأمان مع بيانات العملاء وقواعد بيانات التطبيقات والملفات الداخلية.

الاستيراد من Excel أيضًا

يمكن لـ SQLite Viewer أيضًا استيراد ملف .xlsx أو .xls إلى قاعدة بيانات SQLite جديدة لتتمكن من الاستعلام عن جدول بيانات باستخدام SQL. تفضّل صيغة نصية بسيطة؟ جرّب CSV أو JSON.
