تصدير البنية

تحويل بنية SQLite إلى SQL DDL

استخرج تعريفات بنية مقروءة للتوثيق والمراجعة وتخطيط الترحيل أو التحكم بالإصدارات.

افتح مُصدّر بنية SQLite

تصدير SQL DDL من ملف قاعدة بيانات

  1. افتح قاعدة بيانات SQLite.
  2. افتح مخطط ER.
  3. اختر SQL DDL صيغةً للتصدير.
  4. صدّر نص البنية الناتج واحفظه.

تمثّل النتيجة بنية قاعدة البيانات لا بيانات الجداول. وتتضمن تعريفات الكيانات وأنواع الأعمدة المعلنة ومعلومات المفاتيح التي يمكن استنتاجها من البيانات الوصفية لبنية SQLite.

مثال على المخرجات

CREATE TABLE "orders" (
  "id" INTEGER PRIMARY KEY,
  "customer_id" INTEGER NOT NULL,
  "created_at" TEXT,
  FOREIGN KEY ("customer_id") REFERENCES "customers" ("id")
);

فيمَ يفيد SQL DDL

  • مراجعة بنية قاعدة البيانات أثناء مراجعة الشفرة.
  • إبقاء تغييرات البنية في نظام التحكم بالإصدارات.
  • توثيق الجداول دون كشف صفوف بيئة الإنتاج.
  • التحضير للترحيل إلى نظام قواعد بيانات آخر.
  • مقارنة تعريفات الجداول المتوقعة والفعلية.
ملاحظة حول الترحيل: تختلف صيغة SQLite وألفة الأنواع فيه عن PostgreSQL وMySQL وSQL Server. تعامل مع DDL المُصدَّر على أنه وصف موثوق لبنية SQLite، ثم عدّل الأنواع وسلوك الزيادة التلقائية والاقتباس والقيود بما يناسب المحرك المستهدف.

تصدير البنية مقابل حفظ قاعدة البيانات

يحتوي SQL DDL على البنية فقط. إذا كنت تحتاج إلى قاعدة البيانات بصفوفها وتعديلاتها المحلية، فاستخدم حفظ القاعدة. وإذا كنت تحتاج إلى الصفوف بصيغة نصية قابلة للنقل، فاستخدم عناصر تحكم تصدير النتائج.
