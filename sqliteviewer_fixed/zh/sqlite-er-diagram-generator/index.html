从 SQLite 生成 ER 图

将陌生的数据库变成清晰易读的地图，展示表、列、类型、主键和外键连接。

打开 ER 图工具

创建图表

  1. 在查看器中打开 SQLite 数据库。
  2. 在表侧边栏中选择 ER 图。
  3. 使用适应窗口将所有实体显示在对话框视图中。
  4. 检查每个实体的列名、SQLite 数据类型和键标记。

关系线来自 SQLite 中声明的外键。如果逻辑关系没有通过外键约束定义，仅凭列名，结构读取器无法可靠地识别它。

如何阅读结果

  • PK 表示用于唯一定位一行的主键列。
  • FK 表示引用另一张表中键的列。
  • 列类型显示声明的 SQLite 类型。由于 SQLite 的类型系统很灵活，实际存储的值有时可能与该声明不同。
  • 连接线显示被引用的实体和引用它的实体。
当数据库一致地声明了主键和外键时，图表最有用。缺少连线通常意味着缺少约束，而不是渲染问题。

导出结构

查看图表后，可将其结构导出为 SQL DDL、DBML、Mermaid 或 GraphQL SDL。SQL DDL 最接近原始数据库定义；DBML 和 Mermaid 适用于文档；GraphQL SDL 是 API 模型的起点，可能需要根据应用做调整。

实用的审查问题

查找没有主键的表、指向意外实体的外键、命名不一致、应为必填却允许为空的列，以及表示多对多关系的中间表。在接手应用数据库或规划迁移时，这些检查很有帮助。
