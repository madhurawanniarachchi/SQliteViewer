导出为 Excel

将 SQLite 表导出为 Excel

  1. 在 SQLite Viewer 中打开您的 .db、.sqlite、.sqlite3 或 .db3 文件。文件始终留在您的浏览器中。
  2. 选择一张表，或编写一条恰好返回所需行的查询。
  3. 点击结果上方的导出，并选择要包含的列。
  4. 选择 Excel，文件会立即下载。

导出前先用 SQL 处理

先用 SQL 筛选、排序、聚合或联接表，再导出结果。Excel 将收到您所选的行和列，并以表名作为工作表名称。

Excel 导出会按需加载其电子表格库，因此首次导出 Excel 时需要联网。您的数据库依然不会离开浏览器。

您的数据绝不会离开您的设备

转换以 JavaScript 的形式在浏览器标签页中运行。数据库不会上传到服务器，因此可以放心用于客户数据、应用数据库和内部文件。

也可从 Excel 导入

SQLite Viewer 还可以将 .xlsx 或 .xls 文件导入新的 SQLite 数据库，让您用 SQL 查询电子表格。更喜欢纯文本格式？试试 CSV 或 JSON。
