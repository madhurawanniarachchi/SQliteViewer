将 SQLite 转换为 DBML

将现有 SQLite 结构转换为可读的 DBML，用于文档和数据库设计工作流。

打开 DBML 导出器

从 SQLite 文件生成 DBML

  1. 在 SQLite Viewer 中打开您的数据库。
  2. 选择 ER 图。
  3. 在导出格式列表中选择 DBML。
  4. 导出生成的文本，并在您常用的 DBML 工具中查看。

转换包含的内容

导出内容描述表、列名、声明的 SQLite 数据类型、主键以及声明的外键关系。它为设计工具提供足够的结构来呈现有用的模型，而不会暴露表中的数据行。

Table orders {
  id integer [pk]
  customer_id integer [not null]
  created_at text
}

Ref: orders.customer_id > customers.id

为什么使用 DBML？

DBML 比数据库二进制文件更易于审阅，也比可执行的 SQL 更专注于数据建模。团队用它来讨论结构、创建图表、记录关系，并在编写迁移之前规划更改。

DBML 是设计层面的表示，而不是逐字节的数据库备份。请保留原始 SQLite 文件；需要包含数据的可用数据库时，请使用“保存数据库”。

检查生成的模型

SQLite 允许灵活的类型声明，结构中也可能省略外键。请检查自定义类型、复合约束、生成列、索引以及仅存在于应用代码中的关系。必要时在导出后添加设计层面的注释。
