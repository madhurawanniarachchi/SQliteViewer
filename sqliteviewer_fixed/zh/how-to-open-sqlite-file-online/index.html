如何安全地在线打开 SQLite 文件

无需安装桌面软件，也无需将文件发送到远程服务器，即可在浏览器中查看本地 SQLite 数据库。

打开 SQLite Viewer

三步打开您的数据库

  1. 在现代桌面浏览器中打开 SQLite Viewer。
  2. 将数据库拖到起始卡片上，或点击该卡片并选择 .db、.sqlite、.sqlite3 或 .db3 文件。
  3. 在侧边栏中选择一张表。查看器会创建查询标签页并显示第一页数据行。
隐私：文件由浏览器 JavaScript 在本地读取。查看表、执行 SQL 或生成 ER 图都无需上传。

可以查看什么

表列表可快速访问表和视图。您可以搜索较长的结构、按多种指标对表排序、查看列信息、控制可见列，并在查看较宽的结果集时固定列。

如需更详细的操作，请使用 SQL 编辑器。基本查询如下：

SELECT *
FROM "customers"
LIMIT 0, 30;

文件无法打开时

  • 确认它是真正的 SQLite 数据库，而不是 SQL 文本转储文件。
  • 尝试将不常见的扩展名重命名为 .db，以便它出现在文件选择器中。
  • 检查文件是否已加密；加密的数据库需要对应的扩展或密钥，无法作为普通 SQLite 读取。
  • 对于非常大的文件，请先关闭占用内存较多的浏览器标签页，再重试。

保存或导出您的发现

查询结果可以导出为常见格式。如果您编辑了行或执行了写入语句，请使用保存数据库下载当前数据库。原始本地文件不会被悄悄覆盖。
