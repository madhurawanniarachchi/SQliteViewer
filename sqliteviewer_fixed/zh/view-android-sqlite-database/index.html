查看 Android SQLite 数据库

打开从模拟器、调试版本或已授权设备导出的应用数据库并进行查看，无需安装桌面数据库浏览器。

打开 Android 数据库

请先合法、安全地导出数据库

SQLite Viewer 打开的是您已经拥有的文件，不会从手机中提取数据库。请使用 Android Studio 的 Device Explorer、模拟器、应用备份或您自己的调试工具，来获取您有权查看的数据库。

Android 应用数据库通常位于应用专属的 databases 目录下，可能使用 .db 扩展名或没有扩展名。如果浏览器的文件选择器没有显示无扩展名的副本，请将导出的文件重命名为以 .db 结尾。

打开并查看应用结构

  1. 将导出的数据库拖到 SQLite Viewer 上。
  2. 在表侧边栏中搜索您正在调试的功能。
  3. 打开可能相关的表并查看最近的行。
  4. 使用 ER 图了解外键和 Room 风格的关系。
  5. 运行有针对性的 SQL，而不是在庞大的事件表或缓存表中滚动查找。
SELECT *
FROM "sync_queue"
ORDER BY "created_at" DESC
LIMIT 0, 100;

通过 USB 实时查看调试应用的数据库

在桌面版 Chrome 或 Edge 中，选择工具栏中的 Android，连接已开启 USB 调试的手机，并选择您的某个可调试应用。SQLite Viewer 使用 run-as 复制数据库，合并预写日志以包含最新的写入，并可在您测试时每隔几秒刷新一次。一切都保留在浏览器中。发布版本受 Android 保护，无法以这种方式读取。

Android Studio 会占用 USB 连接，因此查看器还提供 ADB 服务器模式：在 Windows 上，下载一键式桥接安装程序并双击运行一次。它会设置一个在每次登录时自动启动的小型辅助程序，页面与 Android Studio 共享 ADB 服务器，因此两者可同时工作。在 macOS 和 Linux 上，请改为运行 adb-bridge.py 辅助程序。页面会自动检测桥接程序。完整帮助：ADB 桥接设置指南。

想在不重启应用的情况下修改数据？添加一个仅用于调试的小型辅助程序，并按照实时编辑设置指南操作。

正确处理 WAL 数据库

SQLite 可能使用预写日志，产生 -wal 和 -shm 配套文件。在应用写入时只复制主数据库，可能会遗漏最近的事务。建议使用在数据库关闭或已检查点后创建的一致性导出。

敏感数据：应用数据库可能包含个人信息、令牌或业务记录。请仅使用您有权查看的文件，并在调试完成后删除导出的副本。

编辑 Android 数据库

您可以编辑副本并下载，但替换应用数据库可能违反结构预期或破坏应用状态。请保留原始文件，验证约束，并尽可能使用受支持的迁移或调试工具。
