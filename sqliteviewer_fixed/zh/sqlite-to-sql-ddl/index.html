结构导出

将 SQLite 结构转换为 SQL DDL

提取可读的结构定义，用于文档、审阅、迁移规划或版本控制。

打开 SQLite 结构导出器

从数据库文件导出 SQL DDL

  1. 打开 SQLite 数据库。
  2. 打开 ER 图。
  3. 选择 SQL DDL 作为导出格式。
  4. 导出并保存生成的结构文本。

结果表示的是数据库结构，而不是表中的数据。它包含实体定义、声明的列类型，以及可从 SQLite 结构元数据推断出的键信息。

示例输出

CREATE TABLE "orders" (
  "id" INTEGER PRIMARY KEY,
  "customer_id" INTEGER NOT NULL,
  "created_at" TEXT,
  FOREIGN KEY ("customer_id") REFERENCES "customers" ("id")
);

SQL DDL 的用途

  • 在代码审查中审阅数据库结构。
  • 将结构变更纳入版本控制。
  • 在不暴露生产数据行的情况下记录表。
  • 准备迁移到其他数据库系统。
  • 比较预期与实际的表定义。
迁移说明：SQLite 的语法和类型亲和性与 PostgreSQL、MySQL 和 SQL Server 不同。请将导出的 DDL 视为对 SQLite 结构的可靠描述，再针对目标引擎调整类型、自增行为、引号和约束。

结构导出与数据库保存的区别

SQL DDL 只包含结构。如果需要包含数据行和本地修改的数据库，请使用保存数据库。如果需要便携的文本格式数据行，请使用结果导出控件。
