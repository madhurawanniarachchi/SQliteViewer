将 SQLite 转换为 CSV

将表或任意 SQL 查询结果转换为 CSV 文件，可在 Excel、Google 表格中打开，或导入其他数据库。

导出为 CSV

将 SQLite 表导出为 CSV

  1. 在 SQLite Viewer 中打开您的 .db、.sqlite、.sqlite3 或 .db3 文件。文件始终留在您的浏览器中。
  2. 选择一张表，或编写一条恰好返回所需行的查询。
  3. 点击结果上方的导出，并选择要包含的列。
  4. 选择 CSV，文件会立即下载。

只导出您需要的内容

由于导出遵循当前查询，您可以先用 WHERE 筛选、联接表、排序或限制行数，再导出该结果。列选择器可让您排除不想放入文件的列。

提示：要导出整张表，请选择该表，并在点击“导出”前删除查询中的 LIMIT。

您的数据绝不会离开您的设备

转换以 JavaScript 的形式在浏览器标签页中运行。数据库不会上传到服务器，因此可以放心用于客户数据、应用数据库和内部文件。

何时使用 CSV

CSV 是电子表格、BI 工具和批量导入中最通用的格式。如需带类型的值或嵌套数据，请使用 JSON；如需带格式的工作簿，请使用 Excel。
