隐私

您的数据库保留在您的浏览器中

SQLite Viewer 的设计是在用户设备上打开并处理所选数据库文件，而不是上传其内容进行服务器端处理。

本地数据库处理

当您选择 SQLite 文件时，浏览器 JavaScript 会将其读入本地内存。浏览表、执行 SQL、编辑行、查看结构和导出数据库都在浏览器会话中完成。应用无需将所选数据库文件传输到服务器即可提供这些功能。

网站可能接收的信息

与大多数网站一样，托管基础设施可能会收到常规请求信息，例如 IP 地址、浏览器类型、请求的页面、时间戳和错误日志。网站可能使用分析工具来了解页面访问和总体使用情况。数据库文件名、表内容和 SQL 查询文本不应被有意作为分析事件发送。

浏览器存储

应用可能使用浏览器存储来保存本地偏好和工作区信息，例如查询标签页或查询历史。这些信息会一直与浏览器配置文件关联，直到用户或浏览器将其清除。

下载与原始文件

编辑是针对内存中的数据库进行的。“保存数据库”会创建当前状态的下载。应用不会悄悄替换磁盘上的原始数据库文件。

您的责任

请使用您有权访问的数据库。打开敏感文件时，请考虑设备、浏览器配置文件和已安装扩展的安全性。在共享设备上工作时，请清除浏览器存储和已下载的副本。

第三方资源

页面可能从第三方服务加载库、分析工具或其他网站资源。这些服务可能会收到常规的网络请求数据，但所选数据库不会被有意包含在这些请求中。

对于高度敏感或受监管的数据，请使用经您所在组织批准的环境和浏览器配置，并在使用前检查已部署应用的网络行为。

问题
