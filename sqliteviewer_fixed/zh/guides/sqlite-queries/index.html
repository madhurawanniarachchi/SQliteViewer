SQLite 查询指南

检查 SQLite 数据库的实用查询

当您需要了解表、索引、关系和数据质量时，请从安全且有针对性的 SQL 开始。

打开 SQL 工作区

列出用户表和视图

SELECT type, name, sql
FROM sqlite_master
WHERE type IN ('table', 'view')
  AND name NOT LIKE 'sqlite_%'
ORDER BY type, name;

查看表的列

PRAGMA table_info('orders');

这会返回每一列声明的类型、是否可为空、默认值以及在主键中的位置。

检查外键

PRAGMA foreign_key_list('orders');
PRAGMA foreign_key_check;

第一条语句描述某张表已声明的引用。第二条报告违反已启用外键关系的行。

查找重复值

SELECT email, COUNT(*) AS occurrences
FROM customers
WHERE email IS NOT NULL
GROUP BY email
HAVING COUNT(*) > 1
ORDER BY occurrences DESC;

查看索引

PRAGMA index_list('orders');

找到索引名称后，可使用 PRAGMA index_info('index_name') 查看其列。

检查查询行为

EXPLAIN QUERY PLAN
SELECT *
FROM orders
WHERE customer_id = 42
ORDER BY created_at DESC;

执行计划可以显示是否发生了全表扫描，以及 SQLite 能否使用相关索引。

安全的工作流程：先使用 SELECT 或 PRAGMA 检查类查询。在执行 UPDATE 或 DELETE 之前，先用相同的 WHERE 条件运行 SELECT，并保留数据库的原始副本。

对大表进行分页

SELECT *
FROM events
ORDER BY id
LIMIT 100 OFFSET 0;

对于需要反复浏览的超大表，使用键集分页（例如 WHERE id > ? ORDER BY id LIMIT 100）通常比很大的偏移量更高效。
