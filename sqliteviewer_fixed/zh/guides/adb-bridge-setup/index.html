设置 ADB 桥接（可与 Android Studio 并用）

一个小型辅助程序即可让 SQLite Viewer 和 Android Studio 同时使用您的手机。下载它、放到位、让它自动启动，就完成了。

打开查看器

我需要桥接吗？

通常不需要。SQLite Viewer 可以通过 USB 直接与手机通信（Chrome 或 Edge 中的 USB 直连模式），无需安装任何东西。桥接只用于一种情况：Android Studio（或其他 ADB 工具）已在使用手机。USB 连接同一时间只能由一个程序占用，因此桥接让 SQLite Viewer 共享 Android Studio 的 ADB 服务器，两者便能同时工作。

USB 直连ADB 服务器（桥接）
需要安装吗？不需要需要，一次（Windows 上一键完成）
Android Studio 打开时能用吗？不能，必须关闭能
浏览器桌面版 Chrome 或 Edge任何现代浏览器
电脑上需要 ADB 吗？不需要需要（Android Studio 或 Platform Tools）

Windows：一键安装程序

  1. 下载安装程序。在 SQLite Viewer 中打开 Live Android，选择 ADB 服务器，然后点击下载安装程序 (Windows)。
  2. 保留文件。Chrome 可能提示无法验证该文件。请选择保留（或下载未验证的文件）。该文件是纯文本，您可以用记事本打开，查看它具体做了什么。
  3. 运行一次。双击 Install-ADB-Bridge.cmd。如果 Windows 显示Windows 已保护你的电脑，请点击更多信息，再点击仍要运行。
  4. 回到页面。安装程序会在您的电脑上构建桥接程序，让它在每次登录时自动启动，并立即启动它。SQLite Viewer 会在几秒内发现它。点击通过桥接连接。

桥接程序安装在 %LOCALAPPDATA%\SQLiteViewerBridge，启动文件夹中的快捷方式会在登录时启动它。要移除它，请从该文件夹运行 uninstall.cmd。

任意系统：使用 Python 设置

  1. 安装 Python 3。从 python.org 下载。在 Windows 上，请在安装程序中勾选 Add Python to PATH。大多数 Linux 系统已自带 python3。macOS 默认不包含它：首次输入 python3 时，macOS 会提示安装 Apple 的命令行工具（请接受），或使用 python.org 的安装程序。
  2. 下载文件。下载 adb-bridge.py。浏览器会将其保存到“下载”文件夹。如果文件名以 .txt 结尾，请重命名为 adb-bridge.py。
  3. 将它复制到固定位置。打开终端（任意文件夹均可，命令使用完整路径），运行适合您系统的命令。它会创建文件夹并把文件复制进去。如果浏览器把文件保存在了“下载”以外的位置，请修改命令中的那一部分。
  4. 让它自动启动。运行适合您系统的命令。它会为您复制到的文件设置登录时启动项，并立即启动桥接程序。
  5. 连接。回到 SQLite Viewer，它会自动找到桥接程序。点击通过桥接连接。

第 3 步：复制文件（运行一次）

Windows（PowerShell，按 Windows 键，输入 powershell，按 Enter）：

New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\SQLiteViewerBridgePython" | Out-Null; Copy-Item "$env:USERPROFILE\Downloads\adb-bridge.py" "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py"

Windows（命令提示符，按 Windows 键，输入 cmd，按 Enter）：

mkdir "%LOCALAPPDATA%\SQLiteViewerBridgePython" & copy "%USERPROFILE%\Downloads\adb-bridge.py" "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

macOS（终端）：

mkdir -p "$HOME/Library/Application Support/SQLiteViewerBridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py"

Linux：

mkdir -p "$HOME/.local/share/sqliteviewer-bridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py"

第 4 步：登录时自动启动（运行一次）

Windows (PowerShell)：

python "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

Windows（命令提示符）：

python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

macOS：

python3 "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py" --add-to-startup

Linux：

python3 "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py" --add-to-startup

在 Windows 上，这会在启动文件夹中创建一个隐藏的快捷方式；在 macOS 上创建 Launch Agent；在 Linux 上创建 systemd 用户服务（或桌面自动启动项）。它们都不需要管理员权限。请让文件保持在原位置；如果移动了它，请再次运行命令。

赶时间？一条命令完成第 3 步和第 4 步

在您下载文件的文件夹中打开终端并运行：

python adb-bridge.py --install      # Windows
python3 adb-bridge.py --install     # macOS and Linux

想手动添加到启动项？

Windows：按 Win + R，输入 shell:startup 并按 Enter。在打开的文件夹中右键，选择新建 → 快捷方式，并将位置设为：

pythonw "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

命名为 SQLite Viewer ADB Bridge。使用 pythonw 而不是 python 可避免出现黑色窗口。注销后重新登录，或双击该快捷方式立即启动。

macOS：上面的命令会创建 ~/Library/LaunchAgents/com.sqliteviewer.adbbridge.plist。Linux：会创建 ~/.config/systemd/user/sqliteviewer-bridge.service（或 ~/.config/autostart/sqliteviewer-bridge.desktop）。手动编写这些文件也是可行的，但使用命令更安全。

检查、停止和移除

python adb-bridge.py --status                  # is it running?
python adb-bridge.py --remove-from-startup      # stop starting at sign-in (keeps the file)
python adb-bridge.py --uninstall                # stop it and delete everything
# add the full path to the file if you are not in its folder, as in the commands above

我有 ADB 吗？没有就安装

桥接程序会转发到 ADB（Android Platform Tools）。Android Studio 已自带它，所以如果您使用 Android Studio，可以跳过本节。要检查，请打开终端并运行 adb version。如果系统不认识该命令，请用下面的某条命令安装 ADB。当桥接程序在运行但找不到 ADB 时，SQLite Viewer 也会告诉您。桥接程序会在 PATH 以及常见的 Android Studio、winget、Homebrew 和手动下载文件夹中查找 ADB，因此您无需修改 PATH，它还会为您启动 ADB 服务器。

Windows

最简单的方式（Windows 10 和 11，PowerShell 或命令提示符）：

winget install --id Google.PlatformTools -e

没有 winget？直接下载（PowerShell）：

Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile "$env:TEMP\pt.zip"; Expand-Archive "$env:TEMP\pt.zip" "$env:LOCALAPPDATA\Android\Sdk" -Force; Remove-Item "$env:TEMP\pt.zip"

命令提示符中的相同操作：

powershell -NoProfile -Command "Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile \"$env:TEMP\pt.zip\"; Expand-Archive \"$env:TEMP\pt.zip\" \"$env:LOCALAPPDATA\Android\Sdk\" -Force; Remove-Item \"$env:TEMP\pt.zip\""

检查是否成功 (PowerShell)：

& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" version

macOS

使用 Homebrew：

brew install --cask android-platform-tools

不使用 Homebrew：

mkdir -p "$HOME/Library/Android/sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-darwin.zip && unzip -o /tmp/pt.zip -d "$HOME/Library/Android/sdk" && rm /tmp/pt.zip

Linux

Debian、Ubuntu、Mint：

sudo apt install adb

Fedora：

sudo dnf install android-tools

Arch、Manjaro：

sudo pacman -S android-tools

其他任何发行版：

mkdir -p "$HOME/Android/Sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-linux.zip && unzip -o /tmp/pt.zip -d "$HOME/Android/Sdk" && rm /tmp/pt.zip

然后准备手机

  1. 在手机上打开设置 → 关于手机，连续点击版本号七次。
  2. 打开设置 → 开发者选项，开启 USB 调试。
  3. 连接手机并在提示上点击允许。运行 adb devices 应将其列为 device。

我需要配置什么吗？

不需要。桥接程序只接受来自 SQLite Viewer 网站的连接，只在您自己的电脑上监听 (127.0.0.1)，并且只转发到同一台电脑上的 ADB 服务器。不会在其他任何地方存储或发送任何内容。

只有两种情况需要设置：

  • 您从其他地址使用 SQLite Viewer（您自己的副本，或开发时的 localhost）。请在相同的命令中允许该地址：
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --allow-origin https://your-address.example
  • 端口 5038 已被占用。请使用其他端口，然后在 Android 面板的高级中输入相同的端口：
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --port 5040

允许的地址保存在桥接程序旁名为 origins.txt 的文件中（每行一个地址）：Windows 为 %LOCALAPPDATA%\SQLiteViewerBridge（安装程序）或 %LOCALAPPDATA%\SQLiteViewerBridgePython (Python)，macOS 为 ~/Library/Application Support/SQLiteViewerBridge，Linux 为 ~/.local/share/sqliteviewer-bridge。

故障排除

  • “此电脑上未运行桥接程序”：运行安装程序或上面的命令，或注销后重新登录。然后重新打开 Android 面板。
  • 我没有 Python：在 Windows 上不需要，请使用上面的一键安装程序。否则请从 python.org 安装 Python 3（Windows：勾选 Add Python to PATH），或在 macOS 上接受安装命令行工具的提示。然后再次运行命令。
  • python 无法识别，或打开 Microsoft Store (Windows)：尚未安装 Python，或漏选了 PATH 选项。请从 python.org 安装，或在命令中将 python 替换为 py。您也可以在设置 → 应用 → 高级应用设置 → 应用执行别名中关闭应用商店快捷方式。
  • 复制命令提示找不到文件：浏览器把 adb-bridge.py 保存在了“下载”以外的位置。请修改命令中的那一部分，或重命名 .txt 文件。
  • “端口 5038 已被占用”：另一个桥接程序正在运行。请移除旧的（--uninstall 或 uninstall.cmd），或使用 --port 选择其他端口。
  • 桥接程序在运行但看不到手机：ADB 服务器必须能看到手机。运行 adb devices，开启 USB 调试，并在手机上接受“允许 USB 调试”提示。
  • “桥接程序在运行，但未安装 ADB”：请用上面我有 ADB 吗？一节中的命令安装 ADB（或安装 Android Studio）。几秒钟后页面会自动发现。
  • Chrome 询问是否允许访问您网络中的设备：请允许。页面正是通过这种方式访问您自己电脑上的桥接程序。
  • 杀毒软件或 Windows 阻止了安装程序：安装程序只是根据您可以阅读的源码构建一个小程序，并写入您自己的用户文件夹。请允许它，或改用 Python 方式。
