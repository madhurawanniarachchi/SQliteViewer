打开 SQLite 编辑器

在主键保护下编辑行

打开数据库并选择一张表。当该表具有可用的主键时，结果中会包含编辑和删除单行的操作。编辑器使用主键值来定位目标行，而不是依赖其在界面上的位置。

  1. 在该行上选择编辑。
  2. 修改所需的字段值。当列允许时，可使用空值选项。
  3. 保存该行并确认更新后的结果。
  4. 完成后选择保存数据库以下载数据库。
重要：更改是对保存在浏览器内存中的数据库进行的，不会自动覆盖原始文件。关闭页面前请下载最新的数据库。

用 SQL 进行批量更改

查询工作区也支持 SQLite 写入语句。例如：

UPDATE "products"
SET "active" = 0
WHERE "last_order_at" < '2025-01-01';

执行更新或删除之前，请仔细检查 WHERE 条件。较好的做法是先把同样的条件作为 SELECT 运行，确认受影响的行，然后再执行写入查询。

是什么阻止了行编辑？

安全的行操作要求查看器能可靠地识别记录。没有主键的表在行界面中可能显示为只读。视图、计算结果、联接和聚合查询通常无法安全地映射回单个源行，但您仍可以查看或导出它们。

下载完成的数据库

“保存数据库”操作会导出当前 SQLite 数据库的状态，包括成功的行编辑和写入查询。在您用实际使用该数据库的应用测试过下载的文件之前，请保留原始文件作为备份。
