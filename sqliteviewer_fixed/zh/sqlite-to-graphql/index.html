将 SQLite 转换为 GraphQL SDL

将数据库实体转换为可读的 GraphQL 类型定义，然后根据应用需求进行调整。

打开 GraphQL SDL 导出器

生成结构

  1. 打开 SQLite 数据库。
  2. 在 ER 图中查看其实体。
  3. 选择 GraphQL SDL 作为导出格式。
  4. 导出类型定义，并在您的 API 项目中查看。
type Customer {
  id: Int!
  name: String
  orders: [Order!]
}

type Order {
  id: Int!
  customerId: Int!
}

SDL 不是完整的 API

数据库结构描述的是存储，而 GraphQL 描述的是面向应用的契约。生成的 SDL 不会创建解析器、身份验证、分页、验证、变更操作或字段级授权，请将其视为结构化的初稿。

检查类型映射

SQLite 类型与 GraphQL 标量并不能完美对应。日期可能以文本或数字存储，小数可能需要自定义标量，二进制数据需要应用特定的表示方式。当有更清晰的 API 名称时，请重命名技术性的数据库字段。

切勿自动暴露所有数据库表。只选择客户端应能访问的字段和操作，并在 API 层强制执行授权。

审慎使用关系

已声明的外键可以提示 GraphQL 关系，但解析器的行为取决于您的服务器实现。请考虑批处理和分页，以避免昂贵的嵌套数据库访问。
