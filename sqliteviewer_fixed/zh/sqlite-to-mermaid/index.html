创建 Mermaid 语法

  1. 打开 SQLite 文件。
  2. 打开 ER 图以核对实体和关系。
  3. 选择 Mermaid 并导出结构。
  4. 将结果粘贴到兼容 Mermaid 的 Markdown 或文档系统中。

文本式图表的优势

Mermaid 语法可以提交到版本控制、作为文本审阅，并在结构变化时重新生成。在项目 README、架构文档和技术笔记中很有用，因为这些地方的二进制图表文件难以维护。

了解关系的局限

转换器读取已声明的外键，无法仅凭相似的列名可靠地臆造关系。如果缺少预期的连线，请检查 SQLite 结构，并确认该关系已通过外键约束声明。

不同平台上的 Mermaid 渲染器可能略有差异。请在将发布的文档系统中测试导出的语法。

让图表保持聚焦

大型数据库可能产生过于拥挤的图表。可考虑按范围明确的主题领域（例如身份验证、计费或库存）分别记录，同时保留一份完整的结构导出以供参考。
