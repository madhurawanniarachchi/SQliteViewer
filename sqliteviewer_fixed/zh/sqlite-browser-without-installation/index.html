浏览器工具何时有用

基于网页的查看器适合一次性的数据库查看、技术支持、课堂练习、导出的应用数据库，以及无法安装软件的环境。应用从网络加载，但所选数据库在浏览器中本地处理。

无需安装即可使用的功能

  • 搜索和浏览表与视图。
  • 执行 SELECT 语句并查看分页结果。
  • 使用多个查询标签页和数据库标签页。
  • 添加、编辑或删除可安全识别的行。
  • 生成包含列、类型和键的 ER 图。
  • 导出结果或结构格式。
  • 下载当前修改后的数据库。

选浏览器工具还是桌面应用？

对于超大型数据库、加密扩展、持续的生产环境管理、高级索引分析或直接文件系统锁定，桌面应用仍然是更好的选择。当您重视速度、便携性和对普通 SQLite 文件的本地处理时，浏览器工具最具优势。

由于数据库保存在浏览器内存中，请保留原始文件，并在关闭或刷新页面之前下载更改。

隐私注意事项

请确认页面通过 HTTPS 提供，并使用可信的应用副本。SQLite Viewer 不需要上传数据库，但浏览器扩展和设备本身仍是您安全环境的一部分。
