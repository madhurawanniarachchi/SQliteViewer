स्कीमा एक्सपोर्ट

SQLite स्कीमा को SQL DDL में बदलें

दस्तावेज़ीकरण, समीक्षा, माइग्रेशन योजना या वर्ज़न कंट्रोल के लिए पढ़ने योग्य स्कीमा परिभाषाएँ निकालें।

SQLite स्कीमा एक्सपोर्टर खोलें

डेटाबेस फ़ाइल से SQL DDL एक्सपोर्ट करें

  1. SQLite डेटाबेस खोलें।
  2. ER डायग्राम खोलें।
  3. एक्सपोर्ट फ़ॉर्मैट के रूप में SQL DDL चुनें।
  4. बना हुआ स्कीमा टेक्स्ट एक्सपोर्ट करें और सहेजें।

परिणाम डेटाबेस की संरचना दर्शाता है, टेबल का डेटा नहीं। इसमें एंटिटी परिभाषाएँ, घोषित कॉलम टाइप और वह की जानकारी शामिल है जो SQLite स्कीमा मेटाडेटा से निकाली जा सकती है।

उदाहरण आउटपुट

CREATE TABLE "orders" (
  "id" INTEGER PRIMARY KEY,
  "customer_id" INTEGER NOT NULL,
  "created_at" TEXT,
  FOREIGN KEY ("customer_id") REFERENCES "customers" ("id")
);

SQL DDL किस काम आता है

  • कोड रिव्यू में डेटाबेस स्कीमा की समीक्षा करना।
  • संरचना में बदलावों को वर्ज़न कंट्रोल में रखना।
  • प्रोडक्शन की पंक्तियाँ उजागर किए बिना टेबल दस्तावेज़ित करना।
  • किसी दूसरे डेटाबेस सिस्टम में माइग्रेशन की तैयारी करना।
  • अपेक्षित और वास्तविक टेबल परिभाषाओं की तुलना करना।
माइग्रेशन नोट: SQLite का सिंटैक्स और टाइप एफ़िनिटी PostgreSQL, MySQL और SQL Server से अलग है। एक्सपोर्ट किए DDL को SQLite स्कीमा का भरोसेमंद विवरण मानें, फिर लक्ष्य इंजन के लिए टाइप, ऑटो-इन्क्रीमेंट व्यवहार, क्वोटिंग और कंस्ट्रेंट अनुकूलित करें।

स्कीमा एक्सपोर्ट बनाम डेटाबेस सहेजना

SQL DDL में केवल संरचना होती है। अगर आपको पंक्तियों और लोकल बदलावों सहित डेटाबेस चाहिए, तो DB सहेजें इस्तेमाल करें। अगर पंक्तियाँ पोर्टेबल टेक्स्ट फ़ॉर्मैट में चाहिए, तो परिणाम एक्सपोर्ट नियंत्रण इस्तेमाल करें।
