Android लाइव डीबगिंग

ADB ब्रिज सेट अप करें (Android Studio के साथ काम करता है)

एक छोटा सहायक SQLite Viewer और Android Studio को एक साथ आपके फ़ोन का इस्तेमाल करने देता है। उसे डाउनलोड करें, सही जगह रखें, अपने-आप शुरू होने वाला बनाएँ, और काम हो गया।

व्यूअर खोलें

क्या मुझे ब्रिज की ज़रूरत है?

अक्सर नहीं। SQLite Viewer आपके फ़ोन से सीधे USB पर बात कर सकता है (Chrome या Edge में USB डायरेक्ट मोड), कुछ इंस्टॉल किए बिना। ब्रिज एक स्थिति के लिए है: Android Studio (या कोई और ADB टूल) पहले से फ़ोन इस्तेमाल कर रहा है। USB कनेक्शन का मालिक एक समय में एक ही प्रोग्राम हो सकता है, इसलिए ब्रिज SQLite Viewer को Android Studio का ADB सर्वर साझा करने देता है। तब दोनों साथ काम करते हैं।

Windows: एक-क्लिक इंस्टॉलर

  1. इंस्टॉलर डाउनलोड करें। SQLite Viewer में Live Android खोलें, ADB सर्वर चुनें और इंस्टॉलर डाउनलोड करें (Windows) पर क्लिक करें।
  2. फ़ाइल रखें। Chrome कह सकता है कि फ़ाइल सत्यापित नहीं हो सकती। रखें (या असत्यापित फ़ाइल डाउनलोड करें) चुनें। फ़ाइल सादा टेक्स्ट है, इसलिए आप उसे Notepad में खोलकर ठीक-ठीक पढ़ सकते हैं कि वह क्या करती है।
  3. एक बार चलाएँ। Install-ADB-Bridge.cmd पर डबल-क्लिक करें। अगर Windows Windows protected your PC दिखाए, तो More info पर क्लिक करें, फिर Run anyway।
  4. पेज पर लौटें। इंस्टॉलर आपके PC पर ब्रिज बनाता है, उसे हर साइन-इन पर अपने-आप शुरू होने वाला बनाता है और अभी शुरू करता है। SQLite Viewer कुछ सेकंड में उसे पहचान लेता है। ब्रिज के ज़रिए कनेक्ट करें पर क्लिक करें।

ब्रिज %LOCALAPPDATA%\SQLiteViewerBridge में इंस्टॉल होता है और आपके Startup फ़ोल्डर का शॉर्टकट उसे साइन-इन पर शुरू करता है। हटाने के लिए उस फ़ोल्डर से uninstall.cmd चलाएँ।

कोई भी सिस्टम: Python से सेट अप करें

  1. Python 3 इंस्टॉल करें। इसे python.org से डाउनलोड करें। Windows पर इंस्टॉलर में Add Python to PATH पर टिक करें। अधिकांश Linux सिस्टम में python3 पहले से होता है। macOS में यह डिफ़ॉल्ट रूप से नहीं होता: पहली बार python3 टाइप करने पर macOS Apple के Command Line Tools इंस्टॉल करने की पेशकश करता है (स्वीकार करें), या आप python.org का इंस्टॉलर इस्तेमाल कर सकते हैं।
  2. फ़ाइल डाउनलोड करें। adb-bridge.py डाउनलोड करें। आपका ब्राउज़र इसे Downloads फ़ोल्डर में सहेजता है। अगर यह .txt पर खत्म होती है, तो इसका नाम बदलकर adb-bridge.py करें।
  3. इसे स्थायी जगह पर कॉपी करें। टर्मिनल खोलें (कोई भी फ़ोल्डर चलेगा, कमांड पूरे पाथ इस्तेमाल करते हैं) और अपने सिस्टम की कमांड चलाएँ। यह फ़ोल्डर बनाती है और फ़ाइल उसमें कॉपी करती है। अगर आपके ब्राउज़र ने फ़ाइल Downloads के अलावा कहीं और सहेजी है, तो कमांड का वह हिस्सा बदलें।
  4. इसे अपने-आप शुरू होने वाला बनाएँ। अपने सिस्टम की कमांड चलाएँ। यह उस फ़ाइल के लिए साइन-इन पर शुरू होने वाली एंट्री बनाती है जहाँ आपने उसे कॉपी किया, और ब्रिज अभी शुरू करती है।
  5. कनेक्ट करें। SQLite Viewer पर लौटें। वह ब्रिज को खुद ढूँढ लेता है। ब्रिज के ज़रिए कनेक्ट करें पर क्लिक करें।

चरण 3: फ़ाइल कॉपी करें (एक बार चलाएँ)

Windows (PowerShell; Windows कुंजी दबाएँ, powershell टाइप करें, Enter दबाएँ):

New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\SQLiteViewerBridgePython" | Out-Null; Copy-Item "$env:USERPROFILE\Downloads\adb-bridge.py" "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py"

Windows (Command Prompt; Windows कुंजी दबाएँ, cmd टाइप करें, Enter दबाएँ):

mkdir "%LOCALAPPDATA%\SQLiteViewerBridgePython" & copy "%USERPROFILE%\Downloads\adb-bridge.py" "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

macOS (Terminal):

mkdir -p "$HOME/Library/Application Support/SQLiteViewerBridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py"

Linux:

mkdir -p "$HOME/.local/share/sqliteviewer-bridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py"

चरण 4: साइन-इन पर अपने-आप शुरू कराएँ (एक बार चलाएँ)

Windows (PowerShell):

python "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

Windows (Command Prompt):

python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

macOS:

python3 "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py" --add-to-startup

Linux:

python3 "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py" --add-to-startup

Windows पर यह आपके Startup फ़ोल्डर में एक छिपा शॉर्टकट बनाता है, macOS पर Launch Agent, और Linux पर systemd यूज़र सर्विस (या डेस्कटॉप ऑटोस्टार्ट एंट्री)। किसी को भी एडमिनिस्ट्रेटर अधिकार नहीं चाहिए। फ़ाइल को जहाँ है वहीं रहने दें; अगर आप उसे हटाते हैं, तो कमांड दोबारा चलाएँ।

जल्दी में हैं? एक कमांड चरण 3 और 4 कर देती है

जहाँ फ़ाइल डाउनलोड की है उस फ़ोल्डर में टर्मिनल खोलें और चलाएँ:

python adb-bridge.py --install      # Windows
python3 adb-bridge.py --install     # macOS and Linux

Startup में हाथ से जोड़ना चाहते हैं?

Windows: Win + R दबाएँ, shell:startup टाइप करें और Enter दबाएँ। खुले फ़ोल्डर में राइट-क्लिक करें, New → Shortcut चुनें और लोकेशन इस पर सेट करें:

pythonw "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

इसका नाम SQLite Viewer ADB Bridge रखें। python की जगह pythonw इस्तेमाल करने से काली विंडो नहीं आती। साइन आउट करके दोबारा साइन इन करें, या अभी शुरू करने के लिए शॉर्टकट पर डबल-क्लिक करें।

macOS: ऊपर की कमांड ~/Library/LaunchAgents/com.sqliteviewer.adbbridge.plist बनाती है। Linux: यह ~/.config/systemd/user/sqliteviewer-bridge.service (या ~/.config/autostart/sqliteviewer-bridge.desktop) बनाती है। इन फ़ाइलों को हाथ से लिखना संभव है, पर कमांड ज़्यादा सुरक्षित है।

जाँचें, रोकें और हटाएँ

python adb-bridge.py --status                  # is it running?
python adb-bridge.py --remove-from-startup      # stop starting at sign-in (keeps the file)
python adb-bridge.py --uninstall                # stop it and delete everything
# add the full path to the file if you are not in its folder, as in the commands above

क्या मेरे पास ADB है? न हो तो इंस्टॉल करें

ब्रिज ADB (Android Platform Tools) तक रिले करता है। Android Studio में यह पहले से शामिल है, इसलिए अगर आप Android Studio इस्तेमाल करते हैं तो यह भाग छोड़ सकते हैं। जाँचने के लिए टर्मिनल खोलें और adb version चलाएँ। अगर सिस्टम कमांड नहीं पहचानता, तो नीचे की किसी एक कमांड से ADB इंस्टॉल करें। जब ब्रिज चल रहा हो पर ADB न मिले, तब SQLite Viewer भी बताता है। ब्रिज ADB को आपके PATH में और Android Studio, winget, Homebrew व मैन्युअल डाउनलोड के आम फ़ोल्डरों में खोजता है, इसलिए आपको PATH बदलने की ज़रूरत नहीं, और यह आपके लिए ADB सर्वर शुरू कर देता है।

Windows

सबसे आसान (Windows 10 और 11, PowerShell या Command Prompt):

winget install --id Google.PlatformTools -e

winget नहीं है? सीधे डाउनलोड करें (PowerShell):

Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile "$env:TEMP\pt.zip"; Expand-Archive "$env:TEMP\pt.zip" "$env:LOCALAPPDATA\Android\Sdk" -Force; Remove-Item "$env:TEMP\pt.zip"

Command Prompt में वही:

powershell -NoProfile -Command "Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile \"$env:TEMP\pt.zip\"; Expand-Archive \"$env:TEMP\pt.zip\" \"$env:LOCALAPPDATA\Android\Sdk\" -Force; Remove-Item \"$env:TEMP\pt.zip\""

जाँचें कि काम हुआ (PowerShell):

& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" version

macOS

Homebrew के साथ:

brew install --cask android-platform-tools

Homebrew के बिना:

mkdir -p "$HOME/Library/Android/sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-darwin.zip && unzip -o /tmp/pt.zip -d "$HOME/Library/Android/sdk" && rm /tmp/pt.zip

Linux

Debian, Ubuntu, Mint:

sudo apt install adb

Fedora:

sudo dnf install android-tools

Arch, Manjaro:

sudo pacman -S android-tools

कोई अन्य डिस्ट्रीब्यूशन:

mkdir -p "$HOME/Android/Sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-linux.zip && unzip -o /tmp/pt.zip -d "$HOME/Android/Sdk" && rm /tmp/pt.zip

फिर फ़ोन तैयार करें

  1. फ़ोन पर Settings → About phone खोलें और Build number पर सात बार टैप करें।
  2. Settings → Developer options खोलें और USB debugging चालू करें।
  3. फ़ोन प्लग इन करें और प्रॉम्प्ट पर Allow टैप करें। adb devices चलाने पर वह device के रूप में सूचीबद्ध होना चाहिए।

क्या मुझे कुछ कॉन्फ़िगर करना है?

नहीं। ब्रिज केवल SQLite Viewer वेबसाइट से कनेक्शन स्वीकार करता है, केवल आपके अपने कंप्यूटर पर (127.0.0.1) सुनता है, और केवल उसी कंप्यूटर के ADB सर्वर तक रिले करता है। कुछ भी कहीं और संग्रहीत या भेजा नहीं जाता।

केवल दो स्थितियों में आपको सेटिंग चाहिए:

  • आप SQLite Viewer किसी अलग पते से इस्तेमाल करते हैं (आपकी अपनी प्रति, या विकास के दौरान localhost)। उन्हीं कमांड में उस पते को अनुमति दें:
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --allow-origin https://your-address.example
  • पोर्ट 5038 पहले से इस्तेमाल में है। कोई दूसरा पोर्ट इस्तेमाल करें, फिर Android पैनल के Advanced में वही पोर्ट दर्ज करें:
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --port 5040

अनुमत पते ब्रिज के पास origins.txt नाम की फ़ाइल में याद रखे जाते हैं (हर पंक्ति में एक पता): Windows पर %LOCALAPPDATA%\SQLiteViewerBridge (इंस्टॉलर) या %LOCALAPPDATA%\SQLiteViewerBridgePython (Python), macOS पर ~/Library/Application Support/SQLiteViewerBridge, Linux पर ~/.local/share/sqliteviewer-bridge।

समस्या निवारण

  • “The bridge is not running on this computer”: इंस्टॉलर या ऊपर की कमांड चलाएँ, या साइन आउट करके दोबारा साइन इन करें। फिर Android पैनल दोबारा खोलें।
  • मेरे पास Python नहीं है: Windows पर इसकी ज़रूरत नहीं, ऊपर का एक-क्लिक इंस्टॉलर इस्तेमाल करें। वरना python.org से Python 3 इंस्टॉल करें (Windows: Add Python to PATH पर टिक करें), या macOS पर Command Line Tools इंस्टॉल करने की पेशकश स्वीकार करें। फिर कमांड दोबारा चलाएँ।
  • python पहचाना नहीं जाता, या Microsoft Store खुलता है (Windows): Python अभी इंस्टॉल नहीं है, या उसका PATH विकल्प छूट गया। python.org से इंस्टॉल करें, या कमांड में python की जगह py लिखें। आप Settings → Apps → Advanced app settings → App execution aliases में Store शॉर्टकट बंद भी कर सकते हैं।
  • कॉपी कमांड कहती है कि फ़ाइल नहीं मिली: आपके ब्राउज़र ने adb-bridge.py Downloads के अलावा कहीं और सहेजी। कमांड का वह हिस्सा बदलें, या .txt फ़ाइल का नाम बदलें।
  • “Something is already listening on port 5038”: कोई दूसरा ब्रिज चल रहा है। पुराने को हटाएँ (--uninstall या uninstall.cmd) या --port से दूसरा पोर्ट चुनें।
  • ब्रिज चल रहा है पर कोई फ़ोन नहीं दिखता: ADB सर्वर को फ़ोन दिखना चाहिए। adb devices चलाएँ, USB debugging चालू करें और फ़ोन पर “Allow USB debugging” प्रॉम्प्ट स्वीकार करें।
  • “The bridge is running, but ADB is not installed”: ऊपर क्या मेरे पास ADB है? भाग की कमांड से ADB इंस्टॉल करें (या Android Studio इंस्टॉल करें)। पेज कुछ सेकंड बाद खुद पहचान लेता है।
  • Chrome आपके नेटवर्क के डिवाइस तक पहुँच की अनुमति माँगता है: अनुमति दें। इसी तरह पेज आपके अपने कंप्यूटर के ब्रिज तक पहुँचता है।
  • एंटीवायरस या Windows इंस्टॉलर को रोकता है: इंस्टॉलर केवल उस स्रोत से एक छोटा प्रोग्राम बनाता है जिसे आप पढ़ सकते हैं, और आपके अपने यूज़र फ़ोल्डरों में लिखता है। इसे अनुमति दें, या Python वाला रास्ता अपनाएँ।
