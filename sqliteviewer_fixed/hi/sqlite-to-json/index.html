डेटा एक्सपोर्ट

SQLite को JSON में बदलें

पंक्तियों को ऑब्जेक्ट्स के JSON ऐरे के रूप में एक्सपोर्ट करें, जो API, फ़्रंट-एंड प्रोटोटाइप, टेस्ट फ़िक्स्चर और डॉक्यूमेंट डेटाबेस के लिए तैयार है।

JSON में एक्सपोर्ट करें

SQLite टेबल को JSON में एक्सपोर्ट करें

  1. अपनी .db, .sqlite, .sqlite3 या .db3 फ़ाइल SQLite Viewer में खोलें। वह आपके ब्राउज़र में ही रहती है।
  2. कोई टेबल चुनें, या ऐसी क्वेरी लिखें जो ठीक वही पंक्तियाँ लौटाए जो आपको चाहिए।
  3. परिणामों के ऊपर एक्सपोर्ट पर क्लिक करें और शामिल करने के लिए कॉलम चुनें।
  4. JSON चुनें और फ़ाइल तुरंत डाउनलोड हो जाती है।

JSON कैसा दिखता है

हर पंक्ति कॉलम नाम को की बनाकर एक ऑब्जेक्ट बन जाती है, और फ़ाइल इन ऑब्जेक्ट्स का ऐरे होती है।

[
  { "id": 1, "name": "Ada", "email": "ada@example.com" },
  { "id": 2, "name": "Linus", "email": "linus@example.com" }
]

SQL से आउटपुट का आकार तय करें

एक्सपोर्ट से पहले क्वेरी में AS से कॉलम का नाम बदलें, संबंधित टेबल जॉइन करें या पंक्तियाँ फ़िल्टर करें, ताकि JSON आपके ऐप की अपेक्षित संरचना से मेल खाए।

आपका डेटा आपके डिवाइस से बाहर कभी नहीं जाता

रूपांतरण आपके ब्राउज़र टैब में JavaScript के रूप में चलता है। डेटाबेस किसी सर्वर पर अपलोड नहीं होता, इसलिए इसे ग्राहक डेटा, ऐप डेटाबेस और आंतरिक फ़ाइलों के साथ इस्तेमाल करना सुरक्षित है।
