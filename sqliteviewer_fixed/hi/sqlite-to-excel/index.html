SQLite को Excel (XLSX) में बदलें

रिपोर्टिंग, साझा करने और आगे के विश्लेषण के लिए किसी भी टेबल या क्वेरी परिणाम से Excel वर्कबुक बनाएँ।

Excel में एक्सपोर्ट करें

SQLite टेबल को Excel में एक्सपोर्ट करें

  1. अपनी .db, .sqlite, .sqlite3 या .db3 फ़ाइल SQLite Viewer में खोलें। वह आपके ब्राउज़र में ही रहती है।
  2. कोई टेबल चुनें, या ऐसी क्वेरी लिखें जो ठीक वही पंक्तियाँ लौटाए जो आपको चाहिए।
  3. परिणामों के ऊपर एक्सपोर्ट पर क्लिक करें और शामिल करने के लिए कॉलम चुनें।
  4. Excel चुनें और फ़ाइल तुरंत डाउनलोड हो जाती है।

एक्सपोर्ट से पहले SQL इस्तेमाल करें

पहले SQL से टेबल फ़िल्टर, सॉर्ट, एग्रीगेट या जॉइन करें, फिर परिणाम एक्सपोर्ट करें। Excel को ठीक वही पंक्तियाँ और कॉलम मिलते हैं जो आपने चुने हैं, और टेबल का नाम शीट के नाम के रूप में इस्तेमाल होता है।

Excel एक्सपोर्ट अपनी स्प्रेडशीट लाइब्रेरी ज़रूरत पड़ने पर लोड करता है, इसलिए पहले Excel एक्सपोर्ट के लिए इंटरनेट कनेक्शन चाहिए। फिर भी आपका डेटाबेस आपके ब्राउज़र से बाहर नहीं जाता।

आपका डेटा आपके डिवाइस से बाहर कभी नहीं जाता

रूपांतरण आपके ब्राउज़र टैब में JavaScript के रूप में चलता है। डेटाबेस किसी सर्वर पर अपलोड नहीं होता, इसलिए इसे ग्राहक डेटा, ऐप डेटाबेस और आंतरिक फ़ाइलों के साथ इस्तेमाल करना सुरक्षित है।

Excel से इम्पोर्ट भी करें

SQLite Viewer .xlsx या .xls फ़ाइल को नए SQLite डेटाबेस में इम्पोर्ट भी कर सकता है, ताकि आप स्प्रेडशीट को SQL से क्वेरी कर सकें। सादा टेक्स्ट फ़ॉर्मैट पसंद है? CSV या JSON आज़माएँ।
