शुरुआत करें

SQLite फ़ाइल को ऑनलाइन सुरक्षित रूप से कैसे खोलें

डेस्कटॉप सॉफ़्टवेयर इंस्टॉल किए बिना और फ़ाइल को किसी रिमोट सर्वर पर भेजे बिना, अपने ब्राउज़र में लोकल SQLite डेटाबेस जाँचें।

SQLite Viewer खोलें

तीन चरणों में अपना डेटाबेस खोलें

  1. किसी आधुनिक डेस्कटॉप ब्राउज़र में SQLite Viewer खोलें।
  2. अपना डेटाबेस शुरुआती कार्ड पर छोड़ें, या उस पर क्लिक करके .db, .sqlite, .sqlite3 या .db3 फ़ाइल चुनें।
  3. साइडबार में कोई टेबल चुनें। व्यूअर एक क्वेरी टैब बनाता है और पंक्तियों का पहला पृष्ठ दिखाता है।
गोपनीयता: फ़ाइल ब्राउज़र के JavaScript द्वारा लोकल रूप से पढ़ी जाती है। टेबल जाँचने, SQL चलाने या ER डायग्राम बनाने के लिए उसे अपलोड करने की ज़रूरत नहीं।

आप क्या जाँच सकते हैं

टेबल सूची से टेबल और व्यू तक जल्दी पहुँचा जा सकता है। आप लंबे स्कीमा में खोज सकते हैं, टेबल को कई मापों से क्रमबद्ध कर सकते हैं, कॉलम की जानकारी देख सकते हैं, दिखने वाले कॉलम नियंत्रित कर सकते हैं और चौड़े परिणाम देखते समय कॉलम पिन कर सकते हैं।

अधिक विस्तृत काम के लिए SQL एडिटर इस्तेमाल करें। एक बुनियादी क्वेरी ऐसी दिखती है:

SELECT *
FROM "customers"
LIMIT 0, 30;

अगर फ़ाइल नहीं खुलती

  • पुष्टि करें कि वह असली SQLite डेटाबेस है, SQL टेक्स्ट डंप नहीं।
  • किसी असामान्य एक्सटेंशन का नाम बदलकर .db करके देखें ताकि वह फ़ाइल चयनकर्ता में दिखे।
  • जाँचें कि फ़ाइल एन्क्रिप्टेड तो नहीं; एन्क्रिप्टेड डेटाबेस को उसके अनुरूप एक्सटेंशन या की चाहिए और उसे सामान्य SQLite की तरह नहीं पढ़ा जा सकता।
  • बहुत बड़ी फ़ाइलों के लिए दोबारा कोशिश करने से पहले ज़्यादा मेमोरी लेने वाले ब्राउज़र टैब बंद करें।

अपने निष्कर्ष सहेजें या एक्सपोर्ट करें

क्वेरी परिणाम आम फ़ॉर्मैट में एक्सपोर्ट किए जा सकते हैं। अगर आप पंक्तियाँ संपादित करते हैं या राइट स्टेटमेंट चलाते हैं, तो मौजूदा डेटाबेस डाउनलोड करने के लिए DB सहेजें इस्तेमाल करें। मूल लोकल फ़ाइल चुपचाप ओवरराइट नहीं होती।
