ब्राउज़र डेटाबेस एडिटर

SQLite डेटाबेस ऑनलाइन संपादित करें

टेबल की पंक्तियाँ अपडेट करें, SQL राइट स्टेटमेंट चलाएँ और डेस्कटॉप SQLite एडिटर इंस्टॉल किए बिना नवीनतम डेटाबेस डाउनलोड करें।

SQLite एडिटर खोलें

प्राइमरी-की सुरक्षा के साथ पंक्तियाँ संपादित करें

डेटाबेस खोलें और कोई टेबल चुनें। जब टेबल में उपयोग योग्य प्राइमरी की होती है, तो परिणाम में अलग-अलग पंक्तियाँ संपादित और हटाने के विकल्प मिलते हैं। एडिटर पंक्ति की दृश्य स्थिति पर निर्भर रहने के बजाय प्राइमरी-की मानों से सही पंक्ति को निशाना बनाता है।

  1. पंक्ति पर संपादित करें चुनें।
  2. ज़रूरी फ़ील्ड मान बदलें। जब कॉलम इजाज़त दे तो null विकल्प इस्तेमाल करें।
  3. पंक्ति सहेजें और अपडेट किया परिणाम जाँचें।
  4. काम पूरा होने पर डेटाबेस डाउनलोड करने के लिए DB सहेजें चुनें।
महत्वपूर्ण: बदलाव ब्राउज़र मेमोरी में रखे डेटाबेस पर होते हैं। वे मूल फ़ाइल को अपने-आप ओवरराइट नहीं करते। पेज बंद करने से पहले नवीनतम डेटाबेस डाउनलोड करें।

थोक बदलाव के लिए SQL इस्तेमाल करें

क्वेरी वर्कस्पेस SQLite राइट स्टेटमेंट भी समर्थित करता है। उदाहरण:

UPDATE "products"
SET "active" = 0
WHERE "last_order_at" < '2025-01-01';

अपडेट या डिलीट चलाने से पहले WHERE शर्त ध्यान से जाँचें। अच्छा तरीका है कि पहले वही शर्त SELECT के रूप में चलाएँ, प्रभावित पंक्तियाँ पक्की करें और तभी राइट क्वेरी चलाएँ।

पंक्ति संपादन में क्या रुकावट बन सकता है?

सुरक्षित पंक्ति क्रियाओं के लिए व्यूअर को रिकॉर्ड भरोसेमंद ढंग से पहचानने होते हैं। बिना प्राइमरी की वाली टेबल पंक्ति इंटरफ़ेस में केवल-पढ़ने योग्य दिख सकती हैं। व्यू, गणना किए गए परिणाम, जॉइन और एग्रीगेट क्वेरी को आम तौर पर सुरक्षित रूप से किसी एक स्रोत पंक्ति से नहीं जोड़ा जा सकता, हालाँकि आप उन्हें देख या एक्सपोर्ट फिर भी कर सकते हैं।

पूरा डेटाबेस डाउनलोड करें

DB सहेजें क्रिया मौजूदा SQLite डेटाबेस की स्थिति एक्सपोर्ट करती है, जिसमें सफल पंक्ति संपादन और राइट क्वेरी शामिल हैं। जब तक आप डाउनलोड की गई फ़ाइल को उस ऐप में परख न लें जो उसे इस्तेमाल करता है, मूल फ़ाइल को बैकअप के रूप में रखें।
