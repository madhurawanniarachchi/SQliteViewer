Преобразование SQLite в JSON

Экспортируйте строки как JSON-массив объектов — для API, прототипов фронтенда, тестовых данных и документоориентированных баз.

Экспорт в JSON

Экспорт таблицы SQLite в JSON

  1. Откройте файл .db, .sqlite, .sqlite3 или .db3 в SQLite Viewer. Он остаётся в вашем браузере.
  2. Выберите таблицу или напишите запрос, возвращающий именно те строки, которые вам нужны.
  3. Нажмите Экспорт над результатами и выберите столбцы для включения.
  4. Выберите JSON, и файл сразу скачается.

Как выглядит JSON

Каждая строка превращается в объект с именами столбцов в качестве ключей, а файл — в массив таких объектов.

[
  { "id": 1, "name": "Ada", "email": "ada@example.com" },
  { "id": 2, "name": "Linus", "email": "linus@example.com" }
]

Настройте результат с помощью SQL

Используйте запрос, чтобы переименовать столбцы через AS, объединить связанные таблицы или отфильтровать строки до экспорта — так JSON будет соответствовать структуре, которую ожидает ваше приложение.

Ваши данные никогда не покидают ваше устройство

Преобразование выполняется как JavaScript во вкладке браузера. База данных не загружается на сервер, поэтому инструмент безопасно использовать с данными клиентов, базами данных приложений и внутренними файлами.
