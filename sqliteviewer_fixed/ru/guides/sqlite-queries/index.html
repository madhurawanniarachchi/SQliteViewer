Руководство по запросам SQLite

Полезные запросы для проверки баз данных SQLite

Начинайте с безопасного и точного SQL, когда нужно разобраться в таблицах, индексах, связях и качестве данных.

Открыть рабочую область SQL

Список пользовательских таблиц и представлений

SELECT type, name, sql
FROM sqlite_master
WHERE type IN ('table', 'view')
  AND name NOT LIKE 'sqlite_%'
ORDER BY type, name;

Просмотр столбцов таблицы

PRAGMA table_info('orders');

Запрос возвращает объявленный тип, допустимость NULL, значение по умолчанию и позицию в первичном ключе для каждого столбца.

Проверка внешних ключей

PRAGMA foreign_key_list('orders');
PRAGMA foreign_key_check;

Первый оператор описывает объявленные ссылки одной таблицы. Второй сообщает о строках, нарушающих включённые связи внешних ключей.

Поиск повторяющихся значений

SELECT email, COUNT(*) AS occurrences
FROM customers
WHERE email IS NOT NULL
GROUP BY email
HAVING COUNT(*) > 1
ORDER BY occurrences DESC;

Просмотр индексов

PRAGMA index_list('orders');

Найдя имя индекса, посмотрите его столбцы командой PRAGMA index_info('index_name').

Проверка поведения запроса

EXPLAIN QUERY PLAN
SELECT *
FROM orders
WHERE customer_id = 42
ORDER BY created_at DESC;

План может показать полное сканирование таблицы и то, может ли SQLite использовать подходящий индекс.

Безопасный порядок работы: начинайте с проверочных запросов SELECT или PRAGMA. Перед UPDATE или DELETE выполните SELECT с тем же условием WHERE и сохраните исходную копию базы данных.

Постраничный просмотр больших таблиц

SELECT *
FROM events
ORDER BY id
LIMIT 100 OFFSET 0;

Для многократной навигации по очень большим таблицам пагинация по ключу, например WHERE id > ? ORDER BY id LIMIT 100, часто эффективнее очень большого смещения.
