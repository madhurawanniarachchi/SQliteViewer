Отладка Android в реальном времени

Настройка моста ADB (работает вместе с Android Studio)

Один небольшой помощник позволяет SQLite Viewer и Android Studio одновременно работать с вашим телефоном. Скачайте его, поместите на место, настройте автозапуск — и всё готово.

Открыть просмотрщик

Нужен ли мне мост?

Часто нет. SQLite Viewer может работать с телефоном напрямую по USB (режим USB напрямую в Chrome или Edge) без установки чего-либо. Мост нужен в одном случае: Android Studio (или другой инструмент ADB) уже использует телефон. USB-подключением может владеть только одна программа, поэтому мост позволяет SQLite Viewer использовать общий сервер ADB Android Studio. Тогда обе работают одновременно.

USB напрямуюСервер ADB (мост)
Нужно ли что-то устанавливать?НетДа, один раз (в Windows — одним щелчком)
Работает при открытой Android Studio?Нет, её нужно закрытьДа
БраузерChrome или Edge на компьютереЛюбой современный браузер
Нужен ли ADB на ПК?НетДа (Android Studio или Platform Tools)

Windows: установщик в один щелчок

  1. Скачайте установщик. В SQLite Viewer откройте Live Android, выберите Сервер ADB и нажмите Скачать установщик (Windows).
  2. Сохраните файл. Chrome может сообщить, что файл невозможно проверить. Выберите Сохранить (или Скачать непроверенный файл). Файл — обычный текст, поэтому вы можете открыть его в Блокноте и прочитать, что именно он делает.
  3. Запустите его один раз. Дважды щёлкните Install-ADB-Bridge.cmd. Если Windows показывает Windows защитила ваш компьютер, нажмите Подробнее, затем Выполнить в любом случае.
  4. Вернитесь на страницу. Установщик создаёт мост на вашем ПК, настраивает его автозапуск при каждом входе в систему и запускает его. SQLite Viewer замечает его через несколько секунд. Нажмите Подключиться через мост.

Мост устанавливается в %LOCALAPPDATA%\SQLiteViewerBridge, а ярлык в папке «Автозагрузка» запускает его при входе. Чтобы удалить его, запустите uninstall.cmd из этой папки.

Любая система: настройка через Python

  1. Установите Python 3. Скачайте его на python.org. В Windows отметьте Add Python to PATH в установщике. В большинстве систем Linux python3 уже есть. В macOS его по умолчанию нет: при первом вводе python3 macOS предложит установить Command Line Tools от Apple (согласитесь) либо можно воспользоваться установщиком с python.org.
  2. Скачайте файл. Скачайте adb-bridge.py. Браузер сохранит его в папку «Загрузки». Если имя оканчивается на .txt, переименуйте файл в adb-bridge.py.
  3. Скопируйте его на постоянное место. Откройте терминал (подойдёт любая папка, команды используют полные пути) и выполните команду для вашей системы. Она создаёт папку и копирует в неё файл. Если браузер сохранил файл не в «Загрузки», измените эту часть команды.
  4. Настройте автозапуск. Выполните команду для вашей системы. Она создаёт запись автозапуска при входе для файла там, куда вы его скопировали, и запускает мост сейчас.
  5. Подключитесь. Вернитесь в SQLite Viewer. Он сам найдёт мост. Нажмите Подключиться через мост.

Шаг 3: скопируйте файл (выполняется один раз)

Windows (PowerShell; нажмите клавишу Windows, введите powershell, нажмите Enter):

New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\SQLiteViewerBridgePython" | Out-Null; Copy-Item "$env:USERPROFILE\Downloads\adb-bridge.py" "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py"

Windows (командная строка; нажмите клавишу Windows, введите cmd, нажмите Enter):

mkdir "%LOCALAPPDATA%\SQLiteViewerBridgePython" & copy "%USERPROFILE%\Downloads\adb-bridge.py" "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

macOS (Терминал):

mkdir -p "$HOME/Library/Application Support/SQLiteViewerBridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py"

Linux:

mkdir -p "$HOME/.local/share/sqliteviewer-bridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py"

Шаг 4: настройте автозапуск при входе (выполняется один раз)

Windows (PowerShell):

python "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

Windows (командная строка):

python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

macOS:

python3 "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py" --add-to-startup

Linux:

python3 "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py" --add-to-startup

В Windows создаётся скрытый ярлык в папке «Автозагрузка», в macOS — Launch Agent, в Linux — пользовательская служба systemd (или запись автозапуска рабочего стола). Ни одному из них не нужны права администратора. Оставьте файл на месте; если переместите его, выполните команду снова.

Спешите? Одна команда выполняет шаги 3 и 4

Откройте терминал в папке, куда вы скачали файл, и выполните:

python adb-bridge.py --install      # Windows
python3 adb-bridge.py --install     # macOS and Linux

Хотите добавить в автозагрузку вручную?

Windows: нажмите Win + R, введите shell:startup и нажмите Enter. В открывшейся папке щёлкните правой кнопкой, выберите Создать → Ярлык и укажите расположение:

pythonw "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

Назовите его SQLite Viewer ADB Bridge. Использование pythonw вместо python избавляет от чёрного окна. Выйдите из системы и войдите снова либо дважды щёлкните ярлык, чтобы запустить мост сейчас.

macOS: команда выше создаёт ~/Library/LaunchAgents/com.sqliteviewer.adbbridge.plist. Linux: она создаёт ~/.config/systemd/user/sqliteviewer-bridge.service (или ~/.config/autostart/sqliteviewer-bridge.desktop). Эти файлы можно написать вручную, но команда надёжнее.

Проверка, остановка и удаление

python adb-bridge.py --status                  # is it running?
python adb-bridge.py --remove-from-startup      # stop starting at sign-in (keeps the file)
python adb-bridge.py --uninstall                # stop it and delete everything
# add the full path to the file if you are not in its folder, as in the commands above

Есть ли у меня ADB? Установите, если нет

Мост передаёт запросы в ADB (Android Platform Tools). В Android Studio он уже есть, поэтому если вы пользуетесь Android Studio, этот раздел можно пропустить. Для проверки откройте терминал и выполните adb version. Если система не знает такой команды, установите ADB одной из команд ниже. SQLite Viewer также сообщает, когда мост работает, но не находит ADB. Мост ищет ADB в PATH и в обычных папках Android Studio, winget, Homebrew и ручной загрузки, поэтому менять PATH не нужно, а сервер ADB он запускает сам.

Windows

Проще всего (Windows 10 и 11, PowerShell или командная строка):

winget install --id Google.PlatformTools -e

Нет winget? Скачайте напрямую (PowerShell):

Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile "$env:TEMP\pt.zip"; Expand-Archive "$env:TEMP\pt.zip" "$env:LOCALAPPDATA\Android\Sdk" -Force; Remove-Item "$env:TEMP\pt.zip"

То же в командной строке:

powershell -NoProfile -Command "Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile \"$env:TEMP\pt.zip\"; Expand-Archive \"$env:TEMP\pt.zip\" \"$env:LOCALAPPDATA\Android\Sdk\" -Force; Remove-Item \"$env:TEMP\pt.zip\""

Проверьте, что всё получилось (PowerShell):

& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" version

macOS

С Homebrew:

brew install --cask android-platform-tools

Без Homebrew:

mkdir -p "$HOME/Library/Android/sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-darwin.zip && unzip -o /tmp/pt.zip -d "$HOME/Library/Android/sdk" && rm /tmp/pt.zip

Linux

Debian, Ubuntu, Mint:

sudo apt install adb

Fedora:

sudo dnf install android-tools

Arch, Manjaro:

sudo pacman -S android-tools

Любой другой дистрибутив:

mkdir -p "$HOME/Android/Sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-linux.zip && unzip -o /tmp/pt.zip -d "$HOME/Android/Sdk" && rm /tmp/pt.zip

Затем подготовьте телефон

  1. На телефоне откройте Настройки → О телефоне и семь раз нажмите Номер сборки.
  2. Откройте Настройки → Для разработчиков и включите Отладку по USB.
  3. Подключите телефон и нажмите Разрешить в появившемся запросе. После adb devices телефон должен отображаться как device.

Нужно ли что-то настраивать?

Нет. Мост принимает подключения только с сайта SQLite Viewer, слушает только на вашем компьютере (127.0.0.1) и передаёт запросы только на сервер ADB на том же компьютере. Ничего не сохраняется и никуда больше не отправляется.

Настройка нужна лишь в двух случаях:

  • Вы используете SQLite Viewer с другого адреса (собственная копия или localhost при разработке). Разрешите этот адрес в тех же командах:
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --allow-origin https://your-address.example
  • Порт 5038 уже занят. Используйте другой порт, а затем введите тот же порт в разделе Advanced панели Android:
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --port 5040

Разрешённые адреса сохраняются в файле origins.txt (один адрес в строке) рядом с мостом: в Windows %LOCALAPPDATA%\SQLiteViewerBridge (установщик) или %LOCALAPPDATA%\SQLiteViewerBridgePython (Python), в macOS ~/Library/Application Support/SQLiteViewerBridge, в Linux ~/.local/share/sqliteviewer-bridge.

Устранение неполадок

  • «The bridge is not running on this computer»: запустите установщик или команды выше либо выйдите из системы и войдите снова. Затем заново откройте панель Android.
  • У меня нет Python: в Windows он не нужен — воспользуйтесь установщиком в один щелчок выше. В остальных случаях установите Python 3 с python.org (Windows: отметьте Add Python to PATH) или в macOS согласитесь на установку Command Line Tools. Затем снова выполните команды.
  • python не распознаётся или открывается Microsoft Store (Windows): Python ещё не установлен либо пропущена опция PATH. Установите его с python.org или замените python на py в командах. Также можно отключить ярлык Store в Параметры → Приложения → Дополнительные параметры приложений → Псевдонимы выполнения приложений.
  • Команда копирования сообщает, что файл не найден: браузер сохранил adb-bridge.py не в «Загрузки». Измените эту часть команды или переименуйте файл .txt.
  • «Something is already listening on port 5038»: уже запущен другой мост. Удалите старый (--uninstall или uninstall.cmd) или выберите другой порт через --port.
  • Мост работает, но телефон не появляется: сервер ADB должен видеть телефон. Выполните adb devices, включите отладку по USB и подтвердите на телефоне запрос «Разрешить отладку по USB».
  • «The bridge is running, but ADB is not installed»: установите ADB командами из раздела Есть ли у меня ADB? выше (или установите Android Studio). Страница сама заметит это через несколько секунд.
  • Chrome просит разрешить доступ к устройствам в вашей сети: разрешите. Так страница получает доступ к мосту на вашем компьютере.
  • Антивирус или Windows блокирует установщик: установщик лишь собирает небольшую программу из исходного кода, который вы можете прочитать, и записывает данные в ваши пользовательские папки. Разрешите его или воспользуйтесь вариантом с Python.
