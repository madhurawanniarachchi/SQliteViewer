Как безопасно открыть файл SQLite онлайн

Изучайте локальную базу данных SQLite в браузере, не устанавливая настольное ПО и не отправляя файл на удалённый сервер.

Открыть SQLite Viewer

Откройте базу данных за три шага

  1. Откройте SQLite Viewer в современном браузере на компьютере.
  2. Перетащите базу данных на стартовую карточку или нажмите на неё и выберите файл .db, .sqlite, .sqlite3 или .db3.
  3. Выберите таблицу на боковой панели. Просмотрщик создаст вкладку запроса и покажет первую страницу строк.
Конфиденциальность: файл читается локально JavaScript браузера. Для просмотра таблиц, выполнения SQL и создания ER-диаграммы его не нужно загружать.

Что можно изучить

Список таблиц обеспечивает быстрый доступ к таблицам и представлениям. Вы можете искать по длинным схемам, сортировать таблицы по нескольким показателям, просматривать сведения о столбцах, управлять видимыми столбцами и закреплять столбцы при просмотре широких наборов результатов.

Для более подробной работы используйте SQL-редактор. Простой запрос выглядит так:

SELECT *
FROM "customers"
LIMIT 0, 30;

Если файл не открывается

  • Убедитесь, что это настоящая база данных SQLite, а не текстовый дамп SQL.
  • Попробуйте переименовать нестандартное расширение в .db, чтобы файл появился в окне выбора.
  • Проверьте, не зашифрован ли файл: зашифрованной базе данных нужно соответствующее расширение или ключ, и её нельзя прочитать как обычный SQLite.
  • Для очень больших файлов перед повторной попыткой закройте вкладки браузера, потребляющие много памяти.

Сохраните или экспортируйте результаты

Результаты запросов можно экспортировать в распространённые форматы. Если вы редактируете строки или выполняете операторы записи, используйте Сохранить БД, чтобы скачать текущую базу данных. Исходный локальный файл не перезаписывается незаметно.
