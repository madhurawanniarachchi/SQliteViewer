On the phone: open Settings → About phone, tap Build number 7 times, then Settings → Developer options → turn on USB debugging. Plug the phone in and tap Allow when it asks.

You opened this page from a file, so browsers hide its origin ('null') and the bridge must allow every local file page. It is safer to serve the folder with python -m http.server 8000 and open http://localhost:8000 instead.

Advanced
  • Enable USB debugging on the phone and accept the prompt when connecting.
  • Only debuggable apps (debug builds) can be read. Release apps are protected by Android.
  • If the device is busy, run adb kill-server and close Android Studio, then connect again.
  • Use Chrome or Edge on desktop. The view is read-only and re-copies the file on each refresh.

Просматривайте и редактируйте файлы SQLite без загрузки данных

SQLite Viewer работает прямо в браузере. Откройте локальный файл .db, .sqlite, .sqlite3 или .db3, изучите схему и строки, выполните SQL, внесите изменения и скачайте актуальную базу данных — и всё это без отправки файла на сервер.

Просмотр и поиск таблиц

Свободно перемещайтесь по большим схемам, сортируйте список таблиц по имени, числу строк, ячеек или примерному размеру и закрепляйте важные столбцы результатов.

Редактирование реальных строк базы данных

Добавляйте, обновляйте и удаляйте строки с учётом первичного ключа. Изменения остаются в базе данных в браузере, пока вы не скачаете её.

SQL-среда с несколькими вкладками

Открывайте новую вкладку для каждой таблицы или запроса, переключайтесь между несколькими базами данных и сохраняйте связь каждого результата с его запросом.

Создание ER-диаграммы

Визуализируйте сущности, столбцы, типы данных, первичные ключи и связи внешних ключей, а затем вписывайте диаграмму в окно.

Экспорт схемы и результатов

Экспортируйте ER-схемы в SQL DDL, DBML, Mermaid или GraphQL SDL, а результаты запросов — в распространённые форматы данных.

Сохранение изменённого файла SQLite

Изменения применяются локально. Нажмите «Сохранить БД», когда захотите скачать текущую базу как готовый файл SQLite.

Частые вопросы

Вопросы и ответы о SQLite Viewer

Загружается ли моя база данных SQLite?

Нет. База данных открывается и обрабатывается локально средствами JavaScript в вашем браузере. Инструменту не нужно загружать файл для его просмотра.

Можно ли редактировать и сохранять базу данных SQLite?

Да. Вы можете редактировать строки поддерживаемых таблиц или выполнять запросы на запись, а затем скачать актуальное состояние кнопкой «Сохранить БД».

Какие расширения файлов SQLite поддерживаются?

Окно выбора файла принимает .db, .sqlite, .sqlite3 и .db3. Корректная база SQLite может иметь и другое расширение, но перед выбором её, возможно, придётся переименовать.

Работает ли это с большими базами данных?

Работа с большими файлами зависит от доступной памяти браузера. Просмотрщик ограничивает число отображаемых строк и выборочно собирает «тяжёлые» метаданные таблиц, чтобы оставаться отзывчивым.
