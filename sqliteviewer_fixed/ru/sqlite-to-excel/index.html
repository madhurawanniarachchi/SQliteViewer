Преобразование SQLite в Excel (XLSX)

Создайте книгу Excel из любой таблицы или результата запроса для отчётов, обмена и дальнейшего анализа.

Экспорт в Excel

Экспорт таблицы SQLite в Excel

  1. Откройте файл .db, .sqlite, .sqlite3 или .db3 в SQLite Viewer. Он остаётся в вашем браузере.
  2. Выберите таблицу или напишите запрос, возвращающий именно те строки, которые вам нужны.
  3. Нажмите Экспорт над результатами и выберите столбцы для включения.
  4. Выберите Excel, и файл сразу скачается.

Используйте SQL перед экспортом

Сначала отфильтруйте, отсортируйте, агрегируйте или объедините таблицы с помощью SQL, затем экспортируйте результат. Excel получит именно выбранные строки и столбцы, а имя таблицы станет названием листа.

Экспорт в Excel подгружает библиотеку электронных таблиц по требованию, поэтому для первого экспорта нужно подключение к интернету. База данных по-прежнему не покидает ваш браузер.

Ваши данные никогда не покидают ваше устройство

Преобразование выполняется как JavaScript во вкладке браузера. База данных не загружается на сервер, поэтому инструмент безопасно использовать с данными клиентов, базами данных приложений и внутренними файлами.

Можно и импортировать из Excel

SQLite Viewer также умеет импортировать файл .xlsx или .xls в новую базу SQLite, чтобы вы могли запрашивать электронную таблицу через SQL. Предпочитаете простой текстовый формат? Попробуйте CSV или JSON.
