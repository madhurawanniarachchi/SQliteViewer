Преобразование SQLite в DBML

Превратите существующую схему SQLite в читаемый DBML для документации и процессов проектирования баз данных.

Открыть экспорт в DBML

Создание DBML из файла SQLite

  1. Откройте базу данных в SQLite Viewer.
  2. Выберите ER-диаграмма.
  3. Выберите DBML в списке форматов экспорта.
  4. Экспортируйте полученный текст и просмотрите его в любимом инструменте для DBML.

Что входит в преобразование

Экспорт описывает таблицы, имена столбцов, объявленные типы данных SQLite, первичные ключи и объявленные связи внешних ключей. Этого достаточно, чтобы инструменты проектирования построили полезную модель, не раскрывая строки таблиц.

Table orders {
  id integer [pk]
  customer_id integer [not null]
  created_at text
}

Ref: orders.customer_id > customers.id

Зачем нужен DBML?

DBML проще проверять, чем двоичный файл базы данных, и он больше ориентирован на моделирование данных, чем исполняемый SQL. Команды используют его, чтобы обсуждать схемы, создавать диаграммы, документировать связи и планировать изменения до написания миграций.

DBML — это проектное представление, а не побайтовая резервная копия базы данных. Сохраняйте исходный файл SQLite и используйте «Сохранить БД», когда нужна рабочая база с данными.

Проверьте созданную модель

SQLite допускает гибкое объявление типов, а в схемах могут отсутствовать внешние ключи. Проверьте пользовательские типы, составные ограничения, вычисляемые столбцы, индексы и связи, существующие только в коде приложения. При необходимости добавьте проектные пометки после экспорта.
