Конфиденциальность

Ваша база данных остаётся в вашем браузере

SQLite Viewer предназначен для открытия и обработки выбранных файлов баз данных на устройстве пользователя, а не для загрузки их содержимого на сервер для обработки.

Локальная обработка базы данных

Когда вы выбираете файл SQLite, JavaScript браузера считывает его в локальную память. Просмотр таблиц, выполнение SQL, редактирование строк, изучение схемы и экспорт базы данных происходят в сеансе браузера. Для работы этих функций приложению не нужно передавать выбранный файл на сервер.

Что может получать сайт

Как и большинство сайтов, инфраструктура хостинга может получать обычные сведения о запросах: IP-адрес, тип браузера, запрошенные страницы, отметки времени и журналы ошибок. Сайт может использовать аналитику, чтобы понимать посещаемость страниц и общее использование. Имена файлов баз данных, содержимое таблиц и текст SQL-запросов не должны намеренно отправляться как события аналитики.

Хранилище браузера

Приложение может использовать хранилище браузера для локальных настроек и сведений о рабочей области, например вкладок запросов или истории запросов. Эта информация остаётся связанной с профилем браузера, пока её не очистит пользователь или браузер.

Загрузки и исходные файлы

Редактирование выполняется в базе данных в памяти. «Сохранить БД» создаёт загрузку текущего состояния. Приложение не заменяет незаметно исходный файл базы данных на диске.

Ваша ответственность

Используйте базы данных, доступ к которым вам разрешён. Учитывайте безопасность устройства, профиля браузера и установленных расширений при открытии конфиденциальных файлов. Очищайте хранилище браузера и скачанные копии, если работаете на общем устройстве.

Сторонние ресурсы

Страница может загружать библиотеки, аналитику и другие ресурсы сайтов от сторонних сервисов. Эти сервисы могут получать обычные данные веб-запросов, но выбранная база данных намеренно в эти запросы не включается.

Для особо конфиденциальных или регулируемых данных используйте среду и конфигурацию браузера, одобренные вашей организацией, и перед использованием проверьте сетевое поведение развёрнутого приложения.
