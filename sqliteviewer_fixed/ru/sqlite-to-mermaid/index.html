Открыть экспорт в Mermaid

Создание синтаксиса Mermaid

  1. Откройте файл SQLite.
  2. Откройте ER-диаграмму, чтобы проверить сущности и связи.
  3. Выберите Mermaid и экспортируйте схему.
  4. Вставьте результат в Markdown или систему документации с поддержкой Mermaid.

  CUSTOMER ||--o{ ORDER : places

  }

Преимущества текстовых диаграмм

Синтаксис Mermaid можно хранить в системе контроля версий, проверять как текст и пересоздавать при изменении схемы. Он удобен в README проектов, архитектурной документации и технических заметках, где файл бинарной диаграммы было бы трудно поддерживать.

Ограничения определения связей

Конвертер читает объявленные внешние ключи. Он не может надёжно придумывать связи только по похожим именам столбцов. Если ожидаемой линии нет, проверьте схему SQLite и убедитесь, что связь объявлена ограничением внешнего ключа.

Средства отображения Mermaid могут немного отличаться на разных платформах. Проверьте экспортированный синтаксис в системе документации, где он будет опубликован.

Сохраняйте диаграммы сфокусированными

Крупные базы данных могут давать перегруженные диаграммы. Рассмотрите отдельное документирование ограниченных предметных областей — например, аутентификации, биллинга или склада — и сохраните полный экспорт схемы для справки.
