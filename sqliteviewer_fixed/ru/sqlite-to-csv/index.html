Преобразование SQLite в CSV

Превратите таблицу или результат любого SQL-запроса в файл CSV, который можно открыть в Excel, Google Таблицах или импортировать в другую базу данных.

Экспорт в CSV

Экспорт таблицы SQLite в CSV

  1. Откройте файл .db, .sqlite, .sqlite3 или .db3 в SQLite Viewer. Он остаётся в вашем браузере.
  2. Выберите таблицу или напишите запрос, возвращающий именно те строки, которые вам нужны.
  3. Нажмите Экспорт над результатами и выберите столбцы для включения.
  4. Выберите CSV, и файл сразу скачается.

Экспортируйте только нужное

Поскольку экспорт следует текущему запросу, вы можете сначала отфильтровать данные через WHERE, объединить таблицы, отсортировать или ограничить строки, а затем экспортировать именно этот результат. Выбор столбцов позволяет исключить из файла ненужные столбцы.

Совет: чтобы экспортировать таблицу целиком, выберите её и удалите LIMIT из запроса перед нажатием «Экспорт».

Ваши данные никогда не покидают ваше устройство

Преобразование выполняется как JavaScript во вкладке браузера. База данных не загружается на сервер, поэтому инструмент безопасно использовать с данными клиентов, базами данных приложений и внутренними файлами.

Когда использовать CSV

CSV — самый универсальный формат для электронных таблиц, BI-инструментов и массового импорта. Если нужны типизированные значения или вложенные данные, используйте JSON; для форматированной книги — Excel.
