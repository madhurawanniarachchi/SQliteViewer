Открыть базу данных Android

Сначала легально и безопасно экспортируйте базу данных

SQLite Viewer открывает файл, который у вас уже есть; он не извлекает базы данных из телефона. Используйте Device Explorer в Android Studio, эмулятор, резервную копию приложения или собственные средства отладки, чтобы получить базу данных, которую вы вправе изучать.

Базы данных приложений Android обычно находятся в каталоге databases конкретного приложения и могут иметь расширение .db или не иметь его. Если окно выбора файла в браузере не показывает копию без расширения, переименуйте экспортированный файл так, чтобы он оканчивался на .db.

Откройте и изучите схему приложения

  1. Перетащите экспортированную базу данных в SQLite Viewer.
  2. Найдите на боковой панели таблиц функцию, которую вы отлаживаете.
  3. Откройте вероятные таблицы и просмотрите последние строки.
  4. Используйте ER-диаграмму, чтобы понять внешние ключи и связи в стиле Room.
  5. Выполняйте точные SQL-запросы вместо прокрутки больших таблиц событий или кэша.
SELECT *
FROM "sync_queue"
ORDER BY "created_at" DESC
LIMIT 0, 100;

Просмотр базы данных отладочного приложения в реальном времени по USB

В Chrome или Edge на компьютере выберите Android на панели инструментов, подключите телефон с включённой отладкой по USB и выберите одно из ваших отлаживаемых приложений. SQLite Viewer копирует базу данных через run-as, объединяет журнал упреждающей записи, чтобы учесть недавние записи, и может обновлять её каждые несколько секунд во время тестирования. Всё остаётся в вашем браузере. Релизные сборки защищены Android и не могут быть прочитаны таким способом.

Android Studio занимает USB-подключение, поэтому в просмотрщике есть и режим сервера ADB: в Windows скачайте установщик моста в один клик и один раз дважды щёлкните его. Он настроит небольшую вспомогательную программу, которая запускается сама при каждом входе в систему, а страница использует сервер ADB совместно с Android Studio, так что обе работают одновременно. В macOS и Linux вместо этого запустите вспомогательную программу adb-bridge.py. Страница обнаружит мост автоматически. Полная справка: руководство по настройке моста ADB.

Хотите изменять данные без перезапуска приложения? Добавьте небольшой отладочный помощник и следуйте руководству по настройке редактирования в реальном времени.

Правильная работа с базами данных WAL

SQLite может использовать журнал упреждающей записи, создавая сопутствующие файлы -wal и -shm. Если скопировать только основную базу данных во время записи приложением, недавние транзакции могут быть потеряны. Лучше использовать согласованный экспорт, созданный при закрытой базе данных или после контрольной точки.

Конфиденциальные данные: базы данных приложений могут содержать персональные сведения, токены или бизнес-записи. Используйте только файлы, которые вы вправе изучать, и удаляйте экспортированные копии после завершения отладки.

Редактирование баз данных Android

Вы можете отредактировать копию и скачать её, но замена базы данных приложения может нарушить ожидания схемы или повредить состояние приложения. Сохраняйте оригинал, проверяйте ограничения и по возможности используйте поддерживаемые средства миграции или отладки.
