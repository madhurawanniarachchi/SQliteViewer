Genera un diagrama ER a partir de SQLite

Convierte una base de datos desconocida en un mapa legible de tablas, columnas, tipos, claves primarias y conexiones de claves externas.

Abrir la herramienta de diagrama ER

Crea el diagrama

  1. Abre la base de datos SQLite en el visor.
  2. Selecciona Diagrama ER en la barra lateral de tablas.
  3. Usa Ajustar para llevar todas las entidades a la vista del cuadro de diálogo.
  4. Revisa los nombres de columna, los tipos de datos de SQLite y los marcadores de clave de cada entidad.

Las líneas de relación se derivan de las claves externas declaradas en SQLite. Si una relación lógica no está definida con una restricción de clave externa, un lector de esquemas no puede identificarla de forma fiable solo por los nombres de las columnas.

Cómo leer el resultado

  • PK identifica una columna de clave primaria usada para direccionar una fila de forma única.
  • FK identifica una columna que hace referencia a una clave de otra tabla.
  • Los tipos de columna muestran el tipo declarado en SQLite. Debido al sistema de tipos flexible de SQLite, los valores almacenados a veces pueden diferir de esa declaración.
  • Las líneas de conexión muestran las entidades referenciadas y las que referencian.
Un diagrama es más útil cuando la base de datos declara las claves primarias y externas de forma coherente. Las líneas que faltan suelen indicar restricciones ausentes, no un problema de renderizado.

Exporta el esquema

Tras revisar el diagrama, exporta su esquema como SQL DDL, DBML, Mermaid o GraphQL SDL. SQL DDL es lo más parecido a la definición original de la base de datos. DBML y Mermaid sirven para documentación. GraphQL SDL es un punto de partida para un modelo de API y puede requerir ajustes específicos de la aplicación.

Preguntas útiles para revisar

Busca tablas sin claves primarias, claves externas que apuntan a entidades inesperadas, nombres incoherentes, columnas que admiten nulos pero deberían ser obligatorias y tablas intermedias que representan relaciones de muchos a muchos. Estas comprobaciones ayudan al heredar la base de datos de una aplicación o al planificar una migración.
