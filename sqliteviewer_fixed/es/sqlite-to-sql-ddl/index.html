Exportación del esquema

Convertir un esquema de SQLite a SQL DDL

Extrae definiciones de esquema legibles para documentación, revisión, planificación de migraciones o control de versiones.

Abrir el exportador de esquemas SQLite

Exporta SQL DDL desde un archivo de base de datos

  1. Abre la base de datos SQLite.
  2. Abre el diagrama ER.
  3. Selecciona SQL DDL como formato de exportación.
  4. Exporta y guarda el texto del esquema generado.

El resultado representa la estructura de la base de datos, no los datos de las tablas. Incluye las definiciones de entidades, los tipos de columna declarados y la información de claves que puede inferirse de los metadatos del esquema de SQLite.

Ejemplo de salida

CREATE TABLE "orders" (
  "id" INTEGER PRIMARY KEY,
  "customer_id" INTEGER NOT NULL,
  "created_at" TEXT,
  FOREIGN KEY ("customer_id") REFERENCES "customers" ("id")
);

Para qué sirve SQL DDL

  • Revisar el esquema de una base de datos en una revisión de código.
  • Mantener los cambios de estructura en el control de versiones.
  • Documentar tablas sin exponer filas de producción.
  • Preparar una migración a otro sistema de bases de datos.
  • Comparar las definiciones de tablas esperadas y reales.
Nota sobre migraciones: la sintaxis y la afinidad de tipos de SQLite difieren de PostgreSQL, MySQL y SQL Server. Trata el DDL exportado como una descripción fiable del esquema de SQLite y luego adapta los tipos, el comportamiento de autoincremento, el entrecomillado y las restricciones al motor de destino.

Exportar el esquema frente a guardar la base de datos

SQL DDL contiene solo la estructura. Si necesitas la base de datos con sus filas y ediciones locales, usa Guardar BD. Si necesitas las filas en un formato de texto portátil, usa los controles de exportación de resultados.
