Exportar a JSON

Exportar una tabla de SQLite a JSON

  1. Abre tu archivo .db, .sqlite, .sqlite3 o .db3 en SQLite Viewer. Se queda en tu navegador.
  2. Selecciona una tabla o escribe una consulta que devuelva exactamente las filas que necesitas.
  3. Haz clic en Exportar sobre los resultados y elige las columnas que quieres incluir.
  4. Elige JSON y el archivo se descarga de inmediato.

Cómo se ve el JSON

Cada fila se convierte en un objeto con el nombre de columna como clave, y el archivo es un arreglo de esos objetos.

[
  { "id": 1, "name": "Ada", "email": "ada@example.com" },
  { "id": 2, "name": "Linus", "email": "linus@example.com" }
]

Da forma a la salida con SQL

Usa una consulta para renombrar columnas con AS, unir tablas relacionadas o filtrar filas antes de exportar, de modo que el JSON coincida con la estructura que espera tu aplicación.

Tus datos nunca salen de tu dispositivo

La conversión se ejecuta como JavaScript en la pestaña de tu navegador. La base de datos no se sube a ningún servidor, así que es seguro usarla con datos de clientes, bases de datos de apps y archivos internos.
