Ver una base de datos SQLite de Android

Abre una base de datos de app exportada desde un emulador, una compilación de depuración o un dispositivo autorizado e inspecciónala sin instalar un explorador de bases de datos de escritorio.

Abrir base de datos de Android

Primero exporta la base de datos de forma legal y segura

SQLite Viewer abre un archivo que ya posees; no extrae bases de datos de un teléfono. Usa el Device Explorer de Android Studio, un emulador, una copia de seguridad de la aplicación o tus propias herramientas de depuración para obtener una base de datos que estés autorizado a inspeccionar.

Las bases de datos de las apps de Android suelen aparecer en un directorio databases específico de la aplicación y pueden usar .db o no tener extensión. Si el selector del navegador no muestra una copia sin extensión, renombra el archivo exportado para que termine en .db.

Abre e inspecciona el esquema de la app

  1. Suelta la base de datos exportada sobre SQLite Viewer.
  2. Busca en la barra lateral de tablas la función que estás depurando.
  3. Abre las tablas probables e inspecciona las filas recientes.
  4. Usa el diagrama ER para entender las claves externas y las relaciones al estilo Room.
  5. Ejecuta SQL concreto en lugar de desplazarte por tablas grandes de eventos o de caché.
SELECT *
FROM "sync_queue"
ORDER BY "created_at" DESC
LIMIT 0, 100;

Ver la base de datos de una app de depuración en vivo por USB

En Chrome o Edge de escritorio, elige Android en la barra de herramientas, conecta tu teléfono con la depuración USB activada y elige una de tus apps depurables. SQLite Viewer copia la base de datos con run-as, fusiona el registro de escritura anticipada para que se incluyan las escrituras recientes y puede actualizarla cada pocos segundos mientras pruebas. Todo permanece en tu navegador. Las compilaciones de lanzamiento están protegidas por Android y no pueden leerse de este modo.

Android Studio mantiene ocupada la conexión USB, por lo que el visor también tiene un modo de servidor ADB: en Windows, descarga el instalador del puente de un solo clic y haz doble clic en él una vez. Configura un pequeño ayudante que se inicia solo en cada inicio de sesión, y la página comparte el servidor ADB con Android Studio para que ambos funcionen a la vez. En macOS y Linux, ejecuta en su lugar el ayudante adb-bridge.py. La página detecta el puente automáticamente. Ayuda completa: guía de configuración del puente ADB.

¿Quieres cambiar datos sin reiniciar la app? Añade un pequeño ayudante solo para depuración y sigue la guía de configuración de edición en vivo.

Maneja correctamente las bases de datos WAL

SQLite puede usar registro de escritura anticipada, lo que genera archivos auxiliares -wal y -shm. Copiar solo la base de datos principal mientras la app escribe puede omitir transacciones recientes. Es preferible una exportación coherente creada con la base de datos cerrada o con un checkpoint.

Datos sensibles: las bases de datos de las apps pueden contener información personal, tokens o registros de negocio. Usa solo archivos que estés autorizado a inspeccionar y elimina las copias exportadas cuando termine la depuración.

Editar bases de datos de Android

Puedes editar una copia y descargarla, pero reemplazar la base de datos de una app puede incumplir las expectativas del esquema o corromper el estado de la aplicación. Conserva el original, valida las restricciones y usa herramientas de migración o depuración compatibles siempre que sea posible.
