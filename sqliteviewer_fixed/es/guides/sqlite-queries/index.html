Guía de consultas SQLite

Consultas útiles para inspeccionar bases de datos SQLite

Empieza con SQL seguro y concreto cuando necesites entender tablas, índices, relaciones y calidad de los datos.

Abrir el espacio SQL

Listar tablas y vistas del usuario

SELECT type, name, sql
FROM sqlite_master
WHERE type IN ('table', 'view')
  AND name NOT LIKE 'sqlite_%'
ORDER BY type, name;

Inspeccionar las columnas de una tabla

PRAGMA table_info('orders');

Esto devuelve el tipo declarado, la nulabilidad, el valor predeterminado y la posición en la clave primaria de cada columna.

Revisar las claves externas

PRAGMA foreign_key_list('orders');
PRAGMA foreign_key_check;

La primera sentencia describe las referencias declaradas de una tabla. La segunda informa de las filas que incumplen las relaciones de clave externa habilitadas.

Encontrar valores duplicados

SELECT email, COUNT(*) AS occurrences
FROM customers
WHERE email IS NOT NULL
GROUP BY email
HAVING COUNT(*) > 1
ORDER BY occurrences DESC;

Inspeccionar índices

PRAGMA index_list('orders');

Tras encontrar el nombre de un índice, inspecciona sus columnas con PRAGMA index_info('nombre_del_indice').

Comprobar el comportamiento de una consulta

EXPLAIN QUERY PLAN
SELECT *
FROM orders
WHERE customer_id = 42
ORDER BY created_at DESC;

El plan puede revelar escaneos completos de la tabla y si SQLite puede usar un índice relevante.

Flujo de trabajo seguro: empieza con consultas de inspección SELECT o PRAGMA. Antes de un UPDATE o DELETE, ejecuta un SELECT con la misma condición WHERE y conserva una copia original de la base de datos.

Paginar tablas grandes

SELECT *
FROM events
ORDER BY id
LIMIT 100 OFFSET 0;

Para navegar repetidamente por tablas muy grandes, la paginación por clave, como WHERE id > ? ORDER BY id LIMIT 100, suele ser más eficiente que un desplazamiento muy grande.
