Configura el puente ADB (funciona junto a Android Studio)

Un pequeño ayudante permite que SQLite Viewer y Android Studio usen tu teléfono a la vez. Descárgalo, colócalo en su sitio, haz que se inicie solo y listo.

Abrir el visor

¿Necesito el puente?

A menudo no. SQLite Viewer puede hablar con tu teléfono directamente por USB (modo USB directo en Chrome o Edge), sin instalar nada. El puente sirve para una situación: Android Studio (u otra herramienta ADB) ya está usando el teléfono. Solo un programa puede poseer la conexión USB, así que el puente permite que SQLite Viewer comparta el servidor ADB de Android Studio. Así ambos funcionan a la vez.

USB directoServidor ADB (puente)
¿Hay que instalar algo?NoSí, una vez (un clic en Windows)
¿Funciona con Android Studio abierto?No, debe estar cerradoSí
NavegadorChrome o Edge de escritorioCualquier navegador moderno
¿Necesita ADB en el PC?NoSí (Android Studio o Platform Tools)

Windows: instalador de un clic

  1. Descarga el instalador. En SQLite Viewer abre Android en vivo, elige Servidor ADB y haz clic en Descargar el instalador (Windows).
  2. Conserva el archivo. Chrome puede decir que no se puede verificar el archivo. Elige Conservar (o Descargar archivo no verificado). El archivo es texto sin formato, así que puedes abrirlo en el Bloc de notas para leer exactamente qué hace.
  3. Ejecútalo una vez. Haz doble clic en Install-ADB-Bridge.cmd. Si Windows muestra Windows protegió su PC, haz clic en Más información y luego en Ejecutar de todas formas.
  4. Vuelve a la página. El instalador crea el puente en tu PC, hace que se inicie solo cada vez que inicias sesión y lo arranca. SQLite Viewer lo detecta en pocos segundos. Haz clic en Conectar mediante el puente.

El puente se instala en %LOCALAPPDATA%\SQLiteViewerBridge y un acceso directo en tu carpeta de Inicio lo arranca al iniciar sesión. Para quitarlo, ejecuta uninstall.cmd desde esa carpeta.

Cualquier sistema: configúralo con Python

  1. Instala Python 3. Descárgalo de python.org. En Windows, marca Add Python to PATH en el instalador. La mayoría de los sistemas Linux ya tienen python3. macOS no lo incluye por defecto: la primera vez que escribas python3, macOS ofrece instalar las Command Line Tools de Apple (acéptalo), o puedes usar el instalador de python.org.
  2. Descarga el archivo. Descarga adb-bridge.py. Tu navegador lo guarda en la carpeta Descargas. Si termina en .txt, renómbralo a adb-bridge.py.
  3. Cópialo a su lugar permanente. Abre una terminal (sirve cualquier carpeta, los comandos usan rutas completas) y ejecuta el comando de tu sistema. Crea la carpeta y copia el archivo en ella. Si tu navegador guardó el archivo en un lugar distinto de Descargas, cambia esa parte del comando.
  4. Haz que se inicie solo. Ejecuta el comando de tu sistema. Configura la entrada de inicio al iniciar sesión para el archivo donde lo copiaste y arranca el puente ahora.
  5. Conecta. Vuelve a SQLite Viewer. Encuentra el puente por sí solo. Haz clic en Conectar mediante el puente.

Paso 3: copia el archivo (ejecútalo una vez)

Windows (PowerShell; pulsa la tecla Windows, escribe powershell y pulsa Intro):

New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\SQLiteViewerBridgePython" | Out-Null; Copy-Item "$env:USERPROFILE\Downloads\adb-bridge.py" "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py"

Windows (Símbolo del sistema; pulsa la tecla Windows, escribe cmd y pulsa Intro):

mkdir "%LOCALAPPDATA%\SQLiteViewerBridgePython" & copy "%USERPROFILE%\Downloads\adb-bridge.py" "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

macOS (Terminal):

mkdir -p "$HOME/Library/Application Support/SQLiteViewerBridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py"

Linux:

mkdir -p "$HOME/.local/share/sqliteviewer-bridge" && cp "$HOME/Downloads/adb-bridge.py" "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py"

Paso 4: haz que se inicie solo al iniciar sesión (ejecútalo una vez)

Windows (PowerShell):

python "$env:LOCALAPPDATA\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

Windows (Símbolo del sistema):

python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup

macOS:

python3 "$HOME/Library/Application Support/SQLiteViewerBridge/adb-bridge.py" --add-to-startup

Linux:

python3 "$HOME/.local/share/sqliteviewer-bridge/adb-bridge.py" --add-to-startup

En Windows esto crea un acceso directo oculto en tu carpeta de Inicio; en macOS, un Launch Agent; y en Linux, un servicio de usuario de systemd (o una entrada de inicio automático del escritorio). Ninguno necesita derechos de administrador. Deja el archivo donde está; si lo mueves, ejecuta el comando de nuevo.

¿Tienes prisa? Un comando hace los pasos 3 y 4

Abre una terminal en la carpeta donde descargaste el archivo y ejecuta:

python adb-bridge.py --install      # Windows
python3 adb-bridge.py --install     # macOS and Linux

¿Prefieres añadirlo a Inicio a mano?

Windows: pulsa Win + R, escribe shell:startup y pulsa Intro. En la carpeta que se abre, haz clic derecho, elige Nuevo → Acceso directo y establece la ubicación en:

pythonw "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py"

Ponle el nombre SQLite Viewer ADB Bridge. Usar pythonw en lugar de python evita la ventana negra. Cierra sesión y vuelve a iniciarla, o haz doble clic en el acceso directo para iniciarlo ahora.

macOS: el comando anterior crea ~/Library/LaunchAgents/com.sqliteviewer.adbbridge.plist. Linux: crea ~/.config/systemd/user/sqliteviewer-bridge.service (o ~/.config/autostart/sqliteviewer-bridge.desktop). Es posible escribir esos archivos a mano, pero el comando es más seguro.

Compruébalo, deténlo y quítalo

python adb-bridge.py --status                  # is it running?
python adb-bridge.py --remove-from-startup      # stop starting at sign-in (keeps the file)
python adb-bridge.py --uninstall                # stop it and delete everything
# add the full path to the file if you are not in its folder, as in the commands above

¿Tengo ADB? Instálalo si no

El puente retransmite a ADB (Android Platform Tools). Android Studio ya lo incluye, así que si usas Android Studio puedes saltarte esta sección. Para comprobarlo, abre una terminal y ejecuta adb version. Si el sistema no reconoce el comando, instala ADB con uno de los comandos siguientes. SQLite Viewer también te avisa cuando el puente está en marcha pero no encuentra ADB. El puente busca ADB en tu PATH y en las carpetas habituales de Android Studio, winget, Homebrew y descargas manuales, así que no necesitas cambiar el PATH, y arranca el servidor ADB por ti.

Windows

Lo más fácil (Windows 10 y 11, PowerShell o Símbolo del sistema):

winget install --id Google.PlatformTools -e

¿Sin winget? Descárgalo directamente (PowerShell):

Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile "$env:TEMP\pt.zip"; Expand-Archive "$env:TEMP\pt.zip" "$env:LOCALAPPDATA\Android\Sdk" -Force; Remove-Item "$env:TEMP\pt.zip"

Lo mismo en el Símbolo del sistema:

powershell -NoProfile -Command "Invoke-WebRequest https://dl.google.com/android/repository/platform-tools-latest-windows.zip -OutFile \"$env:TEMP\pt.zip\"; Expand-Archive \"$env:TEMP\pt.zip\" \"$env:LOCALAPPDATA\Android\Sdk\" -Force; Remove-Item \"$env:TEMP\pt.zip\""

Comprueba que funcionó (PowerShell):

& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" version

macOS

Con Homebrew:

brew install --cask android-platform-tools

Sin Homebrew:

mkdir -p "$HOME/Library/Android/sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-darwin.zip && unzip -o /tmp/pt.zip -d "$HOME/Library/Android/sdk" && rm /tmp/pt.zip

Linux

Debian, Ubuntu, Mint:

sudo apt install adb

Fedora:

sudo dnf install android-tools

Arch, Manjaro:

sudo pacman -S android-tools

Cualquier otra distribución:

mkdir -p "$HOME/Android/Sdk" && curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-linux.zip && unzip -o /tmp/pt.zip -d "$HOME/Android/Sdk" && rm /tmp/pt.zip

Después, prepara el teléfono

  1. En el teléfono abre Ajustes → Acerca del teléfono y toca Número de compilación siete veces.
  2. Abre Ajustes → Opciones de desarrollador y activa la Depuración USB.
  3. Conecta el teléfono y toca Permitir en el aviso. Al ejecutar adb devices debería aparecer como device.

¿Tengo que configurar algo?

No. El puente solo acepta conexiones del sitio web de SQLite Viewer, escucha únicamente en tu propio ordenador (127.0.0.1) y solo retransmite al servidor ADB del mismo ordenador. No se almacena ni se envía nada a ningún otro sitio.

Solo necesitas un ajuste en dos casos:

  • Usas SQLite Viewer desde otra dirección (tu propia copia, o localhost mientras desarrollas). Permite esa dirección en los mismos comandos:
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --allow-origin https://your-address.example
  • El puerto 5038 ya está en uso. Usa otro puerto y luego introduce el mismo puerto en Avanzado del panel de Android:
python "%LOCALAPPDATA%\SQLiteViewerBridgePython\adb-bridge.py" --add-to-startup --port 5040

Las direcciones permitidas se recuerdan en un archivo llamado origins.txt (una dirección por línea) junto al puente: en Windows %LOCALAPPDATA%\SQLiteViewerBridge (instalador) o %LOCALAPPDATA%\SQLiteViewerBridgePython (Python), en macOS ~/Library/Application Support/SQLiteViewerBridge, en Linux ~/.local/share/sqliteviewer-bridge.

Solución de problemas

  • «El puente no se está ejecutando en este ordenador»: ejecuta el instalador o los comandos anteriores, o cierra sesión y vuelve a iniciarla. Luego vuelve a abrir el panel de Android.
  • No tengo Python: en Windows no lo necesitas, usa el instalador de un clic de arriba. En los demás casos instala Python 3 desde python.org (Windows: marca Add Python to PATH) o, en macOS, acepta la oferta de instalar las Command Line Tools. Luego ejecuta los comandos de nuevo.
  • python no se reconoce o abre Microsoft Store (Windows): Python aún no está instalado o se omitió su opción de PATH. Instálalo desde python.org o sustituye python por py en los comandos. También puedes desactivar el acceso directo a la Store en Configuración → Aplicaciones → Configuración avanzada de aplicaciones → Alias de ejecución de aplicaciones.
  • El comando de copia dice que no se encuentra el archivo: tu navegador guardó adb-bridge.py en un lugar distinto de Descargas. Cambia esa parte del comando o renombra un archivo .txt.
  • «Algo ya está escuchando en el puerto 5038»: hay otro puente en ejecución. Quita el antiguo (--uninstall o uninstall.cmd) o elige otro puerto con --port.
  • El puente funciona pero no aparece ningún teléfono: el servidor ADB debe ver el teléfono. Ejecuta adb devices, activa la depuración USB y acepta el aviso «Permitir depuración USB» en el teléfono.
  • «El puente se está ejecutando, pero ADB no está instalado»: instala ADB con los comandos de la sección ¿Tengo ADB? de arriba (o instala Android Studio). La página lo detecta sola unos segundos después.
  • Chrome pide permiso para acceder a dispositivos de tu red: permítelo. Así es como la página llega al puente de tu propio ordenador.
  • El antivirus o Windows bloquea el instalador: el instalador solo compila un programa pequeño a partir de un código fuente que puedes leer y escribe en tus propias carpetas de usuario. Permítelo o usa la ruta de Python.
