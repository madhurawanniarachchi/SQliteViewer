Edita filas con protección de clave primaria

Abre una base de datos y selecciona una tabla. Cuando la tabla tiene una clave primaria utilizable, el resultado incluye acciones para editar y eliminar filas individuales. El editor usa los valores de la clave primaria para apuntar a la fila correcta en lugar de depender de su posición visual.

  1. Elige Editar en la fila.
  2. Cambia los valores de los campos necesarios. Usa la opción nulo cuando la columna lo permita.
  3. Guarda la fila y confirma el resultado actualizado.
  4. Elige Guardar BD para descargar la base de datos cuando termines.
Importante: los cambios se aplican a la base de datos que está en la memoria del navegador. No sobrescriben el archivo original automáticamente. Descarga la base de datos más reciente antes de cerrar la página.

Usa SQL para cambios masivos

El espacio de consultas también admite sentencias de escritura de SQLite. Por ejemplo:

UPDATE "products"
SET "active" = 0
WHERE "last_order_at" < '2025-01-01';

Revisa con cuidado la condición WHERE antes de ejecutar una actualización o eliminación. Un buen flujo de trabajo es ejecutar primero la misma condición como SELECT, confirmar las filas afectadas y solo entonces ejecutar la consulta de escritura.

¿Qué puede impedir la edición de filas?

Las acciones seguras sobre filas requieren que el visor identifique los registros de forma fiable. Las tablas sin claves primarias pueden mostrarse como de solo lectura en la interfaz de filas. Las vistas, los resultados calculados, las uniones y las consultas de agregación normalmente no se pueden asignar con seguridad a una única fila de origen, aunque sí puedes inspeccionarlos o exportarlos.

Descarga la base de datos terminada

La acción Guardar BD exporta el estado actual de la base de datos SQLite, incluidas las ediciones de filas y las consultas de escritura que se hayan ejecutado correctamente. Conserva el original como copia de seguridad hasta que hayas probado el archivo descargado en la aplicación que lo usa.
