Privacidad

Tu base de datos se queda en tu navegador

SQLite Viewer está diseñado para abrir y procesar los archivos de base de datos seleccionados en el dispositivo del usuario, en lugar de subir su contenido para procesarlo en un servidor.

Procesamiento local de la base de datos

Cuando seleccionas un archivo SQLite, el JavaScript del navegador lo lee en la memoria local. La exploración de tablas, la ejecución de SQL, la edición de filas, la inspección del esquema y la exportación de la base de datos ocurren en la sesión del navegador. La aplicación no necesita transmitir el archivo seleccionado a un servidor para ofrecer estas funciones.

Qué puede recibir el sitio web

Como la mayoría de los sitios web, la infraestructura de alojamiento puede recibir información habitual de las solicitudes, como la dirección IP, el tipo de navegador, las páginas solicitadas, las marcas de tiempo y los registros de errores. El sitio puede usar analítica para entender las visitas a las páginas y el uso general. Los nombres de archivo de las bases de datos, el contenido de las tablas y el texto de las consultas SQL no deberían enviarse intencionadamente como eventos de analítica.

Almacenamiento del navegador

La aplicación puede usar el almacenamiento del navegador para preferencias locales e información del espacio de trabajo, como las pestañas de consultas o el historial de consultas. Esta información permanece asociada al perfil del navegador hasta que el usuario o el navegador la borren.

Descargas y archivos originales

La edición se realiza sobre la base de datos en memoria. Guardar BD crea una descarga del estado actual. La aplicación no sustituye en silencio el archivo de base de datos original en el disco.

Tus responsabilidades

Usa bases de datos a las que estés autorizado a acceder. Ten en cuenta la seguridad del dispositivo, el perfil del navegador y las extensiones instaladas al abrir archivos sensibles. Borra el almacenamiento del navegador y las copias descargadas cuando trabajes en un dispositivo compartido.

Recursos de terceros

La página puede cargar bibliotecas, analítica u otros recursos web de servicios de terceros. Estos servicios pueden recibir datos normales de las solicitudes web, pero la base de datos seleccionada no se incluye intencionadamente en ellas.

Para datos muy sensibles o regulados, usa un entorno y una configuración de navegador aprobados por tu organización y revisa el comportamiento de red de la aplicación desplegada antes de usarla.

Preguntas

Las preguntas sobre privacidad y seguridad pueden dirigirse al operador del sitio, CodeMasterLk. Esta página debe actualizarse cuando cambie el comportamiento del servicio en el tratamiento de datos.
