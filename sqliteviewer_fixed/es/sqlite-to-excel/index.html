Exportar a Excel

Exportar una tabla de SQLite a Excel

  1. Abre tu archivo .db, .sqlite, .sqlite3 o .db3 en SQLite Viewer. Se queda en tu navegador.
  2. Selecciona una tabla o escribe una consulta que devuelva exactamente las filas que necesitas.
  3. Haz clic en Exportar sobre los resultados y elige las columnas que quieres incluir.
  4. Elige Excel y el archivo se descarga de inmediato.

Usa SQL antes de exportar

Filtra, ordena, agrega o une tablas con SQL primero y luego exporta el resultado. Excel recibe exactamente las filas y columnas que seleccionaste, y el nombre de la tabla se usa como nombre de la hoja.

La exportación a Excel carga su biblioteca de hojas de cálculo bajo demanda, por lo que la primera exportación necesita conexión a internet. Tu base de datos sigue sin salir nunca de tu navegador.

Tus datos nunca salen de tu dispositivo

La conversión se ejecuta como JavaScript en la pestaña de tu navegador. La base de datos no se sube a ningún servidor, así que es seguro usarla con datos de clientes, bases de datos de apps y archivos internos.

También puedes importar desde Excel

SQLite Viewer también puede importar un archivo .xlsx o .xls a una nueva base de datos SQLite, para que consultes una hoja de cálculo con SQL. ¿Prefieres un formato de texto plano? Prueba CSV o JSON.
