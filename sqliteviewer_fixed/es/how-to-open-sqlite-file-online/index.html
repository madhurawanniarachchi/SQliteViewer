Primeros pasos

Cómo abrir un archivo SQLite en línea de forma segura

Inspecciona una base de datos SQLite local en tu navegador sin instalar software de escritorio ni enviar el archivo a un servidor remoto.

Abrir SQLite Viewer

Abre tu base de datos en tres pasos

  1. Abre SQLite Viewer en un navegador de escritorio moderno.
  2. Suelta tu base de datos sobre la tarjeta inicial, o haz clic en ella y selecciona un archivo .db, .sqlite, .sqlite3 o .db3.
  3. Selecciona una tabla en la barra lateral. El visor crea una pestaña de consulta y muestra la primera página de filas.
Privacidad: el archivo se lee localmente con JavaScript del navegador. No hace falta subirlo para inspeccionar tablas, ejecutar SQL o generar un diagrama ER.

Qué puedes inspeccionar

La lista de tablas da acceso rápido a tablas y vistas. Puedes buscar en esquemas largos, ordenar las tablas según varias medidas, inspeccionar la información de las columnas, controlar qué columnas se ven y fijar columnas mientras revisas conjuntos de resultados anchos.

Para un trabajo más detallado, usa el editor SQL. Una consulta básica se ve así:

SELECT *
FROM "customers"
LIMIT 0, 30;

Si el archivo no se abre

  • Confirma que es una base de datos SQLite real y no un volcado de texto SQL.
  • Prueba a renombrar una extensión poco común a .db para que aparezca en el selector de archivos.
  • Comprueba si el archivo está cifrado; una base de datos cifrada requiere su extensión o clave correspondiente y no puede leerse como SQLite normal.
  • Para archivos muy grandes, cierra las pestañas del navegador que consuman mucha memoria antes de volver a intentarlo.

Guarda o exporta tus hallazgos

Los resultados de las consultas pueden exportarse en formatos habituales. Si editas filas o ejecutas sentencias de escritura, usa Guardar BD para descargar la base de datos actual. El archivo local original no se sobrescribe de forma silenciosa.
