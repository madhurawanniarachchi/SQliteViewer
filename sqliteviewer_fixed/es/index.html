The bridge talks to ADB (Android Platform Tools). Android Studio already includes it. If you do not use Android Studio, install ADB with one of these commands. Open a terminal first.

On the phone: open Settings → About phone, tap Build number 7 times, then Settings → Developer options → turn on USB debugging. Plug the phone in and tap Allow when it asks.

You opened this page from a file, so browsers hide its origin ('null') and the bridge must allow every local file page. It is safer to serve the folder with python -m http.server 8000 and open http://localhost:8000 instead.

Advanced
  • Enable USB debugging on the phone and accept the prompt when connecting.
  • Only debuggable apps (debug builds) can be read. Release apps are protected by Android.
  • If the device is busy, run adb kill-server and close Android Studio, then connect again.
  • Use Chrome or Edge on desktop. The view is read-only and re-copies the file on each refresh.

Espacio de trabajo de bases de datos privado en el navegador

Inspecciona y edita archivos SQLite sin subir tus datos

SQLite Viewer se ejecuta directamente en tu navegador. Abre un archivo local .db, .sqlite, .sqlite3 o .db3, explora su esquema y sus filas, ejecuta SQL, haz cambios y descarga la última versión de la base de datos, todo sin enviar el archivo a un servidor.

Explora y busca tablas

Navega por esquemas grandes, ordena la lista de tablas por nombre, filas, celdas o tamaño estimado y fija las columnas importantes de los resultados.

Edita filas reales de la base de datos

Añade, actualiza y elimina filas con controles que respetan la clave primaria. Los cambios se quedan en la base de datos del navegador hasta que la descargues.

Usa un espacio de trabajo SQL con pestañas

Abre una pestaña nueva para cada tabla o consulta, cambia entre varias bases de datos y mantén cada resultado vinculado a su consulta.

Genera un diagrama ER

Visualiza entidades, columnas, tipos de datos, claves primarias y relaciones de clave externa, y ajusta el diagrama a la ventana.

Exporta el esquema y los resultados

Exporta esquemas ER como SQL DDL, DBML, Mermaid o GraphQL SDL, y los resultados de consultas en formatos de datos comunes.

Guarda el archivo SQLite modificado

Los cambios se aplican localmente. Elige Guardar BD cuando quieras descargar la base de datos actual como un archivo SQLite utilizable.

Preguntas frecuentes

Preguntas frecuentes de SQLite Viewer

¿Se sube mi base de datos SQLite?

No. La base de datos se abre y se procesa localmente con JavaScript en tu navegador. La herramienta no necesita subir el archivo para inspeccionarlo.

¿Puedo editar y guardar una base de datos SQLite?

Sí. Puedes editar las filas de tablas compatibles o ejecutar consultas de escritura y luego usar Guardar BD para descargar el estado más reciente.

¿Qué extensiones de archivo SQLite se admiten?

El selector de archivos acepta .db, .sqlite, .sqlite3 y .db3. Una base SQLite válida puede usar otra extensión, pero quizá debas renombrarla antes de seleccionarla.

¿Funciona con bases de datos grandes?

Los archivos grandes dependen de la memoria disponible del navegador. El visor limita las filas mostradas y muestrea los metadatos costosos de las tablas para mantenerse fluido.
