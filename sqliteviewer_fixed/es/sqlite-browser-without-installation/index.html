Cuándo es útil una herramienta de navegador

Un visor web es cómodo para inspecciones puntuales de bases de datos, tareas de soporte, ejercicios de clase, bases de datos exportadas de apps y entornos donde no puedes instalar software. La aplicación se carga desde la web, pero la base de datos seleccionada se procesa localmente en el navegador.

Funciones disponibles sin instalación

  • Buscar y explorar tablas y vistas.
  • Ejecutar sentencias SELECT e inspeccionar resultados paginados.
  • Usar varias pestañas de consultas y de bases de datos.
  • Añadir, editar o eliminar filas identificables de forma segura.
  • Generar un diagrama ER con columnas, tipos y claves.
  • Exportar resultados o formatos de esquema.
  • Descargar la base de datos modificada actual.

¿Herramienta de navegador o aplicación de escritorio?

Una aplicación de escritorio sigue siendo mejor para bases de datos extremadamente grandes, extensiones de cifrado, administración continua en producción, análisis avanzado de índices o bloqueo directo del sistema de archivos. Una herramienta de navegador destaca cuando valoras la rapidez, la portabilidad y el procesamiento local de un archivo SQLite normal.

Como la base de datos vive en la memoria del navegador, conserva el archivo original y descarga los cambios antes de cerrar o recargar la página.

Consideraciones de privacidad

Confirma que la página se sirve por HTTPS y usa una copia de confianza de la aplicación. SQLite Viewer no requiere subir la base de datos, pero las extensiones del navegador y el propio dispositivo siguen formando parte de tu entorno de seguridad.
