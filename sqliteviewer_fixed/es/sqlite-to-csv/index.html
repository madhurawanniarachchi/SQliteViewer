Convertir SQLite a CSV

Convierte una tabla o el resultado de cualquier consulta SQL en un archivo CSV que puedes abrir en Excel, Google Sheets o importar a otra base de datos.

Exportar a CSV

Exportar una tabla de SQLite a CSV

  1. Abre tu archivo .db, .sqlite, .sqlite3 o .db3 en SQLite Viewer. Se queda en tu navegador.
  2. Selecciona una tabla o escribe una consulta que devuelva exactamente las filas que necesitas.
  3. Haz clic en Exportar sobre los resultados y elige las columnas que quieres incluir.
  4. Elige CSV y el archivo se descarga de inmediato.

Exporta solo lo que necesitas

Como la exportación sigue la consulta actual, puedes filtrar con WHERE, unir tablas, ordenar o limitar filas primero y luego exportar exactamente ese resultado. El selector de columnas te permite dejar fuera las columnas que no quieras en el archivo.

Consejo: para exportar una tabla completa, selecciónala y quita cualquier LIMIT de la consulta antes de hacer clic en Exportar.

Tus datos nunca salen de tu dispositivo

La conversión se ejecuta como JavaScript en la pestaña de tu navegador. La base de datos no se sube a ningún servidor, así que es seguro usarla con datos de clientes, bases de datos de apps y archivos internos.

Cuándo usar CSV

CSV es el formato más portátil para hojas de cálculo, herramientas de BI e importaciones masivas. Si necesitas valores tipados o datos anidados, usa JSON; para un libro con formato, usa Excel.
