Convert SQLite to CSV

Turn a table or any SQL query result into a CSV file you can open in Excel, Google Sheets or import into another database.

Export to CSV

Export a SQLite table to CSV

  1. Open your .db, .sqlite, .sqlite3 or .db3 file in SQLite Viewer. It stays in your browser.
  2. Select a table, or write a query that returns exactly the rows you need.
  3. Click Export above the results and choose the columns to include.
  4. Pick CSV and the file downloads straight away.

Export only what you need

Because the export follows the current query, you can filter with WHERE, join tables, sort or limit rows first, then export that exact result. The column picker lets you leave out columns you do not want in the file.

Tip: for a full table export, select the table and remove any LIMIT from the query before clicking Export.

Your data never leaves your device

The conversion runs as JavaScript in your browser tab. The database is not uploaded to a server, so it is safe to use with customer data, app databases and internal files.

When to use CSV

CSV is the most portable format for spreadsheets, BI tools and bulk imports. If you need typed values or nested data, use JSON; for a formatted workbook, use Excel.
