Export to Excel

Export a SQLite table to Excel

  1. Open your .db, .sqlite, .sqlite3 or .db3 file in SQLite Viewer. It stays in your browser.
  2. Select a table, or write a query that returns exactly the rows you need.
  3. Click Export above the results and choose the columns to include.
  4. Pick Excel and the file downloads straight away.

Use SQL before you export

Filter, sort, aggregate or join tables with SQL first, then export the result. Excel receives exactly the rows and columns you selected, with the table name used as the sheet name.

The Excel export loads its spreadsheet library on demand, so the first Excel export needs an internet connection. Your database still never leaves your browser.

Your data never leaves your device

The conversion runs as JavaScript in your browser tab. The database is not uploaded to a server, so it is safe to use with customer data, app databases and internal files.

Import from Excel too

SQLite Viewer can also import an .xlsx or .xls file into a new SQLite database, so you can query a spreadsheet with SQL. Prefer a plain-text format? Try CSV or JSON.
