建立 Mermaid 語法

  1. 開啟 SQLite 檔案。
  2. 開啟 ER 圖以確認實體和關聯。
  3. 選擇 Mermaid 並匯出結構。
  4. 將結果貼到相容 Mermaid 的 Markdown 或文件系統中。

文字式圖表的優勢

Mermaid 語法可以提交到版本控制、當作文字檢閱，並在結構變更時重新產生。在專案 README、架構文件和技術筆記中很有用，因為這些地方的二進位圖表檔難以維護。

了解關聯的限制

轉換器讀取已宣告的外部索引鍵，無法僅憑相似的欄位名稱可靠地臆測關聯。如果缺少預期的連線，請檢查 SQLite 結構，並確認該關聯已透過外部索引鍵限制條件宣告。

不同平台上的 Mermaid 算繪器可能略有差異。請在將發布的文件系統中測試匯出的語法。

讓圖表保持聚焦

大型資料庫可能產生過於擁擠的圖表。可考慮依範圍明確的主題領域（例如驗證、計費或庫存）分別記錄，同時保留一份完整的結構匯出以供參考。
