隱私權

您的資料庫保留在您的瀏覽器中

SQLite Viewer 的設計是在使用者裝置上開啟並處理所選資料庫檔案，而不是上傳其內容進行伺服器端處理。

本機資料庫處理

當您選擇 SQLite 檔案時，瀏覽器 JavaScript 會將其讀入本機記憶體。瀏覽資料表、執行 SQL、編輯列、檢視結構和匯出資料庫都在瀏覽器工作階段中完成。應用程式無需將所選資料庫檔案傳輸到伺服器即可提供這些功能。

網站可能接收的資訊

與大多數網站一樣，代管基礎架構可能會收到一般的要求資訊，例如 IP 位址、瀏覽器類型、要求的頁面、時間戳記和錯誤記錄。網站可能使用分析工具來了解頁面造訪和整體使用情況。資料庫檔名、資料表內容和 SQL 查詢文字不應被刻意當作分析事件傳送。

瀏覽器儲存空間

應用程式可能使用瀏覽器儲存空間來保存本機偏好設定和工作區資訊，例如查詢分頁或查詢記錄。這些資訊會一直與瀏覽器設定檔相關聯，直到使用者或瀏覽器將其清除。

下載與原始檔案

編輯是針對記憶體中的資料庫進行的。「儲存資料庫」會建立目前狀態的下載。應用程式不會悄悄取代磁碟上的原始資料庫檔案。

您的責任

請使用您有權存取的資料庫。開啟敏感檔案時，請考量裝置、瀏覽器設定檔和已安裝擴充功能的安全性。在共用裝置上作業時，請清除瀏覽器儲存空間和已下載的副本。

第三方資源

頁面可能從第三方服務載入程式庫、分析工具或其他網站資源。這些服務可能會收到一般的網路要求資料，但所選資料庫不會被刻意包含在這些要求中。

對於高度敏感或受監管的資料，請使用經您所屬組織核准的環境和瀏覽器設定，並在使用前檢查已部署應用程式的網路行為。

問題

有關隱私權和安全性的問題，可聯絡網站營運者 CodeMasterLk。當服務的資料處理行為變更時，應更新本頁面。
