將 SQLite 轉換為 CSV

將資料表或任何 SQL 查詢結果轉換為 CSV 檔案，可在 Excel、Google 試算表中開啟，或匯入其他資料庫。

匯出為 CSV

將 SQLite 資料表匯出為 CSV

  1. 在 SQLite Viewer 中開啟您的 .db、.sqlite、.sqlite3 或 .db3 檔案。檔案始終留在您的瀏覽器中。
  2. 選擇一個資料表，或撰寫一則剛好傳回所需列的查詢。
  3. 點選結果上方的匯出，並選擇要包含的欄位。
  4. 選擇 CSV，檔案會立即下載。

只匯出您需要的內容

由於匯出會依據目前的查詢，您可以先用 WHERE 篩選、聯結資料表、排序或限制列數，再匯出該結果。欄位選擇器可讓您排除不想放入檔案的欄位。

提示：若要匯出整個資料表，請選擇該資料表，並在點選「匯出」前移除查詢中的 LIMIT。

您的資料絕不會離開您的裝置

轉換會以 JavaScript 的形式在瀏覽器分頁中執行。資料庫不會上傳到伺服器，因此可以放心用於客戶資料、應用程式資料庫和內部檔案。

何時使用 CSV

CSV 是試算表、BI 工具和大量匯入最通用的格式。如需具型別的值或巢狀資料，請使用 JSON；如需有格式的活頁簿，請使用 Excel。
