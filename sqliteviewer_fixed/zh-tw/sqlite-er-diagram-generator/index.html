結構視覺化

從 SQLite 產生 ER 圖

將陌生的資料庫變成清楚易讀的地圖，呈現資料表、欄位、類型、主索引鍵和外部索引鍵連線。

開啟 ER 圖工具

建立圖表

  1. 在檢視器中開啟 SQLite 資料庫。
  2. 在資料表側邊欄中選擇 ER 圖。
  3. 使用符合視窗將所有實體顯示在對話方塊檢視區中。
  4. 檢查每個實體的欄位名稱、SQLite 資料類型和索引鍵標記。

關聯線來自 SQLite 中宣告的外部索引鍵。如果邏輯關聯沒有以外部索引鍵限制條件定義，僅憑欄位名稱，結構讀取器無法可靠地辨識。

如何閱讀結果

  • PK 表示用來唯一定位一列的主索引鍵欄位。
  • FK 表示參照另一個資料表中索引鍵的欄位。
  • 欄位類型顯示宣告的 SQLite 類型。由於 SQLite 的類型系統很有彈性，實際儲存的值有時可能與該宣告不同。
  • 連接線顯示被參照的實體與參照它的實體。
當資料庫一致地宣告了主索引鍵和外部索引鍵時，圖表最有用。缺少連線通常代表缺少限制條件，而不是算繪問題。

匯出結構

檢視圖表後，可將其結構匯出為 SQL DDL、DBML、Mermaid 或 GraphQL SDL。SQL DDL 最接近原始資料庫定義；DBML 和 Mermaid 適用於文件；GraphQL SDL 是 API 模型的起點，可能需要依應用程式調整。

實用的檢視問題

找出沒有主索引鍵的資料表、指向非預期實體的外部索引鍵、命名不一致、應為必填卻允許空值的欄位，以及代表多對多關聯的中介資料表。在接手應用程式資料庫或規劃移轉時，這些檢查很有幫助。
