開啟 SQLite 瀏覽器

瀏覽器工具何時有用

網頁版檢視器適合一次性的資料庫檢視、技術支援、課堂練習、匯出的應用程式資料庫，以及無法安裝軟體的環境。應用程式從網路載入，但所選資料庫在瀏覽器中本機處理。

免安裝即可使用的功能

  • 搜尋和瀏覽資料表與檢視表。
  • 執行 SELECT 陳述式並檢視分頁結果。
  • 使用多個查詢分頁和資料庫分頁。
  • 新增、編輯或刪除可安全識別的列。
  • 產生包含欄位、類型和索引鍵的 ER 圖。
  • 匯出結果或結構格式。
  • 下載目前修改後的資料庫。

選瀏覽器工具還是桌面應用程式？

對於超大型資料庫、加密擴充功能、持續的正式環境管理、進階索引分析或直接檔案系統鎖定，桌面應用程式仍是更好的選擇。當您重視速度、可攜性和對一般 SQLite 檔案的本機處理時，瀏覽器工具最具優勢。

由於資料庫存放在瀏覽器記憶體中，請保留原始檔案，並在關閉或重新整理頁面之前下載變更。

隱私權注意事項

請確認頁面透過 HTTPS 提供，並使用可信任的應用程式副本。SQLite Viewer 不需要上傳資料庫，但瀏覽器擴充功能和裝置本身仍是您安全環境的一部分。
