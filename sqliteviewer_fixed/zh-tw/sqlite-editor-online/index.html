開啟 SQLite 編輯器

在主索引鍵保護下編輯列

開啟資料庫並選擇一個資料表。當該資料表具有可用的主索引鍵時，結果中會包含編輯和刪除單列的操作。編輯器使用主索引鍵值來定位目標列，而不是依賴其在介面上的位置。

  1. 在該列上選擇編輯。
  2. 修改所需的欄位值。當欄位允許時，可使用空值選項。
  3. 儲存該列並確認更新後的結果。
  4. 完成後選擇儲存資料庫以下載資料庫。
重要：變更是針對保存在瀏覽器記憶體中的資料庫進行的，不會自動覆寫原始檔案。關閉頁面前請下載最新的資料庫。

用 SQL 進行大量變更

查詢工作區也支援 SQLite 寫入陳述式。例如：

UPDATE "products"
SET "active" = 0
WHERE "last_order_at" < '2025-01-01';

執行更新或刪除之前，請仔細檢查 WHERE 條件。較好的做法是先把相同的條件當作 SELECT 執行，確認受影響的列，然後再執行寫入查詢。

是什麼阻止了列編輯？

安全的列操作要求檢視器能可靠地識別記錄。沒有主索引鍵的資料表在列介面中可能顯示為唯讀。檢視表、計算結果、聯結和彙總查詢通常無法安全地對應回單一來源列，但您仍可檢視或匯出它們。

下載完成的資料庫

「儲存資料庫」操作會匯出目前 SQLite 資料庫的狀態，包括成功的列編輯和寫入查詢。在您用實際使用該資料庫的應用程式測試過下載的檔案之前，請保留原始檔案作為備份。
