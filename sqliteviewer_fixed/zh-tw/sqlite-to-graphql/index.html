開啟 GraphQL SDL 匯出器

產生結構

  1. 開啟 SQLite 資料庫。
  2. 在 ER 圖中檢視其實體。
  3. 選擇 GraphQL SDL 作為匯出格式。
  4. 匯出類型定義，並在您的 API 專案中檢視。
type Customer {
  id: Int!
  name: String
  orders: [Order!]
}

type Order {
  id: Int!
  customerId: Int!
}

SDL 不是完整的 API

資料庫結構描述的是儲存，而 GraphQL 描述的是面向應用程式的合約。產生的 SDL 不會建立解析器、驗證、分頁、驗證規則、變更操作或欄位層級授權，請將其視為結構化的初稿。

檢查類型對應

SQLite 類型與 GraphQL 純量並不能完美對應。日期可能以文字或數字儲存，小數可能需要自訂純量，二進位資料需要應用程式專屬的表示方式。當有更清楚的 API 名稱時，請重新命名技術性的資料庫欄位。

切勿自動公開所有資料庫資料表。只選擇用戶端應能存取的欄位和操作，並在 API 層強制執行授權。

審慎使用關聯

已宣告的外部索引鍵可以提示 GraphQL 關聯，但解析器的行為取決於您的伺服器實作。請考慮批次處理和分頁，以避免昂貴的巢狀資料庫存取。
