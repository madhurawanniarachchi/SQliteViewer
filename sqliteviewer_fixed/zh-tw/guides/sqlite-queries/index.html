SQLite 查詢指南

檢查 SQLite 資料庫的實用查詢

當您需要了解資料表、索引、關聯和資料品質時，請從安全且有針對性的 SQL 開始。

開啟 SQL 工作區

列出使用者資料表和檢視表

SELECT type, name, sql
FROM sqlite_master
WHERE type IN ('table', 'view')
  AND name NOT LIKE 'sqlite_%'
ORDER BY type, name;

檢視資料表的欄位

PRAGMA table_info('orders');

這會傳回每個欄位宣告的類型、是否可為 Null、預設值以及在主索引鍵中的位置。

檢查外部索引鍵

PRAGMA foreign_key_list('orders');
PRAGMA foreign_key_check;

第一個陳述式描述某個資料表已宣告的參照。第二個陳述式回報違反已啟用外部索引鍵關聯的列。

尋找重複值

SELECT email, COUNT(*) AS occurrences
FROM customers
WHERE email IS NOT NULL
GROUP BY email
HAVING COUNT(*) > 1
ORDER BY occurrences DESC;

檢視索引

PRAGMA index_list('orders');

找到索引名稱後，可使用 PRAGMA index_info('index_name') 檢視其欄位。

檢查查詢行為

EXPLAIN QUERY PLAN
SELECT *
FROM orders
WHERE customer_id = 42
ORDER BY created_at DESC;

執行計畫可以顯示是否發生了全資料表掃描，以及 SQLite 能否使用相關索引。

安全的工作流程：先使用 SELECT 或 PRAGMA 檢查類查詢。在執行 UPDATE 或 DELETE 之前，先用相同的 WHERE 條件執行 SELECT，並保留資料庫的原始副本。

對大型資料表分頁

SELECT *
FROM events
ORDER BY id
LIMIT 100 OFFSET 0;

對於需要反覆瀏覽的超大型資料表，使用索引鍵集分頁（例如 WHERE id > ? ORDER BY id LIMIT 100）通常比很大的位移量更有效率。
