快速入門

如何安全地線上開啟 SQLite 檔案

無需安裝桌面軟體，也無需將檔案傳送到遠端伺服器，即可在瀏覽器中檢視本機 SQLite 資料庫。

開啟 SQLite Viewer

三步驟開啟您的資料庫

  1. 在現代桌面瀏覽器中開啟 SQLite Viewer。
  2. 將資料庫拖曳到起始卡片上，或點選該卡片並選擇 .db、.sqlite、.sqlite3 或 .db3 檔案。
  3. 在側邊欄中選擇一個資料表。檢視器會建立查詢分頁並顯示第一頁資料列。
隱私權：檔案由瀏覽器 JavaScript 在本機讀取。檢視資料表、執行 SQL 或產生 ER 圖都無需上傳。

可以檢視什麼

資料表清單可快速存取資料表和檢視表。您可以搜尋較長的結構、依多種指標對資料表排序、檢視欄位資訊、控制可見欄位，並在檢視較寬的結果集時固定欄位。

如需更詳細的操作，請使用 SQL 編輯器。基本查詢如下：

SELECT *
FROM "customers"
LIMIT 0, 30;

檔案無法開啟時

  • 確認它是真正的 SQLite 資料庫，而不是 SQL 文字傾印檔。
  • 嘗試將不常見的副檔名重新命名為 .db，以便它出現在檔案選擇器中。
  • 檢查檔案是否已加密；加密的資料庫需要對應的擴充功能或金鑰，無法當作一般 SQLite 讀取。
  • 對於非常大的檔案，請先關閉佔用記憶體較多的瀏覽器分頁，再重試。

儲存或匯出您的發現

查詢結果可以匯出為常見格式。如果您編輯了列或執行了寫入陳述式，請使用儲存資料庫下載目前的資料庫。原始本機檔案不會被悄悄覆寫。
