將 SQLite 轉換為 JSON

將列匯出為由物件組成的 JSON 陣列，可直接用於 API、前端原型、測試資料和文件型資料庫。

匯出為 JSON

將 SQLite 資料表匯出為 JSON

  1. 在 SQLite Viewer 中開啟您的 .db、.sqlite、.sqlite3 或 .db3 檔案。檔案始終留在您的瀏覽器中。
  2. 選擇一個資料表，或撰寫一則剛好傳回所需列的查詢。
  3. 點選結果上方的匯出，並選擇要包含的欄位。
  4. 選擇 JSON，檔案會立即下載。

JSON 的樣子

每一列會變成以欄位名稱為鍵的物件，檔案則是這些物件組成的陣列。

[
  { "id": 1, "name": "Ada", "email": "ada@example.com" },
  { "id": 2, "name": "Linus", "email": "linus@example.com" }
]

用 SQL 調整輸出

可在匯出前透過查詢使用 AS 重新命名欄位、聯結相關資料表或篩選列，讓 JSON 符合您的應用程式所需的結構。

您的資料絕不會離開您的裝置

轉換會以 JavaScript 的形式在瀏覽器分頁中執行。資料庫不會上傳到伺服器，因此可以放心用於客戶資料、應用程式資料庫和內部檔案。
