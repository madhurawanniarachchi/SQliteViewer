結構匯出

將 SQLite 結構轉換為 SQL DDL

擷取可讀的結構定義，用於文件、檢閱、移轉規劃或版本控制。

開啟 SQLite 結構匯出器

從資料庫檔案匯出 SQL DDL

  1. 開啟 SQLite 資料庫。
  2. 開啟 ER 圖。
  3. 選擇 SQL DDL 作為匯出格式。
  4. 匯出並儲存產生的結構文字。

結果表示的是資料庫結構，而不是資料表中的資料。它包含實體定義、宣告的欄位類型，以及可從 SQLite 結構中繼資料推斷出的索引鍵資訊。

範例輸出

CREATE TABLE "orders" (
  "id" INTEGER PRIMARY KEY,
  "customer_id" INTEGER NOT NULL,
  "created_at" TEXT,
  FOREIGN KEY ("customer_id") REFERENCES "customers" ("id")
);

SQL DDL 的用途

  • 在程式碼檢閱中檢視資料庫結構。
  • 將結構變更納入版本控制。
  • 在不公開正式環境資料列的情況下記錄資料表。
  • 準備移轉到其他資料庫系統。
  • 比較預期與實際的資料表定義。
移轉說明：SQLite 的語法和類型親和性與 PostgreSQL、MySQL 和 SQL Server 不同。請將匯出的 DDL 視為對 SQLite 結構的可靠描述，再針對目標引擎調整類型、自動遞增行為、引號和限制條件。

結構匯出與資料庫儲存的差異

SQL DDL 只包含結構。如果需要包含資料列和本機編輯內容的資料庫，請使用儲存資料庫。如果需要可攜的文字格式資料列，請使用結果匯出控制項。
