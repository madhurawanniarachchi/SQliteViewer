將現有 SQLite 結構轉換為可讀的 DBML，用於文件和資料庫設計工作流程。

開啟 DBML 匯出器

從 SQLite 檔案產生 DBML

  1. 在 SQLite Viewer 中開啟您的資料庫。
  2. 選擇 ER 圖。
  3. 在匯出格式清單中選擇 DBML。
  4. 匯出產生的文字，並在您慣用的 DBML 工具中檢視。

轉換包含的內容

匯出內容描述資料表、欄位名稱、宣告的 SQLite 資料類型、主索引鍵以及宣告的外部索引鍵關係。它為設計工具提供足夠的結構來呈現有用的模型，而不會暴露資料表中的資料列。

Table orders {
  id integer [pk]
  customer_id integer [not null]
  created_at text
}

Ref: orders.customer_id > customers.id

為什麼使用 DBML？

DBML 比資料庫二進位檔更易於檢閱，也比可執行的 SQL 更專注於資料建模。團隊用它來討論結構、建立圖表、記錄關聯，並在撰寫移轉之前規劃變更。

DBML 是設計層面的表示，而不是逐位元組的資料庫備份。請保留原始 SQLite 檔案；需要包含資料的可用資料庫時，請使用「儲存資料庫」。

檢查產生的模型

SQLite 允許彈性的類型宣告，結構中也可能省略外部索引鍵。請檢查自訂類型、複合限制條件、產生的欄位、索引以及僅存在於應用程式程式碼中的關聯。必要時在匯出後加入設計層面的註解。
